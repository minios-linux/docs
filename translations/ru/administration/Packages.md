# Пакеты и редакции

Состав пакетов MiniOS формируется на основе условных исходных списков. Он может различаться в зависимости от дистрибутива, архитектуры, системы инициализации, рабочего окружения, локали, параметров ядра и доступности репозиториев. На этой странице описывается наследование редакций и типичное содержимое; это не полный перечень пакетов для каждого релиза.

## Наследование редакций

Публичные редакции образуют нарастающую последовательность:

1. **Flux** предоставляет общую live-систему и облегчённую среду Flux.
2. **Standard** наследует общую базу пакетов и добавляет инструменты для администрирования, управления рабочим столом и MiniOS.
3. **Toolbox** наследует Standard и добавляет средства восстановления, диагностики, работы с хранилищами, сетями и виртуализации.
4. **Ultra** наследует Toolbox и расширяет набор программ для рабочих станций, мультимедиа, офисных задач и контейнеризации.

Условные выражения позволяют выбирать альтернативы или исключать пакет в зависимости от набора, архитектуры, среды или опций сборки. Указанный ниже пакет является примером текущих исходных списков и не гарантирует, что одноимённый бинарный пакет Debian будет присутствовать во всех выпусках MiniOS.

## Охват рабочих столов и окружений

Пакеты рабочего стола формируются из упорядоченной цепочки модулей выбранного окружения. Окружения Xfce, Fluxbox, LXQt, core и debug имеют разные наборы модулей и пакетов. Примеры ниже основаны на текущих списках Xfce, если только функция не предоставляется общим core-списком. Консольные или другие сборки рабочих столов требуют отдельного анализа.

## Примерное содержимое

### Flux

Общий состав Flux включает средства конфигурирования и создания образов MiniOS live, NetworkManager, SSH, поддержку клавиатуры и локалей, прошивки, подобранные для целевой системы, а также утилиты для диагностики оборудования и работы с основными хранилищами.
Примерные пакеты: `minios-tools`, `minios-image-compose`, `minios-live-config`, `pciutils`, `usbutils`, `smartmontools`, `dosfstools`, `ntfs-3g`, `btrfs-progs`, `xorriso`, `squashfs-tools`, `zstd`, `rfkill` и `wpasupplicant`.

Цепочка рабочего стола Flux добавляет Fluxbox и вспомогательные инструменты, выбранные в исходных списках. Она не включает полный набор приложений Xfce и графических утилит MiniOS, описанных в разделе Standard.

Утилиты MiniOS, присутствующие во всех редакциях, включая Flux: `minios-tools`, `minios-image-compose`, `minios-live-config`, соответствующая интеграция с systemd или SysV init, `minios-live-config-doc` и `minios-welcome`.

### Standard

Standard добавляет общие возможности, такие как поддержка DNS, дополнительные инструменты для сжатия и работы с файловыми системами, клиенты сетевых файловых систем, FUSE, разметку дисков и создание ISO-образов. Примеры пакетов: `dnsmasq-base`, `ncdu`, `lsof`, `xfsprogs`, `exfatprogs` или его альтернативу для конкретного дистрибутива, `cifs-utils`, `nfs-common`, `parted`, `7zip` и `genisoimage`.

В Xfce редакции Standard и выше добавляют актуальные графические и административные утилиты MiniOS: `minios-configurator`, `minios-installer`, `minios-session-manager`, `minios-kernel-manager`, `minios-store`, `minios-store-gui`, `minios-image-builder`, `minios-module-manager` и `driveutility`. Также добавляются LightDM, интеграция с аудио и Bluetooth, создание скриншотов, управление задачами, уведомления и терминал Xfce.

### Toolbox

Toolbox добавляет командные утилиты для работы с хранилищами, восстановления, производительности, сетей и виртуальных машин. Актуальные примеры: инструменты LVM и LUKS, Clonezilla, Partclone, TestDisk, `gddrescue`, инструменты ZFS (если поддерживаются сборкой), Nmap, iperf3, QEMU, libvirt, гостевые агенты, fio, sysbench и средства диагностики оборудования.

Модуль приложений Xfce включает такие инструменты, как GParted, GSmartControl, Guymager, средства восстановления и работы с дисками, Wireshark, Remmina, Virt Manager, VLC, KeePassXC, PDF Arranger, Codium, BleachBit и графические утилиты для шифрования. Точные названия зависят от дистрибутива; исходный список может использовать одну из нескольких альтернатив.

### Ultra

Ultra сохраняет набор Toolbox и добавляет ПО для контейнеризации и рабочих станций. К общим дополнениям относятся пакеты Docker, подобранные под целевой репозиторий, поддержку Compose, `lazydocker`, инструменты iSCSI и утилиты для работы с user-namespace. В текущем списке приложений Xfce также присутствуют LibreOffice, GIMP, Inkscape, Blender, Audacity, OBS Studio, RawTherapee, Synaptic и связанные пакеты для интеграции с рабочим столом.

## Просмотр точного содержимого релиза

Работающая система является авторитетным источником сведений о реально установленных в этом релизе пакетах. Для вывода списка имён и версий пакетов используйте:

```bash
dpkg-query -W -f='${binary:Package}\t${Version}\n' | sort
```

Изучайте по отдельности упорядоченные модули, составляющие корень запущенной системы, и файлы, выбранные для следующей загрузки. В MiniOS Module Manager они отображаются как **Работает сейчас** и **Следующая загрузка**. В командной строке смонтированные в рантайме SquashFS-модули можно посмотреть так:

```bash
findmnt -rn -t squashfs -o TARGET,SOURCE
```

Для офлайн-носителей или смонтированного ISO просмотрите исходные файлы модулей напрямую:

```bash
find /path/to/media/minios -type f -name '*.sb' -printf '%P\n' | sort -n
```

Для исходной сборки авторитетными источниками манифестов и входных данных выбора являются следующие файлы и каталоги:

- `linux-live/environments/<environment>/` — для упорядоченной цепочки модулей.
- `linux-live/scripts/00-core/packages.list` — для общего выбора редакции.
- `linux-live/scripts/01-kernel/packages.list` и `02-firmware/packages.list` — для условных добавлений ядра и прошивок.
- `packages.list` каждого выбранного модуля рабочего стола и приложений.
- `linux-live/build.conf` — для фильтрации по набору, архитектуре, среде, варианту пакета, системе инициализации, ядру, локали и другим параметрам.
- `linux-live/condinapt.map` — для расшифровки префиксов фильтров списков пакетов.

Исходные списки описывают запрошенные пакеты и альтернативы. Только готовый образ и `dpkg-query` показывают точный набор разрешённых зависимостей и версий для конкретного релиза. Доступность и имена пакетов могут отличаться между наборами Debian, Ubuntu, Devuan и между рабочими столами.

Система сборки называет свой минимальный вариант пакета `minimum`. Это внутреннее значение `PACKAGE_VARIANT`, используемое в фильтрах CondinAPT, а не имя опубликованной редакции MiniOS. Опубликованная редакция, собранная из этого варианта пакета и среды Flux, называется **Flux**.

См. [Архитектура системы](/about/System-Architecture.md) для порядка модулей и [CondinAPT в MiniOS](/development/CondinAPT-MiniOS.md) для условного выбора пакетов.
