# Список пакетов MiniOS

В этом документе представлен подробный обзор всех пакетов, входящих в различные редакции MiniOS. MiniOS выпускается в трех основных редакциях, каждая из которых содержит свой набор предустановленного ПО:

- **Стандарт** — Минимальная система с базовой функциональностью
- **Toolbox** — Инструменты для администрирования и диагностики системы
- **Ultra** — Полноценное рабочее окружение с приложениями
