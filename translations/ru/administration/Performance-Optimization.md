# Руководство по оптимизации производительности

В этом руководстве описаны методы оптимизации производительности MiniOS с акцентом на его уникальные особенности как live-системы. Наибольший прирост производительности достигается за счёт настройки того, как MiniOS загружает свои данные и обрабатывает постоянные изменения.

## Параметры загрузки для повышения производительности

Самый эффективный способ ускорить работу системы, особенно при запуске с медленного USB-накопителя, — использовать параметры загрузки для управления тем, как система загружается в память. Полный список доступных параметров смотрите в разделе [Параметры загрузки](/configuration/Boot-Parameters.md).

### Загрузка системы в оперативную память (`toram`)

Это самая важная оптимизация. Параметр загрузки `toram` копирует всю систему MiniOS с загрузочного носителя в оперативную память вашего компьютера. Благодаря этому система становится максимально отзывчивой, так как больше не требуется считывать данные с медленного USB-накопителя.

- **Использование:** Добавьте `toram` в командную строку ядра при загрузке.
- **Требование:** Необходимо достаточно оперативной памяти для размещения основных модулей системы. Для редакции `standard` рекомендуется минимум 2–3 ГБ свободной ОЗУ.
- **Преимущество:** Значительно ускоряет запуск приложений и общую отзывчивость системы.

Для `toram` доступны два режима:

- **`toram=full` (по умолчанию):** Копируются все модули системы в оперативную память. Используйте этот режим, если у вас достаточно памяти.
- **`toram=trim`:** Копируются только необходимые модули, определённые параметрами загрузки `load` и `noload`. Подходит для систем с ограниченным объёмом ОЗУ.

### Фильтрация модулей (`load` и `noload`)

Чтобы снизить использование памяти, вы можете указать, какие модули загружать. Это особенно эффективно в сочетании с `toram=trim`.

- **`load=module1,module2`:** Загружаются только указанные модули (например, `load=01-kernel,03-gui-base,04-xfce-desktop`).
- **`noload=module_name`:** Исключает определённый модуль из загрузки.

Это позволяет создать компактную систему в ОЗУ, настроенную под ваши задачи.

## Оптимизация постоянства изменений

То, как MiniOS сохраняет ваши изменения (постоянство), может существенно влиять на производительность, особенно на скорость записи.

### Режимы постоянства (`perchmode`)

Параметр загрузки `perchmode` определяет механизм хранения ваших изменений. Выбор зависит от вашего устройства хранения:

- **`perchmode=native` (по умолчанию):** Сохраняет файлы напрямую в каталог на вашем устройстве. Это **самый быстрый вариант для SSD и быстрых USB-накопителей**, так как отсутствуют накладные расходы на файловую систему внутри файла.
- **`perchmode=raw`:** Использует заранее выделенный образ-файл для изменений. Производительность хорошая, но размер файла фиксирован.
- **`perchmode=dynfilefs`:** Использует динамически расширяемый файл. Это хороший выбор для **медленных USB-флешек**, так как может снизить износ памяти и потенциально продлить срок службы накопителя, хотя может быть немного медленнее, чем режим `native`.

### Включение и отключение постоянства

По умолчанию MiniOS работает в "live"-режиме, при котором все изменения теряются после перезагрузки. Чтобы сохранить изменения, необходимо явно включить постоянство.

- **Включить постоянство:** Добавьте параметр `perch` в командную строку загрузки. Это укажет MiniOS активировать механизм сохранения изменений.
- **Отключить постоянство:** Просто не добавляйте параметр `perch`. Если его нет, система будет работать полностью из ОЗУ (или загрузочного устройства), и изменения сохраняться не будут.

## Настройка ZRAM

MiniOS по умолчанию использует `zram` для создания сжатого swap-пространства в оперативной памяти. Это повышает производительность на системах с ограниченным объёмом физической памяти, позволяя избежать использования гораздо более медленного swap-файла на диске.

**Автоматический размер:**
- **≥4ГБ ОЗУ:** 2ГБ ZRAM
- **1–4ГБ ОЗУ:** 50% от общего объёма ОЗУ  
- **<1ГБ ОЗУ:** 512МБ ZRAM

**Параметры загрузки:**
- **`zramsize=1024`:** Задаёт размер устройства zram (например, `zramsize=1024` для 1ГБ). По умолчанию размер определяется автоматически в зависимости от объёма вашей ОЗУ.
- **`zramcomp=lz4`:** Задаёт алгоритм сжатия (`lzo`, `lzo-rle`, `lz4`, `lz4hc`, `zstd`). `lz4` обычно обеспечивает хороший баланс между скоростью и степенью сжатия.
- **`nozram`:** Полностью отключает ZRAM.

Для большинства пользователей стандартные настройки `zram` оптимальны. Изменять их рекомендуется только при наличии особых требований и понимании возможных последствий.

## Файловая система и оборудование для хранения данных

- **Используйте быстрый USB-накопитель:** Ключевой аппаратный фактор производительности MiniOS — это скорость вашего USB-устройства. Использование **USB 3.0 или более быстрого SSD-накопителя** обеспечит значительно лучший опыт по сравнению с дешёвой и медленной флешкой USB 2.0.
- **Выбор файловой системы:** Для раздела с постоянством изменений рекомендуется стандартная Linux-файловая система, такая как **ext4** — она обычно обеспечивает наилучшую производительность и надёжность.
