# Руководство по оптимизации производительности

В этом руководстве описаны методы оптимизации производительности MiniOS с акцентом на его уникальные особенности как live-системы. Наибольший прирост производительности достигается за счёт настройки того, как MiniOS загружает свои данные и обрабатывает постоянные изменения.

## Параметры загрузки для повышения производительности

Самый эффективный способ ускорить работу системы, особенно при запуске с медленного USB-накопителя, — использовать параметры загрузки для управления тем, как система загружается в память. Полный список доступных параметров смотрите в разделе [Параметры загрузки](/configuration/Boot-Parameters.md).

### Загрузка системы в RAM (`toram`)

Это самое важное улучшение производительности. Параметр загрузки `toram` копирует всю систему MiniOS с загрузочного носителя в оперативную память вашего компьютера (RAM). Благодаря этому система становится невероятно отзывчивой, так как больше не требуется считывать данные с медленного USB-накопителя.

- **Использование:** Добавьте `toram` в командную строку ядра при загрузке.
- **Требование:** Необходимо достаточно RAM для размещения основных модулей системы. Для редакции `standard` рекомендуется минимум 2-3 ГБ свободной RAM.
- **Преимущество:** Значительно ускоряет запуск приложений и повышает общую отзывчивость системы.

Для `toram` предусмотрено два режима:

- **`toram=full` (по умолчанию):** Копирует все модули системы в RAM. Используйте этот режим, если у вас достаточно памяти.
- **`toram=trim`:** Копирует только необходимые модули, определённые параметрами загрузки `load` и `noload`. Полезно для систем с ограниченным объёмом RAM.

### Фильтрация модулей (`load` и `noload`)

Чтобы снизить использование памяти, вы можете указать, какие модули загружать. Это особенно эффективно в сочетании с `toram=trim`.

- **`load=module1,module2`:** Загружает только указанные модули (например, `load=01-kernel,03-gui-base,04-xfce-desktop`).
- **`noload=module_name`:** Исключает определённый модуль из загрузки.

Это позволяет создать компактную систему в RAM, адаптированную под ваши задачи.

## Оптимизация постоянства изменений

То, как MiniOS сохраняет ваши изменения (постоянство), может существенно влиять на производительность, особенно на скорость записи.

### Режимы постоянства (`perchmode`)

Параметр загрузки `perchmode` определяет механизм хранения ваших изменений. Выбор зависит от вашего устройства хранения:

- **`perchmode=native` (по умолчанию):** Сохраняет файлы напрямую в каталог на вашем устройстве. Это **самый быстрый вариант для SSD и быстрых USB-накопителей**, так как отсутствуют накладные расходы на файловую систему внутри файла.
- **`perchmode=raw`:** Использует заранее выделенный образ-файл для изменений. Производительность хорошая, но размер файла фиксирован.
- **`perchmode=dynfilefs`:** Использует динамически расширяемый файл. Это хороший выбор для **медленных USB-флешек**, так как может снизить износ памяти и потенциально продлить срок службы накопителя, хотя может быть немного медленнее, чем режим `native`.

### Включение и отключение постоянства данных

По умолчанию MiniOS работает в "live"-режиме, при котором все изменения теряются после перезагрузки. Чтобы сохранять изменения, необходимо явно включить постоянство данных.

- **Чтобы включить постоянство:** Добавьте параметр `perch` в командную строку загрузки. Это активирует механизм сохранения изменений в MiniOS.
- **Чтобы отключить постоянство:** Просто не добавляйте параметр `perch`. Если его нет, система будет работать полностью из RAM (или с загрузочного устройства), и изменения сохраняться не будут.

## Настройка ZRAM

MiniOS по умолчанию использует `zram` для создания сжатого пространства подкачки в вашей RAM. Это повышает производительность на системах с ограниченным объемом оперативной памяти, позволяя избежать использования гораздо более медленного swap-файла на диске.

**Автоматическое определение размера:**
- **≥4GB RAM:** 2GB ZRAM
- **1-4GB RAM:** Половина объёма RAM
- **<1GB RAM:** 512MB ZRAM

**Параметры загрузки:**
- **`zramsize=1024`:** Устанавливает размер устройства zram (например, `zramsize=1024` для 1GB). По умолчанию размер определяется автоматически на основе объёма вашей RAM.
- **`zramcomp=lz4`:** Устанавливает алгоритм сжатия (`lzo`, `lzo-rle`, `lz4`, `lz4hc`, `zstd`). `lz4` обычно обеспечивает хороший баланс между скоростью и степенью сжатия.
- **`nozram`:** Полностью отключает ZRAM.

Для большинства пользователей настройки `zram` по умолчанию являются оптимальными. Изменять их рекомендуется только при наличии особых требований и понимании возможных последствий.

## Файловая система и оборудование для хранения данных

- **Используйте быстрый USB-накопитель:** Ключевой аппаратный фактор производительности MiniOS — это скорость вашего USB-устройства. Использование **USB 3.0 или более быстрого SSD-накопителя** обеспечит значительно лучший опыт по сравнению с дешёвой и медленной флешкой USB 2.0.
- **Выбор файловой системы:** Для раздела с постоянством изменений рекомендуется стандартная Linux-файловая система, такая как **ext4** — она обычно обеспечивает наилучшую производительность и надёжность.
