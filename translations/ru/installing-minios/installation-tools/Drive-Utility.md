# Дисковая утилита

Дисковая утилита — это графический инструмент для записи образов MiniOS ISO на USB-накопители.

**Установка:** По умолчанию доступно в MiniOS, для других дистрибутивов смотрите https://github.com/minios-linux/driveutility

## Важно

**Внимание:** Неправильный выбор устройства приведёт к потере данных! Всегда перепроверяйте выбранный диск и делайте резервные копии важных данных.

## Требования к накопителю

### Размер накопителя (для записи MiniOS)

Смотрите [Руководство по совместимости оборудования](/getting-started/Hardware-Compatibility) для подробных системных требований и размеров накопителей.

### Поддерживаемые файловые системы

- **FAT32**: максимальная совместимость
- **NTFS**: совместимость с Windows
- **EXT4**: рекомендуется для Linux

## Запуск Дисковой утилиты

**Через меню приложений:**
1. Откройте меню → Система → «Дисковая утилита»

**Через терминал:**
```bash
driveutility
```

## Создание загрузочного USB-накопителя

1. **Выберите режим «Запись»** в главном окне программы
2. **Выберите ISO-файл MiniOS:**
   - Нажмите кнопку «Обзор» рядом с полем «Источник»
   - Найдите и выберите скачанный файл MiniOS.iso
3. **Выберите целевой диск:**
   - Выберите ваш USB-накопитель из списка устройств
   - Проверьте выбор по размеру и модели
4. **Начните запись:**
   - Нажмите кнопку «Записать»
   - Подтвердите операцию — все данные на накопителе будут удалены
5. **Дождитесь завершения** — процесс займет несколько минут

## Результат и персистентность

В режиме записи выполняется побайтовое копирование образа: структура ISO полностью переносится на выбранное устройство. При этом не создаётся раздел ext4 в неиспользуемом пространстве, не создаётся сессия с сохранением данных и не выполняется развертывание Установщика MiniOS. Выбор файловой системы выше относится к операциям форматирования в Дисковой утилите, а не к разметке, копируемой при записи ISO.

Персистентность включается только при соответствующем параметре загрузки или командной строке ядра, и для этого всё равно требуется подходящее записываемое хранилище. Подробнее смотрите [Режимы загрузки](/using-minios/Boot-Modes) и [Initrd-персистентность](/reference/boot-process/Persistence-Internals) прежде чем полагаться на сохранение изменений.
