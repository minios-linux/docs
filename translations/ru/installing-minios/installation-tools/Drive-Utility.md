# Дисковая утилита

Дисковая утилита — это универсальная GTK-программа для работы с дисками, входящая в состав MiniOS. Она позволяет записывать существующий образ диска, создавать образ с физического устройства, форматировать или полностью очищать устройство. Программа не ограничивается работой только с носителями MiniOS и не является заменой для Установщика MiniOS.

Откройте её через меню приложений в разделе **Система**, или выполните команду:

```bash
driveutility
```

## Безопасность

Запись образа, форматирование и очистка — это операции, приводящие к удалению данных. Перед подтверждением убедитесь, что выбрано правильное устройство по его названию, модели и объёму. Сохраняйте резервные копии важных данных и по возможности отключайте неиспользуемые съёмные накопители.

Смонтированные диски по умолчанию скрыты. Вы можете явно отобразить их, однако Дисковая утилита предупредит о возможном удалении данных, а внутренний модуль попытается размонтировать выбранное устройство и его разделы перед изменениями. Если состояние монтирования неясно или файловая система остаётся смонтированной, операция будет прервана, чтобы не вносить изменения в активную файловую систему.

## Записать образ

**Запись** копирует образ побайтно на выбранное устройство. Если поддерживается, сжатые образы автоматически определяются внутренним модулем.

Обычные сценарии использования: запись ISO-образа MiniOS на USB- или SD-носитель, восстановление ранее созданного полного образа устройства.
Для ISO-образа MiniOS выполняется прямая запись. Копируются разделы ISO и загрузочная структура точно так же, как они сохранены в образе. Это **не** создаёт дополнительный раздел для записи данных, не запускает сессию с сохранением изменений и не выполняет управляемую установку через Установщик MiniOS.

Возможность сохранения изменений после прямой записи зависит от режима загрузки и наличия доступной для записи области в образе. Для создания управляемой структуры разделов или заранее подготовленной сессии используйте [Установщик MiniOS](/installing-minios/MiniOS-Installer).

Пример CLI:

```bash
sudo driveutility-write -s /path/to/minios.iso -t /dev/sdX
```

## Создать образ устройства

**Создать образ** считывает данные с физического устройства в файл-образ. Итоговый файл может быть сохранён как в несжатом виде, так и сжат по мере записи.

Доступные варианты сжатия:

- gzip (`.gz`)
- bzip2 (`.bz2`)
- XZ (`.xz`)
- LZ4 (`.lz4`)
- Zstandard (`.zst`) при наличии установленной поддержки Python zstd

Графическая версия программы может также назначить владельцем итогового файла пользователя рабочего стола, чтобы резервная копия, созданная от имени root, была сразу доступна без смены владельца.
Пример CLI:

```bash
sudo driveutility-read -s /dev/sdX -t /path/to/backup.img -c zstd
```

Расширение, соответствующее выбранному типу сжатия, добавляется автоматически при чтении через командную строку.

## Форматировать устройство

**Форматировать** создаёт на выбранном устройстве новую файловую систему. Доступные типы файловых систем:

- FAT32
- exFAT
- NTFS
- ext4

Вы можете задать метку тома. Для ext4 Дисковая утилита может назначить владельцем корневого каталога выбранного пользователя и группу.

Форматирование не связано с записью ISO-образа MiniOS. Перечисленные здесь файловые системы относятся только к операциям форматирования в Дисковой утилите и не изменяют структуру файловой системы внутри записываемого ISO-образа.

Пример CLI:

```bash
sudo driveutility-format -d /dev/sdX -f ext4 -u 1000 -g 1000 MYDISK
```

## Стереть устройство

**Очистить** выбирает между аппаратными операциями стирания, discard/TRIM и программной перезаписью в зависимости от выбранного устройства и метода.

Доступные внутренние модули:

- **Безопасное стирание** — автоматически выбирает поддерживаемый контроллером метод, если он доступен.
- **ATA Secure Erase / Enhanced Secure Erase** — выполняется через UDisks2 для поддерживаемых SATA/ATA-устройств; неподдерживаемые или «замороженные» устройства отклоняются.
- **NVMe User Data Erase / Cryptographic Erase** — использует NVMe Format NVM только если контроллер поддерживает необходимую функцию.
- **Discard / secure discard** — используется `blkdiscard` если блочное устройство поддерживает discard.
- **Обнуление** — записывает нули с хоста.
- **Случайная перезапись** — записывает случайные данные выбранное количество проходов и может добавить финальный проход с нулями.

Аппаратное безопасное стирание не эквивалентно многократной перезаписи каждого логического блока с хоста. Доступность зависит от прошивки устройства, интерфейсов ядра, UDisks2, `nvme-cli` и `blkdiscard` поддержки.
Для NVMe-устройств Дисковая утилита сохраняет выбранный формат LBA, параметры метаданных и защиты при выполнении Format NVM. Также программа откажет в операциях контроллера, если их область действия может затронуть несколько пространств имён и нельзя гарантировать безопасность для одного пространства.

Примеры:

```bash
sudo driveutility-wipe -d /dev/nvme0n1 -m secure
sudo driveutility-wipe -d /dev/sdX -m discard
sudo driveutility-wipe -d /dev/sdX -p 3 -t random -z
```

Используйте параметры количества проходов и частичного размера только для традиционных методов обнуления или случайной перезаписи. Аппаратное стирание и discard работают по команде устройства, а не по количеству байт, заданному на стороне хоста.

## Инструменты командной строки

Дисковая утилита устанавливает четыре низкоуровневые команды:

| Команда | Назначение |
|---|---|
| `driveutility-write` | Записать на блочное устройство необработанный или поддерживаемый сжатый образ. |
| `driveutility-read` | Создать необработанный или сжатый образ с блочного устройства. |
| `driveutility-format` | Создать на устройстве файловую систему FAT32, exFAT, NTFS или ext4. |
| `driveutility-wipe` | Стереть устройство с помощью контроллера, discard или методов перезаписи. |

Все разрушающие команды следует запускать только после проверки правильности выбранного устройства. Используйте установленные man-страницы и `--help` вывод для получения информации о параметрах, зависящих от версии.

## Дисковая утилита и Установщик MiniOS

Используйте **Дисковая утилита** для стандартных операций с дисками: записи образов, создания образов устройств, форматирования или очистки.

Используйте **Установщик MiniOS** если вам нужна установка с поддержкой MiniOS, с возможностью выбора места, файловой системы, загрузочной схемы, модулей, настроек или создания live-сессии.

Другие способы записи MiniOS на носитель смотрите в разделе [Методы установки](/installing-minios/Installation-Methods). Для сохранения изменений после загрузки см. [Режимы загрузки](/using-minios/Boot-Modes) и [Сессии и сохранение данных](/using-minios/Sessions-and-Persistence).
