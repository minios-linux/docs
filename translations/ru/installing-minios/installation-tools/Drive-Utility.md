# Дисковая утилита

Дисковая утилита — это графический инструмент для записи ISO-образов MiniOS на USB-накопители.

**Установка:** По умолчанию доступна в MiniOS, для других дистрибутивов смотрите https://github.com/minios-linux/driveutility

## Важно

**Внимание:** Неправильный выбор устройства приведёт к потере данных! Всегда тщательно проверяйте выбранный накопитель и делайте резервные копии важных данных.

## Требования к накопителю

### Размер накопителя (для записи MiniOS)

См. [Руководство по совместимости оборудования](/getting-started/Hardware-Compatibility) для подробных системных требований и рекомендуемых размеров накопителей.

### Поддерживаемые файловые системы

- **FAT32**: максимальная совместимость
- **NTFS**: совместимость с Windows
- **EXT4**: рекомендуется для Linux

## Запуск Дисковой утилиты

**Через меню приложений:**
1. Откройте меню → Система → "Дисковая утилита"

**Через терминал:**
```bash
driveutility
```

## Создание загрузочного USB-накопителя

1. **Выберите режим "Запись"** в главном окне программы
2. **Выберите ISO-файл MiniOS:**
   - Нажмите кнопку "Обзор" рядом с полем "Источник"
   - Найдите и выберите загруженный файл MiniOS.iso
3. **Выберите целевой накопитель:**
   - Выберите ваш USB-накопитель из списка устройств
   - Проверьте выбор по размеру и модели
4. **Начните запись:**
   - Нажмите кнопку "Записать"
   - Подтвердите операцию — все данные на накопителе будут удалены
5. **Дождитесь завершения** — процесс займет несколько минут

## Результат и персистентность

Режим записи выполняет прямую запись образа: копируется структура ISO на всё целевое устройство. Не создаётся раздел ext4 в неиспользуемом пространстве, не создаётся сессия сохранения изменений и не выполняется развертывание Установщика MiniOS. Выбор файловой системы выше относится к операциям Дисковой утилиты по форматированию файловой системы, а не к разметке разделов, копируемой при записи ISO.

Персистентность включается только при наличии соответствующей записи в меню загрузки или параметра ядра, и всё равно требует подходящего носителя с возможностью записи. Ознакомьтесь с разделами [Режимы загрузки](/using-minios/Boot-Modes) и [Персистентность в initrd](/reference/boot-process/Persistence-Internals) перед использованием сохранения изменений.
