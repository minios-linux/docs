# dd

`dd` — это универсальная консольная утилита для побитового копирования данных между файлами и устройствами. Чаще всего используется для записи ISO-образов на USB-накопители, создания резервных копий и восстановления данных.

## Важно

**Внимание:** Неправильный выбор устройства приведёт к потере данных! Всегда тщательно проверяйте выбранный диск и делайте резервные копии важных данных.

## Требования к накопителю

### Размер накопителя

См. [Руководство по совместимости оборудования](/getting-started/Hardware-Compatibility) для подробных системных требований и размеров накопителей.

## Подготовка

1. Определите ваш USB-накопитель:
   - **Linux:** `lsblk` или `sudo fdisk -l`
   - **macOS:** `diskutil list`

2. Отмонтируйте накопитель:
   - **Linux:** `sudo umount /dev/sdX*`
   - **macOS:** `sudo diskutil unmountDisk /dev/diskX`

## Создание загрузочного USB-накопителя

**Linux:**
```bash
sudo dd if=MiniOS.iso of=/dev/sdX bs=4M status=progress conv=fsync
```

**macOS:**
```bash
sudo dd if=MiniOS.iso of=/dev/diskX bs=4m
```

**Замените:**
- `MiniOS.iso` — путь к вашему ISO-файлу
- `/dev/sdX` — ваш USB-накопитель (например, `/dev/sdb`)

## Результат и персистентность

`dd` выполняет запись образа "как есть": копирует структуру ISO на всё целевое устройство. Он не создаёт раздел ext4 в неиспользуемом пространстве, не создаёт сессию с сохранением изменений и не выполняет развертывание через Установщик MiniOS.

Персистентность включается только при наличии соответствующей записи загрузки или параметра ядра, и всё равно требует подходящего носителя с возможностью записи. Перед тем как полагаться на сохранение изменений, ознакомьтесь с разделами [Режимы загрузки](/using-minios/Boot-Modes) и [Персистентность initrd](/reference/boot-process/Persistence-Internals).
