# dd

`dd` — это многофункциональная консольная утилита для побитового копирования данных между файлами и устройствами. Чаще всего используется для записи ISO-образов на USB-накопители, создания резервных копий и восстановления данных.

## Важно

**Внимание:** Неправильный выбор устройства приведёт к потере данных! Всегда тщательно проверяйте выбранный диск и сохраняйте важные данные.

## Требования к накопителю

### Размер накопителя

См. [Руководство по совместимости оборудования](/getting-started/Hardware-Compatibility) для подробных системных требований и информации о размерах накопителей.

## Подготовка

1. Определите свой USB-накопитель:
   - **Linux:** `lsblk` или `sudo fdisk -l`
   - **macOS:** `diskutil list`

2. Отмонтируйте накопитель:
   - **Linux:** `sudo umount /dev/sdX*`
   - **macOS:** `sudo diskutil unmountDisk /dev/diskX`

## Создание загрузочного USB-накопителя

**Linux:**
```bash
sudo dd if=MiniOS.iso of=/dev/sdX bs=4M status=progress conv=fsync
```

**macOS:**
```bash
sudo dd if=MiniOS.iso of=/dev/diskX bs=4m
```

**Замените:**
- `MiniOS.iso` — путь к вашему ISO-файлу
- `/dev/sdX` — ваш USB-накопитель (например, `/dev/sdb`)

## Результат и постоянство данных

`dd` выполняет запись образа в «сыром» виде: копирует структуру ISO на всё целевое устройство. Не создаёт раздел ext4 в неиспользуемом пространстве, не формирует сессию с сохранением данных и не выполняет развертывание Установщика MiniOS.

Постоянство данных включается только если это указано в загрузочном меню или параметрах ядра, и всё равно требует подходящего носителя с возможностью записи. См. [Режимы загрузки](/using-minios/Boot-Modes) и [Постоянство через initrd](/reference/boot-process/Persistence-Internals) перед тем как полагаться на сохранение изменений.
