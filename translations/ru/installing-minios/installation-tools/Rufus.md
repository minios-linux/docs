# Rufus

Rufus — это популярная утилита для Windows, которая помогает форматировать и создавать загрузочные USB-накопители.

## Важно

**Внимание:** Неправильный выбор устройства приведёт к потере данных! Всегда внимательно проверяйте выбранный диск и делайте резервные копии важных данных.

См. [Руководство по совместимости оборудования](/getting-started/Hardware-Compatibility) для подробных системных требований и размеров накопителей.

## Установка Rufus

1. **Скачайте Rufus** с [официального сайта](https://rufus.ie/)
2. **Запустите программу** — Rufus не требует установки, это портативное приложение

## Создание загрузочного USB-накопителя

Rufus может создавать MiniOS носители двумя способами. Обычный режим ISO — лучший выбор, если вы хотите, чтобы USB-накопитель оставался обычной записываемой файловой системой и одновременно загрузочным устройством.

### Способ 1: режим ISO

1. **Запустите Rufus** от имени администратора.
2. **Выберите USB-накопитель** в поле **Устройство**.
3. **Выберите ISO-файл MiniOS** с помощью **SELECT**.
4. Когда Rufus спросит, как записать гибридный образ, оставьте **режим ISO-образа**.
5. Выберите подходящую файловую систему. FAT32 обеспечивает наибольшую совместимость с прошивками; NTFS может ограничить прямую загрузку по UEFI на некоторых системах.
6. Нажмите **START** и подтвердите форматирование выбранного устройства.

В режиме ISO файлы MiniOS извлекаются на обычную файловую систему. После установки оставшееся свободное место можно использовать для хранения обычных файлов. Обычно это наиболее удобная структура Rufus для портативного MiniOS накопителя.

### Способ 2: режим DD

Выбирайте **режим DD-образа** только если вам нужно получить точную поблочную копию опубликованного ISO. Rufus тогда воспроизводит структуру ISO на всём устройстве, аналогично `dd`, Etcher или режиму записи Дисковой утилиты.

Режим DD прост и предсказуем, но устройство больше не будет иметь привычную однородную файловую систему, как у обычной флешки.

## Результат и персистентность

В режиме ISO создаются файловые MiniOS носители на обычной записываемой файловой системе. В режиме DD создаются носители в виде необработанного образа. Ни один из режимов не является Установщиком MiniOS, и ни один не создаёт автоматически постоянную сессию.

Персистентность MiniOS может использовать подходящее записываемое хранилище на файловой установке Rufus, если выбран режим постоянной загрузки. См. [Режимы загрузки](/using-minios/Boot-Modes) и [Управление сессиями](/using-minios/Sessions-and-Persistence).
