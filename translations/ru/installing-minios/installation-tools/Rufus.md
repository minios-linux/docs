# Rufus

Rufus — популярная утилита для Windows, которая помогает форматировать и создавать загрузочные USB-накопители.

## Важно

**Внимание:** Неправильный выбор устройства приведёт к потере данных! Всегда внимательно проверяйте выбранный диск и делайте резервные копии важных данных.

## Требования к накопителю

### Размер накопителя

Подробные системные требования и размеры накопителей смотрите в [Руководстве по совместимости оборудования](/getting-started/Hardware-Compatibility).

## Установка Rufus

1. **Скачайте Rufus** с [официального сайта](https://rufus.ie/)
2. **Запустите программу** — Rufus не требует установки, это портативное приложение

## Создание загрузочного USB-накопителя

Rufus может создавать загрузочные носители MiniOS двумя разными способами. Обычный режим ISO — лучший выбор, если вы хотите, чтобы USB-накопитель оставался обычной записываемой файловой системой, а также загрузочным устройством.

### Метод 1: режим ISO

1. **Запустите Rufus** от имени администратора.
2. **Выберите USB-накопитель** в поле **Устройство**.
3. **Выберите ISO-файл MiniOS** с помощью **ВЫБРАТЬ**.
4. Когда Rufus спросит, как записывать гибридный образ, оставьте **режим ISO-образа**.
5. Выберите подходящую файловую систему. FAT32 обеспечивает наибольшую совместимость с прошивками; NTFS может ограничить прямую загрузку по UEFI на некоторых системах.
6. Нажмите **СТАРТ** и подтвердите форматирование выбранного устройства.

В режиме ISO файлы MiniOS извлекаются на обычную файловую систему. После установки оставшееся свободное место можно использовать для обычных файлов. Обычно это наиболее удобная схема Rufus для портативного USB-накопителя MiniOS.

### Метод 2: режим DD

Выбирайте **режим DD-образа** только если вам нужен точный поблочный клон опубликованного ISO. Rufus тогда воспроизводит структуру ISO на всём устройстве, аналогично `dd`, Etcher или режиму записи Дисковой утилиты.

Режим DD прост и предсказуем, но устройство больше не имеет привычной единой записываемой файловой системы, ожидаемой от обычной флешки.

## Результат и сохранение данных

Режим ISO создает файловые MiniOS-носители на обычной записываемой файловой системе. Режим DD создает носители в виде необработанного образа. Ни один из этих режимов не является развертыванием через Установщик MiniOS, и ни один из них не создает автоматически постоянную сессию.

Постоянство MiniOS может использовать подходящее записываемое хранилище на файловой установке Rufus, если выбран режим постоянной загрузки. Подробнее см. [Режимы загрузки](/using-minios/Boot-Modes) и [Управление сессиями](/using-minios/Sessions-and-Persistence).
