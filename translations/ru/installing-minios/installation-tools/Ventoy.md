# Ventoy

Ventoy — это популярный инструмент для создания загрузочных USB-накопителей, который позволяет хранить несколько ISO-файлов на одном устройстве и загружаться с любого из них.

## Важно

**Внимание:** Неправильный выбор устройства приведёт к потере данных! Всегда тщательно проверяйте выбранный диск и делайте резервные копии важных данных.

Текущая интеграция MiniOS поддерживает режим Ventoy **по умолчанию**, включая прямые образы с сохранением данных в BIOS и UEFI. Старые образы MiniOS могут потребовать **режим GRUB2**; используйте этот режим, если старый образ не может обнаружить свой источник в обычном режиме. Суффикс `VTGRUB2` имени файла может принудительно включить режим GRUB2 для такого образа. Для актуальных образов это не обязательно.

## Требования к накопителю

### Размер диска

Оставьте место для файлов ISO, других данных и планируемого хранилища для постоянных данных. Зарезервированное пространство и объем persistent-образа для Ventoy настраиваются отдельно. Подробнее см. [Аппаратная совместимость](/getting-started/Hardware-Compatibility) для системных требований.

## Установка Ventoy

### Способ 1: Стандартная установка

1. **Скачайте Ventoy** с [официального сайта](https://www.ventoy.net/)
2. **Запустите установщик Ventoy** и выберите ваш USB-накопитель
3. **Установите Ventoy** на накопитель (все данные будут удалены)
4. **Скопируйте ISO-файл MiniOS** в корневую папку USB-накопителя

Это создаёт мультизагрузочный носитель с ISO-файлами: Ventoy сохраняет ISO как файл на своём разделе данных и отображает его при загрузке. Это не запись образа MiniOS напрямую и не развёртывание через Установщик MiniOS.

### Метод 2: Установка с отдельным разделом для данных (рекомендуется)

1. **Скачайте Ventoy** с [официального сайта](https://www.ventoy.net/)
2. **Запустите установщик Ventoy** и выберите ваш USB-накопитель
3. **Включите опцию «Зарезервировать место»** во время установки, чтобы оставить нераспределённое пространство в конце накопителя
4. **Установите Ventoy** на накопитель
5. **Скопируйте ISO-файл MiniOS** в корневую папку USB-накопителя
6. **Создайте раздел ext4** в зарезервированном пространстве с меткой `persistence` с помощью редактора разделов

Это создаёт возможное место для хранения данных, но сам по себе раздел не включает поддержку постоянства и не создаёт сессию.

## Интеграция с MiniOS

MiniOS обнаруживает ISO, предоставленный Ventoy, отдельно от доступного для записи хранилища. Существуют две модели сохранения данных; выберите одну из них осознанно.

### Обычные сеансы MiniOS

Если не выбран бэкенд плагина постоянства Ventoy, стандартные **Запустить MiniOS** запросы на вход `perchdir=resume`. MiniOS может использовать раздел на том же диске `persistence` или его `minios/changes/` хранилище на разделе данных Ventoy. Для схемы с разделом данных включите поддержку перемонтирования Linux для Ventoy в `/ventoy/ventoy.json`:

```json
{
  "control": [{ "VTOY_LINUX_REMOUNT": "1" }]
}
```

Вносите эти изменения в существующую конфигурацию, не удаляя другие плагины. Всё равно требуется подходящее хранилище с возможностью записи. На FAT32/NTFS/exFAT при запуске по умолчанию используется DynBlk, если доступно, иначе — DynFileFS. Session Manager, нумерованные сеансы, шифрование и поддерживаемое сохранение сессий RAM работают по обычным правилам MiniOS. Загрузка без запроса на постоянство останется временной.

### Ventoy Плагин постоянства

В качестве альтернативы можно связать ISO с **образом постоянства ext4**, используя плагин постоянства Ventoy. Например, уже созданный образ по адресу `/ventoy/minios.dat`можно выбрать для `/ISO/MiniOS.iso`:

```json
{
  "persistence": [
    {
      "image": "/ISO/MiniOS.iso",
      "backend": "/ventoy/minios.dat"
    }
  ]
}
```

Пути указываются относительно корня раздела данных Ventoy. Создайте образ ext4 с помощью инструментов для создания образов постоянства от Ventoy и выберите его при загрузке; простое размещение файла `.dat`на диске не активирует его. MiniOS использует выбранный в Ventoy бэкенд, а не любое устройство с подходящей меткой.

Этот образ содержит одну среду с постоянством, с `changes/`и для OverlayFS, `workdir/`. Нумерованных сессий MiniOS он не содержит. Чтобы использовать другую среду, выберите другой бэкенд в Ventoy. Session Manager и `minios-session`недоступны, `perchdir`выбор сессии игнорируется, а `perchtoram`не может скопировать этот upper в RAM. Системное `toram`остается возможным, но не убирает зависимость от образа постоянства.

При первом использовании записывается формат union. Повторное использование образа с другим union-бэкендом, недоступным образом, не-ext4 образом или при ошибке активации на запись вызывает предупреждение и создает новый upper RAM. **Запустить без сохранения**не открывает образ. Подробнее см. [Режимы загрузки](/using-minios/Boot-Modes) и [Внутренняя реализация постоянства](/reference/boot-process/Persistence-Internals).

## Использование MiniOS с Ventoy

### Загрузка

После установки Ventoy и копирования ISO-файла MiniOS на диск:

1. **Загрузитесь с USB-накопителя** - выберите его в BIOS/UEFI
2. **Выберите MiniOS** из списка доступных ISO-файлов в меню Ventoy
3. Выберите обычный режим для текущего образа MiniOS; для старых образов используйте режим, указанный в их документации
4. **Дождитесь загрузки MiniOS**

После запуска проверьте статус сохранения данных, прежде чем полагаться на сохранённые изменения. В обычных сессиях используйте `sudo minios-session status`. Для Persistence Plugin проверьте `/run/initramfs/minios-persistence/boot-state` от имени root: при успешной активации backend записывает `mode=ventoy` и `boot_level=ok`. Держите накопитель подключённым, пока используется его ISO- или persistence-образ.
