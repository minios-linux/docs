# Ventoy

Ventoy — это популярный инструмент для создания загрузочных USB-накопителей, который позволяет хранить несколько ISO-файлов на одном устройстве и загружаться с любого из них.

## Важно

**Внимание:** Неправильный выбор устройства приведёт к потере данных! Всегда внимательно проверяйте выбранный диск и делайте резервные копии важных данных.

**Требования к режиму загрузки:** Чтобы MiniOS корректно работал с Ventoy, ОБЯЗАТЕЛЬНО выберите **режим GRUB2** при загрузке или переименуйте ваш ISO-файл с `VTGRUB2` суффиксом (например, `minios-standard-amd64_VTGRUB2.iso`) для автоматического принудительного выбора режима GRUB2.

## Требования к накопителю

### Размер накопителя

См. [Руководство по совместимости оборудования](/getting-started/Hardware-Compatibility) для подробных системных требований и рекомендуемых размеров накопителей.

## Установка Ventoy

### Способ 1: Стандартная установка

1. **Скачайте Ventoy** с [официального сайта](https://www.ventoy.net/)
2. **Запустите установщик Ventoy** и выберите ваш USB-накопитель
3. **Установите Ventoy** на накопитель (все данные будут удалены)
4. **Скопируйте ISO-файл MiniOS** в корневую папку USB-накопителя

Это создаёт мультизагрузочный носитель с ISO-файлами: Ventoy сохраняет ISO как файл на своём разделе данных и отображает его при загрузке. Это не запись образа MiniOS напрямую и не развёртывание через Установщик MiniOS.

### Способ 2: Установка с отдельным разделом для данных (рекомендуется)

1. **Скачайте Ventoy** с [официального сайта](https://www.ventoy.net/)
2. **Запустите установщик Ventoy** и выберите ваш USB-накопитель
3. **Включите опцию «Зарезервировать место»** при установке, чтобы создать дополнительный раздел
4. **Установите Ventoy** на накопитель
5. **Скопируйте ISO-файл MiniOS** в корневую папку USB-накопителя
6. **Создайте раздел ext4** в зарезервированном пространстве с меткой `persistence`

Это создаёт возможное место для хранения данных с сохранением, однако создание раздела само по себе не включает функцию сохранения и не создаёт пользовательскую сессию.

## Интеграция с MiniOS

MiniOS поддерживает обнаружение ISO-файла, предоставленного Ventoy. Обнаружение источника и выбор места для сохранения независимы друг от друга; сам Ventoy не включает сохранение MiniOS.

### Сохранение данных (Persistence)

Сохранение включается только если это указано в загрузочном меню или через параметры ядра. Для активации требуется совместимый раздел с возможностью записи и рабочая сессия; стандартная установка Ventoy не гарантирует их автоматическое создание. См. [Режимы загрузки](/using-minios/Boot-Modes) и [Сохранение данных через initrd](/reference/boot-process/Persistence-Internals) перед использованием сохранённых изменений.

## Использование MiniOS с Ventoy

### Загрузка

После установки Ventoy и копирования ISO-файла MiniOS на накопитель:

1. **Загрузитесь с USB-накопителя** - выберите его в BIOS/UEFI
2. **Выберите MiniOS** из списка доступных ISO-файлов в меню Ventoy
3. **ВАЖНО: выберите режим GRUB2** при появлении запроса от Ventoy
4. **Дождитесь загрузки MiniOS**

### **Требования к режиму загрузки Ventoy**

**Чтобы MiniOS работал корректно:**
- **режим GRUB2** - требуется для правильной работы MiniOS

**Альтернативное решение:**
- Добавьте суффикс `VTGRUB2` к имени ISO-файла (например, `minios-5.0.0-standard-amd64_VTGRUB2.iso`)
- Это заставит Ventoy автоматически использовать режим GRUB2 без дополнительного запроса
