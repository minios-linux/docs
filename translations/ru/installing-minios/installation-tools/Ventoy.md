# Ventoy

Ventoy — это популярный инструмент для создания загрузочных USB-накопителей, который позволяет хранить несколько ISO-файлов на одном устройстве и загружаться с любого из них.

## Важно

**Внимание:** Неправильный выбор устройства приведёт к потере данных! Всегда тщательно проверяйте выбранный диск и делайте резервные копии важных данных.

**Требование к режиму загрузки:** Для корректной работы MiniOS с Ventoy ОБЯЗАТЕЛЬНО выберите **режим GRUB2** при загрузке или переименуйте ваш ISO-файл, добавив суффикс `VTGRUB2` (например, `minios-standard-amd64_VTGRUB2.iso`), чтобы автоматически принудительно включить режим GRUB2.

## Требования к накопителю

### Размер накопителя

См. [Руководство по совместимости оборудования](/getting-started/Hardware-Compatibility) для подробных системных требований и размеров накопителей.

## Установка Ventoy

### Метод 1: Стандартная установка

1. **Скачайте Ventoy** с [официального сайта](https://www.ventoy.net/)
2. **Запустите установщик Ventoy** и выберите ваш USB-накопитель
3. **Установите Ventoy** на накопитель (все данные будут удалены)
4. **Скопируйте ISO-файл MiniOS** в корневую папку USB-накопителя

Это создаёт мультизагрузочный носитель с ISO-файлами: Ventoy сохраняет ISO как файл на раздел данных и отображает его при загрузке. Это не запись образа MiniOS в "сыром" виде и не развертывание через Установщик MiniOS.

### Метод 2: Установка с отдельным разделом данных (рекомендуется)

1. **Скачайте Ventoy** с [официального сайта](https://www.ventoy.net/)
2. **Запустите установщик Ventoy** и выберите ваш USB-накопитель
3. **Включите опцию "Reserve Space"** при установке для создания дополнительного раздела
4. **Установите Ventoy** на накопитель
5. **Скопируйте ISO-файл MiniOS** в корневую папку USB-накопителя
6. **Создайте раздел ext4** в зарезервированном пространстве с меткой `persistence`

Это предоставляет возможное место для сохранения данных, но создание раздела само по себе не включает постоянство и не создаёт сессию.

## Интеграция с MiniOS

MiniOS поддерживает обнаружение ISO, предоставленного Ventoy. Поиск источника и выбор места для сохранения данных выполняются отдельно; сам Ventoy не включает постоянство MiniOS.

### Постоянство

Постоянство включается только при наличии соответствующей записи загрузки или параметра ядра. Для активации требуется совместимое место для записи и рабочая сессия; стандартная установка Ventoy не гарантирует их автоматическое создание. Ознакомьтесь с разделами [Режимы загрузки](/using-minios/Boot-Modes) и [Постоянство initrd](/reference/boot-process/Persistence-Internals) перед тем, как полагаться на сохранение изменений.

## Использование MiniOS с Ventoy

### Загрузка

После установки Ventoy и копирования ISO-файла MiniOS на накопитель:

1. **Загрузитесь с USB-накопителя** — выберите его в BIOS/UEFI
2. **Выберите MiniOS** из списка доступных ISO-файлов в меню Ventoy
3. **ВАЖНО: Выберите режим GRUB2** при появлении запроса от Ventoy
4. **Дождитесь загрузки MiniOS**

### **Требования к режиму загрузки Ventoy**

**Для корректной работы MiniOS:**
- **Режим GRUB2** — обязателен для правильной работы MiniOS

**Альтернативное решение:**
- Добавьте суффикс `VTGRUB2` к имени ISO-файла (например, `minios-5.0.0-standard-amd64_VTGRUB2.iso`)
- Это заставит Ventoy автоматически использовать режим GRUB2 без запроса
