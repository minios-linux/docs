# Balena Etcher

Balena Etcher — удобная кроссплатформенная программа для записи ISO-образов на USB-накопители. Подходит для Windows, macOS и Linux.

## Важно

**Внимание:** Неправильный выбор устройства приведёт к потере данных! Всегда тщательно проверяйте выбранный диск и делайте резервные копии важных данных.

## Требования к накопителю

### Размер накопителя

См. [Руководство по совместимости оборудования](/getting-started/Hardware-Compatibility) для подробных системных требований и размеров накопителей.

## Подготовка

1. Скачайте Balena Etcher с [официального сайта](https://www.balena.io/etcher/)
2. Установите программу в вашей ОС
3. Подключите USB-накопитель

## Создание загрузочного USB-накопителя

1. Запустите Balena Etcher
2. Выберите ISO-образ MiniOS:
   - Нажмите «Flash from file»
   - Укажите путь к ISO-файлу
3. Выберите целевой USB-накопитель:
   - Нажмите «Select target»
   - Проверьте модель и размер устройства
4. Начните запись:
   - Нажмите «Flash!»
   - Дождитесь завершения процесса (5–15 минут)

## Результат и персистентность

Etcher выполняет низкоуровневую запись образа: он копирует структуру ISO на всё целевое устройство. Программа не создаёт раздел ext4 в неиспользуемом пространстве, не запускает сессию с сохранением изменений и не выполняет развертывание через Установщик MiniOS.

Персистентность включается только при наличии соответствующей записи загрузки или параметра ядра, и всё равно требует подходящего носителя с возможностью записи. Перед использованием сохранения изменений ознакомьтесь с разделами [Режимы загрузки](/using-minios/Boot-Modes) и [Персистентность initrd](/reference/boot-process/Persistence-Internals).
