# Balena Etcher

Balena Etcher — удобная кроссплатформенная программа для записи ISO-образов на USB-накопители. Подходит для Windows, macOS и Linux.

## Важно

**Внимание:** Неправильный выбор устройства приведёт к потере данных! Всегда перепроверяйте выбранный накопитель и делайте резервные копии важных данных.

## Требования к накопителю

### Размер накопителя

См. [Руководство по совместимости оборудования](/getting-started/Hardware-Compatibility) для подробных системных требований и размеров накопителей.

## Подготовка

1. Скачайте Balena Etcher с [официального сайта](https://www.balena.io/etcher/)
2. Установите программу в вашей операционной системе
3. Подключите USB-накопитель

## Создание загрузочного USB-накопителя

1. Запустите Balena Etcher
2. Выберите ISO-образ MiniOS:
   - Нажмите «Flash from file»
   - Укажите путь к ISO-файлу
3. Выберите целевой USB-накопитель:
   - Нажмите «Select target»
   - Проверьте модель устройства и его объём
4. Начните запись:
   - Нажмите «Flash!»
   - Дождитесь завершения процесса (5–15 минут)

## Результат и персистентность

Etcher выполняет запись образа на низком уровне: копирует структуру ISO на весь целевой накопитель. Программа не создаёт раздел ext4 в неиспользуемом пространстве, не настраивает сессию с сохранением данных и не выполняет развёртывание Установщика MiniOS.

Персистентность включается только при соответствующем параметре загрузки или командной строке ядра и требует подходящего накопителя с возможностью записи. См. [Режимы загрузки](/using-minios/Boot-Modes) и [Персистентность через initrd](/reference/boot-process/Persistence-Internals) перед использованием сохранения изменений.
