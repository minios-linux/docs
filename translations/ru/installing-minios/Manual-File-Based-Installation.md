# Ручная установка на основе файловой системы

Этот метод установки MiniOS копирует системные файлы на обычную файловую систему и устанавливает загрузчик туда, вместо поблочной записи ISO-образа.
Оставшееся пространство на файловой системе остаётся доступным для обычных файлов, поэтому устройство можно продолжать использовать как обычный USB-накопитель, а также как загрузочное устройство MiniOS.

Этот способ особенно полезен, если вам нужен прямой доступ к файлам MiniOS, обычное хранение данных на том же разделе или возможность записи для постоянных сессий. Используется загрузчик SYSLINUX и предназначен для Windows и Linux.

## Важно

**Внимание:** Эта процедура переразбивает и форматирует выбранное устройство. Это действие уничтожает все данные на устройстве, а не только видимые файлы. Сделайте резервную копию важных данных и проверьте точный путь к устройству, модель, объем, раздел и точку монтирования перед запуском `fdisk`, `mkfs` или `bootinst`. По возможности отключите другие съемные накопители.

## Требования к накопителю

### Размер накопителя

См. [Руководство по совместимости оборудования](/getting-started/Hardware-Compatibility) для подробных системных требований и размеров накопителей.

### Технические требования

- **Файловые системы**: FAT32, NTFS, ext2/3/4, Btrfs
- **Схема разделов**: MBR
- **Загрузка в режиме EFI**: При использовании файловых систем NTFS, exFAT или ext2/3/4 загрузка в режиме EFI может быть недоступна. Для поддержки EFI рекомендуется FAT32.

## Создание загрузочного USB-накопителя

### Шаг 1: Подготовьте накопитель

**Windows:**
1. Откройте "Управление дисками" (`Win+R`, затем `diskmgmt.msc`)
2. Проверьте USB-устройство по номеру диска, модели и объему. Не продолжайте, если есть сомнения в деталях.
3. Щелкните правой кнопкой мыши по его разделу и выберите "Удалить том"
4. Щелкните правой кнопкой по неразмеченной области и выберите "Создать простой том"
5. Выберите файловую систему: FAT32 (рекомендуется) или NTFS

**Linux:**

Устанавливайте `TARGET_DISK` и `TARGET_PARTITION` только после проверки модели и объема устройства в `lsblk`. Запись `fdisk` заменяет таблицу разделов на всем целевом диске. Выполните только одну команду `mkfs` для нужной файловой системы.

```bash
lsblk -o NAME,PATH,SIZE,FSTYPE,LABEL,MOUNTPOINTS,MODEL
TARGET_DISK=/dev/sdX
TARGET_PARTITION=/dev/sdX1
lsblk -o NAME,PATH,SIZE,FSTYPE,LABEL,MOUNTPOINTS,MODEL "$TARGET_DISK"

# Create new MBR partition table
sudo fdisk "$TARGET_DISK"
# In fdisk: o (new table), n (new partition), p (primary), a (bootable), w (write)

# Verify the new partition, then create one filesystem
lsblk -o NAME,PATH,SIZE,FSTYPE,LABEL,MOUNTPOINTS,MODEL "$TARGET_DISK"
sudo mkfs.vfat -F 32 "$TARGET_PARTITION"  # For FAT32
# Or: sudo mkfs.ext4 "$TARGET_PARTITION"  # For ext4
```

### Шаг 2: Извлечение и копирование файлов

**Монтирование ISO:**

*Windows:*
- Щелкните правой кнопкой мыши по ISO-файлу и выберите "Подключить"

*Linux:*
```bash
sudo mkdir /mnt/minios-iso
sudo mount -o loop MiniOS.iso /mnt/minios-iso

TARGET_PARTITION=/dev/sdX1
sudo mkdir /mnt/minios-target
sudo mount "$TARGET_PARTITION" /mnt/minios-target
findmnt --mountpoint /mnt/minios-target
```

**Копирование файлов:**
1. **Найдите папку `/minios/`** в смонтированном ISO
2. **Скопируйте всю папку `/minios/`** в корень USB-накопителя

В Linux целевой корень в приведенном выше примере — это `/mnt/minios-target`. Перед копированием файлов убедитесь, что `findmnt --mountpoint /mnt/minios-target` показывает именно тот раздел, который выбран на Шаге 1.

### Шаг 3: Установка загрузчика

Перейдите в папку `/minios/boot/syslinux/` на накопителе и запустите установщик:

`bootinst` записывает загрузочный код на диск, определяя его по расположению установщика. Прочитайте [Устранение неполадок](/maintenance-and-recovery/Troubleshooting) перед изменением загрузочного кода и не запускайте установщик, пока не убедитесь в правильности устройства и точки монтирования.

**Windows:**
- Откройте проверенный USB-накопитель по точной букве диска, перейдите в `minios\boot\syslinux` и запустите `bootinst.bat` **от имени администратора**.

**Linux:**
```bash
TARGET_MOUNT=/mnt/minios-target
findmnt --mountpoint "$TARGET_MOUNT"
lsblk -o NAME,PATH,SIZE,FSTYPE,LABEL,MOUNTPOINTS,MODEL
cd "$TARGET_MOUNT/minios/boot/syslinux"
chmod +x bootinst.sh
sudo ./bootinst.sh
```

Не используйте подстановочные знаки для точки монтирования. Скрипт определяет целевой диск по своему расположению и записывает загрузочный код именно на этот диск.

## Результат и постоянство

Эта процедура создает файловую live-установку, размещая дерево `minios/` и загрузчик на обычной файловой системе. Это не поблочная запись ISO, не мультизагрузка с ISO-файлом и не развертывание через Установщик MiniOS.

Выбранная файловая система влияет на то, какие механизмы постоянства могут работать, но не включает постоянство автоматически и не гарантирует создание сессии. Постоянство включается только при наличии соответствующей записи в меню загрузки или параметра ядра, а для активации все равно требуется подходящее хранилище с возможностью записи. Перед использованием сохранения изменений ознакомьтесь с разделами [Режимы загрузки](/using-minios/Boot-Modes) и [Постоянство initrd](/reference/boot-process/Persistence-Internals).
