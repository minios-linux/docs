# MiniOS Configurator

MiniOS Configurator — это графический редактор настроек MiniOS `live-config`. Он
проверяет изменения и записывает конфигурацию для последующей загрузки. Текущая система при этом не изменяется напрямую.

## Запуск конфигуратора

Откройте MiniOS Configurator через меню приложений или выполните команду:

```bash
minios-configurator
```

Целевой файл по умолчанию — `/etc/live/config.conf`. Чтобы редактировать другой обычный файл,
укажите его путь:

```bash
minios-configurator /path/to/config.conf
```

Для сохранения требуется аутентификация через PolicyKit. Символические ссылки и не обычные файлы-цели
не поддерживаются.

## Конфигурация носителя и среды выполнения

MiniOS может читать конфигурацию из двух мест:

- `minios/config.conf` и `minios/config.conf.d/*.conf` на загрузочном носителе
- `/etc/live/config.conf` и `/etc/live/config.conf.d/*.conf` в корневой
  файловой системе во время работы

Configurator редактирует только выбранный файл. Если путь не указан, редактируется
файл среды выполнения `/etc/live/config.conf`; файл на носителе напрямую не открывается. MiniOS синхронизирует более новую конфигурацию между файловой системой среды выполнения
и доступным для записи носителем MiniOS при загрузке. На носителях только для чтения изменения среды выполнения не сохраняются, а постоянная конфигурация среды выполнения может оставаться независимой от копии на носителе.

Для каждой опции параметры ядра имеют приоритет над конфигурационными файлами,
а конфигурация на носителе — над конфигурацией в корневой файловой системе.
Используйте `-i`, чтобы наложить распознанные параметры из текущей командной строки ядра в редакторе:

```bash
minios-configurator --inherit-cmdline /etc/live/config.conf
```

Выбранный файл останется целью для сохранения. Неизвестные параметры ядра игнорируются.

## Когда применяются настройки

Каждый элемент управления указывает, когда он используется. Сохранение никогда не применяет настройку к текущей сессии.

### Применяются после перезагрузки

Имя хоста, локаль, часовой пояс, клавиатура, целевой режим загрузки, выбор сервисов, режим модулей, обработка пользовательских директорий на носителе, параметры отладки и экспорт логов читаются при следующей загрузке. Перезагрузите систему после сохранения, чтобы применить их.

### Используются только для новой сессии

Создание аккаунта, пароли пользователя и root, `noroot`, политика sudo и PolicyKit,
политика SSH и XRDP, доступ к X11, подсказки к паролям и блокировка экрана — одноразовые
настройки. В постоянной сессии обычно фиксируются завершённые компоненты `live-config`
в каталоге `/var/lib/live/config/`, поэтому изменение этих значений и перезагрузка
той же сессии не создаёт заново аккаунт или состояние безопасности. Чтобы применить их как начальные настройки, начните новую сессию.

Профили безопасности — это предустановки редактора. Имя профиля не сохраняется; сохраняются отдельные параметры безопасности, которые остаются доступными для редактирования.

## Пользовательские директории и постоянство

Связывание (symlink) и bind-монтирование пользовательских директорий взаимно исключают друг друга. Оба варианта используют существующий доступный для записи локальный носитель данных MiniOS и безопасный путь относительно носителя. Они недоступны при использовании `toram`, `toram=full` или `toram=trim`, и MiniOS не объединяет автоматически две заполненные директории.

`perchmode` и `perchsize` — это параметры загрузки initramfs, а не настройки Configurator. Configurator не создаёт, не разблокирует, не изменяет размер и не восстанавливает контейнер постоянства. Для зашифрованного постоянства он только сообщает, присутствует ли маркер шифрования initramfs.

## Поведение при сохранении

В обзоре отображаются только изменённые значения, а пароли скрываются. При сохранении обновляются только изменённые ключи, при этом сохраняются комментарии, порядок, неизвестные ключи, права владельца, разрешения и расширенные атрибуты. Запись происходит атомарно.

Полную справку по переменным и параметрам загрузки смотрите в
[Configuration file](/configuration/Configuration-File.md),
[Boot parameters](/configuration/Boot-Parameters.md) и
[live-config](/configuration/live-config.md).
