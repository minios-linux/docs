# Параметры загрузки

## Как использовать параметры загрузки

Параметры загрузки позволяют настраивать запуск MiniOS. Разделяйте параметры пробелами в командной строке ядра.

### Syslinux

- Нажмите <kbd>Esc</kbd> во время загрузки MiniOS, чтобы открыть меню загрузки.
- Нажмите <kbd>Tab</kbd> для редактирования параметров загрузки.
- Введите параметры и нажмите <kbd>Enter</kbd> для запуска.

### GRUB

- Нажмите <kbd>E</kbd> в меню GRUB.
- Отредактируйте параметры загрузки в конце командной строки.
- Нажмите <kbd>F10</kbd> для загрузки с новыми настройками.

## Параметры загрузки

Столбец "Применение" различает параметры, которые обычно принимаются при каждой загрузке, и настройки учётной записи, предназначенные для первоначальной настройки. При использовании постоянства компоненты live-config обычно запускаются только один раз; см. [live-config](/configuration/live-config.md).

Эта таблица служит краткой справкой. Приоритет источников и допустимые формы `from=` определены в разделе [Обнаружение системы в initrd](/configuration/Initrd-System-Discovery.md), фильтрация модулей — в [Загрузка модулей initrd](/configuration/Initrd-Module-Loading.md), выбор постоянства — в [Постоянство в initrd](/configuration/Initrd-Persistence.md), а поддерживаемые комбинации — в [Режимы загрузки](/configuration/Boot-Modes.md).

| Параметр | Применение | Описание | Пример |
|---|---|---|---|
| `from` | Каждая загрузка | Загружает данные MiniOS из каталога, поддерживаемого устройства или ISO. Формы UUID, PARTUUID и by-id не обрабатываются. Буквальный URL **`http://` only** имеет приоритет над `ip=` и запускает [сетевую загрузку](/installation/Network-Boot.md) через httpfs2. | `from=/minios/`<br>`from=/Downloads/minios.iso`<br>`from=http://domain.com/minios.iso`<br>`from=/dev/sr0/minios`<br>`from=/dev/disk/by-label/MyFlash/minios`<br>`from=askdisk`<br>`from=askdisk:customdir` |
| `load` | Каждая загрузка | Оставляет кандидаты `.sb`, путь которых соответствует нефиксированному расширенному регулярному выражению; запятые заменяются на альтернативу, а целый возрастающий числовой диапазон имеет специальное расширение. Также фильтрует `toram=trim`. Может исключить основные или модуль ядра и сделать систему незагружаемой. | `load=00-core`<br>`load=core,kernel,firmware`<br>`load=00,01,02`<br>`load=00-03` |
| `noload` | Каждая загрузка | Исключает кандидаты, путь которых соответствует нефиксированному расширенному регулярному выражению, включая из `toram=trim`; применяется после `load` и может исключить основные или модуль ядра. | `noload=05-xfce-apps`<br>`noload=xfce-apps,firefox`<br>`noload=05,06`<br>`noload=04-06` |
| `bext` | Каждая загрузка | Устанавливает расширение бандла. По умолчанию: `sb`. Координация с ядром всё равно использует буквальные имена `.sb`, поэтому пользовательское расширение не может координировать модуль `01-kernel`. | `bext=mymod` |
| `timing` | Каждая загрузка | Включает вывод времени запуска. | `timing` |
| `union` | Каждая загрузка | Выбирает файловую систему union. | `union=aufs`<br>`union=overlayfs` |
| `ip` | Каждая загрузка | Статический адрес для ранней загрузки по сети. Формат: `<client-ip>:<server-ip>:<gateway-ip>:<netmask>[:<port>]` (по умолчанию порт PXE HTTP **7529**). Буквальный `from=http://...` имеет приоритет над `ip=` и использует его поля адресации; иначе любое непустое значение `ip=` принудительно скачивает данные PXE и пропускает локальные носители. Это не конфигурация NetworkManager для сессии. См. [Сетевая загрузка](/installation/Network-Boot.md). | `ip=192.168.1.10:192.168.1.1:192.168.1.1:255.255.255.0` |
| `cache` | Каждая загрузка | Размер кэша httpfs в MiB для сетевой загрузки HTTP ISO (`from=http://…`). См. [Сетевая загрузка](/installation/Network-Boot.md). | `cache=512` |
| `rd.break` | Каждая загрузка | Открывает отладочную оболочку в конце стадии initramfs. | `rd.break` |
| `perchdir` | Каждая загрузка | Выбирает номер сессии постоянства или действие: `resume`, `new` или `ask`. Несуществующий числовой селектор может использовать значение по умолчанию из метаданных; он не резервирует и не создаёт этот номер. Устройство/путь или форма `askdisk` выбирает другое место для постоянства. Для пользовательского пути используйте суффикс, разделённый двоеточием. Без параметра постоянства MiniOS стартует "чисто". | `perchdir=1`<br>`perchdir=resume`<br>`perchdir=new`<br>`perchdir=ask`<br>`perchdir=/dev/sda1/changes`<br>`perchdir=/dev/disk/by-label/MyFlash/changes`<br>`perchdir=askdisk`<br>`perchdir=askdisk:customdir` |
| `perchsize` | Каждая загрузка | Размер контейнера для `dynfilefs`, `raw` и `luks`; не применяется к `native` или `squashfs`. Число или значение `M`/`MB` выделяется в MiB; `G`/`GB` и `T`/`TB` преобразуются в 1000 и 1 000 000 MiB. Лимит — 1 000 000 MiB, дополнительно ограничивается доступным пространством после `perchreserve`. Session Manager ограничивает raw и LUKS-файлы 4000 MiB на FAT32; initrd LUKS применяет это ограничение, но запрос на слишком большой raw-файл initrd может завершиться ошибкой, а не быть уменьшен. Новые raw и LUKS-контейнеры по умолчанию 4000 MiB. DynFileFS, созданный initramfs, по умолчанию равен доступной ёмкости, округлённой вниз до 1000 MiB; Session Manager по умолчанию — 4000 MiB. | `perchsize=4000`<br>`perchsize=32GB`<br>`perchsize=1TB` |
| `perchreserve` | Каждая загрузка | Свободное место в MiB, сохраняемое на устройстве постоянства. Новые или увеличивающиеся контейнеры его не используют, и MiniOS предупреждает, когда свободное место достигает этого значения. По умолчанию: 256; максимум: 4096. | `perchreserve=512`<br>`perchreserve=1024` |
| `perchmode` | Каждая загрузка | Режим хранения постоянства.<br>`native` (по умолчанию): каталог на записываемой POSIX-файловой системе.<br>`dynfilefs`: расширяемый контейнер, включая FAT32, NTFS или exFAT.<br>`raw`: образ ext4 фиксированного размера.<br>`luks`: контейнер с шифрованием LUKS2 и ext4; создание и разблокировка требуют поддержки crypt в initramfs и подтверждаются в консоли.<br>`squashfs`: существующий сжатый снимок, распаковываемый для сессии. Session Manager может создавать и сохранять снимки SquashFS из работающей системы; initramfs может только возобновлять, но не создавать их. | `perchmode=native`<br>`perchmode=dynfilefs`<br>`perchmode=raw`<br>`perchmode=luks`<br>`perchmode=squashfs` |
| `perch` | Каждая загрузка | Включает устаревший путь восстановления постоянства. В отличие от `perchdir=resume`, не создаёт автоматически совместимую замену, если не найдено подходящей сессии по умолчанию. | `perch` |
| `toram` | Каждая загрузка | Обычный `toram` — это `full`. При постоянстве копия верхнего уровня режима full `*` не включает скрытые файлы; без постоянства не копирует `changes`, но копирует другие элементы верхнего уровня, включая скрытые файлы. Trim копирует необходимые `config.conf`, обычные файлы `authorized_keys`, выбранные модули верхнего уровня и рекурсивные, а также полностью дерево `changes/` при запросе постоянства; не копирует `boot/`, `kernels/`, `rootcopy/`, `config.conf.d/`, логи, другие данные вне модулей и отдельный уровень модулей постоянства. Ни один режим не проверяет объём RAM заранее. Хранилище постоянства, скопированное в RAM, не является долговечным, изменения не сохраняются обратно. Извлекать носитель только после подтверждения, что источник, loop-устройства и отображения успешно отсоединены. | `toram`<br>`toram=trim`<br>`toram=full` |

## Соображения безопасности

Командная строка ядра хранится в открытом виде и обычно видна в конфигурации загрузчика, `/proc/cmdline` и диагностике. Не размещайте повторно используемые секреты в `root-password=` или `user-password=`. Предпочитайте соответствующие параметры `*-crypted`, при этом даже хэши паролей, оказавшиеся в открытом доступе, следует считать чувствительными.

Хуки выполняются с привилегиями загрузочного кода. Хук `http://` не обеспечивает ни шифрования транспорта, ни аутентификации сервера, поэтому любой, кто может изменить сетевой путь, способен его подменить. Используйте только доверенные механизмы доставки и содержимое; не применяйте неаутентифицированные HTTP-хуки для запуска, критичного к безопасности.

Команды разделяются пробелами. Дополнительные параметры ядра, общие для всех дистрибутивов Linux, смотрите в справочных страницах `man bootparam`.

Подробную информацию о параметрах live-config смотрите в [live-config](/configuration/live-config.md).

Для загрузки MiniOS по сети (PXE и HTTP ISO) см. [Сетевая загрузка](/installation/Network-Boot.md).
