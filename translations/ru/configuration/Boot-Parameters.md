# Параметры загрузки

## Как использовать параметры загрузки

Параметры загрузки позволяют настраивать запуск MiniOS. Разделяйте параметры пробелами в командной строке ядра.

### Syslinux

- Нажмите <kbd>Esc</kbd> во время загрузки MiniOS, чтобы открыть меню загрузки.
- Нажмите <kbd>Tab</kbd> для редактирования параметров загрузки.
- Введите параметры и нажмите <kbd>Enter</kbd> для запуска.

### GRUB

- Нажмите <kbd>E</kbd> в меню GRUB.
- Отредактируйте параметры загрузки в конце командной строки.
- Нажмите <kbd>F10</kbd> для загрузки с новыми настройками.

## Параметры загрузки

В столбце "Применение" указано, какие параметры обычно используются при каждой загрузке, а какие относятся к настройке учётной записи при первом запуске. При использовании постоянства компоненты live-config обычно запускаются только один раз; см. [live-config](/configuration/live-config.md).

| Параметр | Применение | Описание | Пример |
|---|---|---|---|
| `from` | Каждая загрузка | Загружает данные MiniOS из каталога, устройства или ISO-образа. При удалённом ISO через **`http://` только** запускается [сетевой загрузчик](/installation/Network-Boot.md) (httpfs2). | `from=/minios/`<br>`from=/Downloads/minios.iso`<br>`from=http://domain.com/minios.iso`<br>`from=/dev/sr0/minios`<br>`from=/dev/disk/by-label/MyFlash/minios`<br>`from=askdisk`<br>`from=askdisk/customdir` |
| `load` | Каждая загрузка | Загружает только модули `.sb`, соответствующие имени, списку, регулярному выражению или поддерживаемому числовому диапазону. Также фильтрует модули, копируемые с помощью `toram=trim`. | `load=00-core`<br>`load=core,kernel,firmware`<br>`load=00,01,02`<br>`load=00-03` |
| `noload` | Каждая загрузка | Исключает подходящие модули `.sb`, включая из `toram=trim`. | `noload=05-xfce-apps`<br>`noload=xfce-apps,firefox`<br>`noload=05,06`<br>`noload=04-06` |
| `bext` | Каждая загрузка | Устанавливает расширение бандла. По умолчанию: `sb`. | `bext=mymod` |
| `timing` | Каждая загрузка | Включает вывод времени запуска. | `timing` |
| `union` | Каждая загрузка | Выбирает файловую систему union. | `union=aufs`<br>`union=overlayfs` |
| `ip` | Каждая загрузка | **Только для сетевой загрузки (PXE).** Статический адрес для раннего получения. Формат: `<client-ip>:<server-ip>:<gateway-ip>:<netmask>[:<port>]` (порт HTTP по умолчанию **7529**). Непустое значение `ip=` принудительно загружает данные PXE и пропускает локальные носители. Не относится к сессионной настройке NetworkManager. Подробнее см. [Сетевая загрузка](/installation/Network-Boot.md). | `ip=192.168.1.10:192.168.1.1:192.168.1.1:255.255.255.0` |
| `cache` | Каждая загрузка | Размер кэша httpfs в МБ для сетевой загрузки ISO по HTTP (`from=http://…`). Подробнее см. [Сетевая загрузка](/installation/Network-Boot.md). | `cache=512` |
| `rd.break` | Каждая загрузка | Открывает отладочную оболочку в конце стадии initramfs. | `rd.break` |
| `perchdir` | Каждая загрузка | Выбирает номер сессии постоянства или действие: `resume`, `new` или `ask`. Указание устройства/пути или форма `askdisk` выбирает другое место хранения постоянства. Без параметра постоянства MiniOS запускается "чисто". | `perchdir=1`<br>`perchdir=resume`<br>`perchdir=new`<br>`perchdir=ask`<br>`perchdir=/dev/sda1/changes`<br>`perchdir=/dev/disk/by-label/MyFlash/changes`<br>`perchdir=askdisk`<br>`perchdir=askdisk/customdir` |
| `perchsize` | Каждая загрузка | Размер контейнера для `dynfilefs`, `raw` и `luks`; не применяется к `native` или `squashfs`. Принимает целое число в МБ или суффиксы `M`/`MB`, `G`/`GB` или `T`/`TB`; ГБ и ТБ пересчитываются как 1000 МБ и 1 000 000 МБ. Лимит — 1 000 000 МБ, дополнительно ограничивается доступным пространством после `perchreserve`; raw- и LUKS-файлы ограничены 4000 МБ на FAT32. Новые контейнеры raw и LUKS по умолчанию 4000 МБ. DynFileFS, созданный в initramfs, по умолчанию использует доступную ёмкость, округлённую до 1000 МБ; Session Manager по умолчанию — 4000 МБ. | `perchsize=4000`<br>`perchsize=32GB`<br>`perchsize=1TB` |
| `perchreserve` | Каждая загрузка | Свободное место в MiB, резервируемое на устройстве постоянства. Новые или увеличивающиеся контейнеры его не используют, и MiniOS предупреждает, когда свободное место достигает этого значения. По умолчанию: 256; максимум: 4096. | `perchreserve=512`<br>`perchreserve=1024` |
| `perchmode` | Каждая загрузка | Режим хранения постоянства.<br>`native` (по умолчанию): каталог на доступной для записи POSIX-файловой системе.<br>`dynfilefs`: расширяемый контейнер, включая FAT32, NTFS или exFAT.<br>`raw`: образ ext4 фиксированного размера.<br>`luks`: контейнер с шифрованием LUKS2 и ext4; создание и разблокировка требуют поддержки crypt в initramfs и выполняются через консоль.<br>`squashfs`: существующий сжатый снимок, распаковываемый для сессии. Session Manager может создавать и сохранять снимки SquashFS из работающей системы; initramfs может только восстанавливать их, но не создавать. | `perchmode=native`<br>`perchmode=dynfilefs`<br>`perchmode=raw`<br>`perchmode=luks`<br>`perchmode=squashfs` |
| `perch` | Каждая загрузка | Включает постоянство и восстанавливает последнюю сессию. Эквивалентно `perchdir=resume`. | `perch` |
| `toram` | Каждая загрузка | Копирует MiniOS в RAM. Без значения используется `full`; `full` копирует весь каталог MiniOS, а `trim` — только выбранные модули, указанные через `load` и `noload`. При включённом постоянстве учитываются и сохранённые изменения. | `toram`<br>`toram=trim`<br>`toram=full` |
| `text` | Каждая загрузка | Запускает в текстовом консольном режиме. | `text` |
| `automount` | Каждая загрузка | Включает автоматическое монтирование устройств хранения. | `automount` |
| `debug` | Каждая загрузка | Включает расширенную диагностику при запуске. | `debug` |
| `nozram` | Каждая загрузка | Отключает swap на zram. | `nozram` |
| `zramsize` | Каждая загрузка | Устанавливает размер swap на zram в MiB. Если не указан, MiniOS рассчитывает его исходя из объёма RAM. | `zramsize=512`<br>`zramsize=2048` |
| `zramcomp` | Каждая загрузка | Выбирает `lzo`, `lzo-rle`, `lz4`, `lz4hc` или `zstd`; доступность зависит от используемого ядра. Если не указано, используется значение по умолчанию ядра. | `zramcomp=lzo`<br>`zramcomp=lz4` |
| `default-target` | Каждая загрузка | Устанавливает целевой systemd по умолчанию. | `default-target=multi-user`<br>`default-target=rescue` |
| `enable-services` | Каждая загрузка | Включает указанные сервисы systemd при загрузке. | `enable-services=ssh,docker`<br>`enable-services=ssh` |
| `disable-services` | Каждая загрузка | Отключает указанные сервисы systemd при загрузке. | `disable-services=apache2`<br>`disable-services=nginx` |
| `novirtres` | Каждая загрузка | Отключает автоматическое изменение разрешения экрана в виртуальных машинах. В XFCE по умолчанию 1280x800. | `novirtres` |
| `virtres` | Каждая загрузка | Устанавливает разрешение экрана XFCE в виртуальных машинах. | `virtres=1920x1080`<br>`virtres=1024x768` |
| `components` | Каждая загрузка | Запускает только указанные компоненты live-config, в порядке их следования. | `components=hostname,user-setup,sudo` |
| `nocomponents` | Каждая загрузка | Запускает все компоненты live-config, кроме указанных. | `nocomponents=anacron,apport` |
| `hostname` | Каждая загрузка | Устанавливает имя хоста системы. | `hostname=minios` |
| `username` | Первичная настройка | Устанавливает имя пользователя для автологина. | `username=live` |
| `user-default-groups` | Первичная настройка | Устанавливает группы пользователя по умолчанию. | `user-default-groups=audio,cdrom,video` |
| `user-fullname` | Первичная настройка | Устанавливает полное имя пользователя. | `user-fullname="MiniOS Live User"` |
| `root-password` | Первичная настройка | Устанавливает пароль root в открытом виде. | `root-password=toor` |
| `root-password-crypted` | Первичная настройка | Устанавливает пароль root в виде хэша crypt. | `root-password-crypted=$y$j9T$...` |
| `user-password` | Первичная настройка | Устанавливает пароль пользователя в открытом виде. | `user-password=live` |
| `user-password-crypted` | Первичная настройка | Устанавливает пароль пользователя в виде хэша crypt. | `user-password-crypted=$y$j9T$...` |
| `locales` | Каждая загрузка | Устанавливает одну или несколько локалей системы. | `locales=en_US.UTF-8` |
| `timezone` | Каждая загрузка | Устанавливает часовой пояс системы. | `timezone=Europe/Berlin` |
| `keyboard-model` | Каждая загрузка | Устанавливает модель клавиатуры. | `keyboard-model=pc105` |
| `keyboard-layouts` | Каждая загрузка | Устанавливает раскладки клавиатуры через запятую. | `keyboard-layouts=us,de` |
| `keyboard-variants` | Каждая загрузка | Устанавливает варианты клавиатуры через запятую, соответствующие раскладкам. | `keyboard-variants=,dvorak` |
| `keyboard-options` | Каждая загрузка | Устанавливает параметры клавиатуры. | `keyboard-options=grp:alt_shift_toggle` |
| `noroot` | Первичная настройка | Запрещает live-config назначать права sudo и policykit. | `noroot` |
| `noautologin` | Каждая загрузка | Запрещает live-config настраивать автологин в консоли и графической среде; существующая постоянная конфигурация не удаляется. | `noautologin` |
| `nottyautologin` | Каждая загрузка | Запрещает настройку автологина только в консоли; существующая постоянная конфигурация не удаляется. | `nottyautologin` |
| `nox11autologin` | Каждая загрузка | Запрещает настройку автологина только в графической среде; существующая постоянная конфигурация не удаляется. | `nox11autologin` |
| `xorg-driver` | Каждая загрузка | Выбирает драйвер Xorg вместо автодетекта. | `xorg-driver=nouveau` |
| `xorg-resolution` | Каждая загрузка | Устанавливает разрешение Xorg вместо автодетекта. | `xorg-resolution=1920x1080` |
| `module-mode` | Каждая загрузка | С параметром `merged` интегрирует изменения конфигурации в работающую live-систему. | `module-mode=merged` |
| `hooks` | Каждая загрузка | Загружает и выполняет хуки с файловой системы, live-носителя или URL, поддерживаемых wget. | `hooks=filesystem`<br>`hooks=http://example.com/script.sh` |

Разделяйте команды пробелами. Дополнительные параметры ядра, общие для всех дистрибутивов Linux, смотрите в справочных страницах `man bootparam`.

Подробную информацию о параметрах live-config см. в разделе [live-config](/configuration/live-config.md).

Для загрузки MiniOS по сети (PXE и HTTP ISO) см. [Сетевая загрузка](/installation/Network-Boot.md).
