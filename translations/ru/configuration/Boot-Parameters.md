# Параметры загрузки

## Как использовать параметры загрузки

Параметры загрузки, также называемые параметрами ядра, — это команды, которые вы можете ввести для настройки процесса загрузки MiniOS. С их помощью можно отключить определение оборудования, запустить MiniOS с конкретного устройства и многое другое.

### Для Syslinux:

- Нажмите <kbd>Esc</kbd> во время загрузки MiniOS, чтобы открыть меню загрузки.
- Нажмите <kbd>Tab</kbd> для редактирования параметров загрузки.
- Введите нужные параметры и нажмите Enter для запуска.

### Для Grub:

- Нажмите <kbd>E</kbd>, когда появится меню grub.
- Отредактируйте параметры загрузки в конце командной строки.
- Нажмите <kbd>F10</kbd>, чтобы загрузиться с новыми настройками.

## Таблица параметров загрузки

В таблице ниже перечислены доступные в MiniOS параметры загрузки, их функции и примеры использования.

**Легенда:**
- 🔒 **Только один раз** — применяется только при первой загрузке, не может быть изменён при последующих загрузках
- 🔄 **Переконфигурируемый** — можно изменять при каждой загрузке и применять повторно


| Параметр | Переконфигурируемый | Описание | Пример использования |
|---|---|---|---|
| `from` | 🔄 | Загружает данные MiniOS из указанного каталога, устройства или ISO-файла. | `from=/minios/`<br>`from=/Downloads/minios.iso`<br>`from=http://domain.com/minios.iso`<br>`from=/dev/sr0/minios`<br>`from=/dev/disk/by-label/MyFlash/minios`<br>`from=askdisk`<br>`from=askdisk/customdir` |
| `load` | 🔄 | Включает загрузку указанных модулей `.sb` с помощью регулярного выражения. Работает вместе с командой `toram=trim`, позволяя загружать в ОЗУ только выбранные модули.| `load=00-core`<br>`load=core,kernel,firmware`<br>`load=00,01,02`<br>`load=00-03` |
| `noload` | 🔄 | Отключает загрузку указанных модулей `.sb` с помощью регулярного выражения. Работает вместе с командой `toram=trim`, позволяя исключить выбранные модули из загрузки в ОЗУ. | `noload=05-xfce-apps`<br>`noload=xfce-apps,firefox`<br>`noload=05,06`<br>`noload=04-06` |
| `bext` | 🔄 | Устанавливает расширение файлов для бандлов (модулей). По умолчанию — `sb`. | `bext=mymod` |
| `timing` | 🔄 | Включает вывод времени выполнения на старте для отладки производительности. | `timing` |
| `union` | 🔄 | Принудительно использует определённую union-файловую систему. | `union=aufs`<br>`union=overlayfs` |
| `ip` | 🔄 | Устанавливает статический IP-адрес для сетевых интерфейсов, используется для PXE-загрузки. Формат: `<client-ip>:<server-ip>:<gateway-ip>:<netmask>`. | `ip=192.168.1.10:192.168.1.1:192.168.1.1:255.255.255.0` |
| `cache` | 🔄 | Устанавливает размер кэша в МБ для данных, загружаемых по HTTP. | `cache=512` |
| `rd.break` | 🔄 | Останавливает процесс загрузки в конце стадии initramfs и открывает отладочную оболочку. | `rd.break` |
| `perchdir` | 🔄 | Выбор профиля или действие с профилем. Принимает номер профиля или ключевые слова: `resume` (возобновить предыдущую сессию), `new` (начать новую сессию), `ask` (выбрать сессию при старте). Если не указано, MiniOS стартует в «чистом» режиме. | `perchdir=1`<br>`perchdir=resume`<br>`perchdir=new`<br>`perchdir=ask`<br>`perchdir=/dev/sda1/changes`<br>`perchdir=/dev/disk/by-label/MyFlash/changes`<br>`perchdir=askdisk`<br>`perchdir=askdisk/customdir` |
| `perchsize` | 🔄 | Устанавливает размер виртуальной файловой системы DynFileFS (в МБ), используемой для хранения данных на не-Linux файловых системах (например, FAT32, NTFS). По умолчанию — 16 ГБ. Используйте этот параметр, если целевой диск меньше. | `perchsize=4000`<br>`perchsize=32000` |
| `perchmode` | 🔄 | Режим сохранения постоянных изменений.<br>`native` (по умолчанию) — хранение данных как есть на POSIX-совместимых файловых системах;<br>`dynfilefs` — хранение данных в динамически расширяемых образах;<br>`raw` — хранение данных в образе фиксированного размера.| `perchmode=native`<br>`perchmode=dynfilefs`<br>`perchmode=raw` |
| `perch` | 🔄 | Включает сохранение изменений и возобновляет последнюю сессию. Эквивалентно `perchdir=resume`. | `perch` |
| `toram` | 🔄 | Копирует систему в ОЗУ. Может принимать значения `trim` и `full`. Если указано без параметров, используется `full`.<br>`trim` — копируется только необходимое, с учётом фильтров `load` и `noload`. Если заданы параметры `perch`, также загружаются изменения.<br>`full` — полностью загружается папка minios, кроме изменений, если не указан `perch`. | `toram`<br>`toram=trim`<br>`toram=full` |
| `text` | 🔄 | Отключает X-сервер и запускает текстовый режим консоли. | `text` |
| `automount` | 🔄 | Включает автоматическое монтирование устройств хранения. | `automount` |
| `debug` | 🔄 | Включает отладочный вывод при запуске. | `debug` |
| `nozram` | 🔄 | Отключает swap на zram. | `nozram` |
| `zramsize` | 🔄 | Устанавливает размер swap на zram (в МБ). | `zramsize=512`<br>`zramsize=2048` |
| `zramcomp` | 🔄 | Указывает алгоритм сжатия для zram. Для Debian 12 доступны: `lzo`, `lzo-rle`, `lz4`, `lz4hc`, `zstd`. По умолчанию — `lzo-rle`. | `zramcomp=lzo`<br>`zramcomp=lz4` |
| `default-target` | 🔄 | Устанавливает целевой режим systemd по умолчанию. | `default-target=multi-user`<br>`default-target=rescue` |
| `enable-services` | 🔄 | Включает указанные сервисы systemd при загрузке. | `enable-services=ssh,docker`<br>`enable-services=ssh` |
| `disable-services` | 🔄 | Отключает указанные сервисы systemd при загрузке. | `disable-services=apache2`<br>`disable-services=nginx` |
| `novirtres` | 🔄 | Отключает автоматическое изменение разрешения экрана в виртуальных машинах. По умолчанию в ВМ используется разрешение 1280x800. (Применимо только в окружении XFCE.) | `novirtres` |
| `virtres` | 🔄 | Устанавливает разрешение экрана в виртуальных машинах (ширина x высота). (Применимо только в окружении XFCE.) | `virtres=1920x1080`<br>`virtres=1024x768` |
| `components` | 🔄 | Указывает, какие компоненты live-config запускать. | `components=hostname,user-setup,sudo` |
| `nocomponents` | 🔄 | Указывает, какие компоненты live-config НЕ запускать. | `nocomponents=anacron,apport` |
| `hostname` | 🔄 | Устанавливает имя хоста системы. | `hostname=minios` |
| `username` | 🔒 | Устанавливает имя пользователя для автологина. | `username=live` |
| `user-default-groups` | 🔒 | Устанавливает группы пользователя по умолчанию. | `user-default-groups=audio,cdrom,video` |
| `user-fullname` | 🔒 | Устанавливает полное имя пользователя. | `user-fullname="MiniOS Live User"` |
| `root-password` | 🔒 | Устанавливает пароль root в открытом виде. | `root-password=toor` |
| `root-password-crypted` | 🔒 | Устанавливает пароль root в зашифрованном виде. | `root-password-crypted=$y$j9T$...` |
| `user-password` | 🔒 | Устанавливает пароль пользователя в открытом виде. | `user-password=live` |
| `user-password-crypted` | 🔒 | Устанавливает пароль пользователя в зашифрованном виде. | `user-password-crypted=$y$j9T$...` |
| `locales` | 🔄 | Устанавливает системную локаль. | `locales=en_US.UTF-8` |
| `timezone` | 🔄 | Устанавливает часовой пояс системы. | `timezone=Europe/Berlin` |
| `keyboard-model` | 🔄 | Устанавливает модель клавиатуры. | `keyboard-model=pc105` |
| `keyboard-layouts` | 🔄 | Устанавливает раскладки клавиатуры (через запятую). | `keyboard-layouts=us,de` |
| `keyboard-variants` | 🔄 | Устанавливает варианты раскладок клавиатуры (через запятую). | `keyboard-variants=,dvorak` |
| `keyboard-options` | 🔄 | Устанавливает опции клавиатуры. | `keyboard-options=grp:alt_shift_toggle` |
| `noroot` | 🔒 | Отключает права sudo и policykit. | `noroot` |
| `noautologin` | 🔄 | Отключает автологин как в консоли, так и в графическом режиме. | `noautologin` |
| `nottyautologin` | 🔄 | Отключает автологин только в консоли. | `nottyautologin` |
| `nox11autologin` | 🔄 | Отключает автологин только в графическом режиме. | `nox11autologin` |
| `xorg-driver` | 🔄 | Устанавливает драйвер xorg вместо автоопределения. | `xorg-driver=nouveau` |
| `xorg-resolution` | 🔄 | Устанавливает разрешение xorg вместо автоопределения. | `xorg-resolution=1920x1080` |
| `module-mode` | 🔄 | Устанавливает режим модуля live-конфигурации. При значении "merged" динамически интегрирует изменения конфигурации. | `module-mode=merged` |
| `hooks` | 🔄 | Выполняет произвольные файлы из файловой системы, носителя или по URL. | `hooks=filesystem`<br>`hooks=http://example.com/script.sh` |

Разделяйте команды пробелами. Для дополнительных параметров ядра, общих для всех дистрибутивов Linux, смотрите справочные страницы `man bootparam`.

Подробную информацию о параметрах live-config смотрите в [live-config](/configuration/live-config.md).
