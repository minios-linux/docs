# Руководство по загрузочным меню MiniOS

Загрузочные меню MiniOS предоставляют удобные пункты для популярных режимов Live-загрузки. В этом руководстве объясняется, как выбирать и редактировать эти пункты.

## Обзор

В зависимости от прошивки, структуры образа и сборки MiniOS может использовать GRUB или Syslinux. Их меню, клавиши для редактирования, поддержка языков и доступные пункты могут отличаться. В конечном итоге загрузчик передает командную строку ядра одному и тому же initrd; см. [Режимы загрузки](/configuration/Boot-Modes.md) для описания поведения источника, персистентности, копирования в RAM и зависимости от носителя.

## Варианты загрузочного меню

Обычно предоставляемый образ предлагает следующие варианты, однако названия, доступность, порядок и выбор по умолчанию могут отличаться в зависимости от образа:

| Вариант меню | Типичный селектор initrd | Назначение |
|---|---|---|
| Возобновить предыдущую сессию | `perchdir=resume` | Попробовать совместимую сессию по умолчанию и разрешить создание новой при определённых условиях. |
| Начать новую сессию | `perchdir=new` | Создать новую пронумерованную персистентную сессию. |
| Выбрать сессию при запуске | `perchdir=ask` | Выбрать существующую сессию или запросить новую в интерактивном режиме. |
| Новый старт | без селектора персистентности | Использовать временный записываемый слой. |
| Копировать в RAM | `toram` | Запросить полный путь копирования в RAM. |

Это селекторы, а не гарантии того, что хранилище доступно для записи, сессия совместима, RAM достаточно или исходный носитель отключён. Подробнее о поведении и комбинациях см. [Режимы загрузки](/configuration/Boot-Modes.md), о крайних случаях селекторов — [Персистентность initrd](/configuration/Initrd-Persistence.md), а о компромиссах между RAM и I/O — [Оптимизация производительности](/administration/Performance-Optimization.md).

## Как пользоваться загрузочным меню

### Навигация по меню

- Используйте **стрелки** для перемещения между пунктами
- Нажмите **Enter** для выбора пункта
- Нажмите **Esc** для возврата к предыдущему меню (в GRUB)
- Автоматический выбор и длительность тайм-аута зависят от активной конфигурации меню; некоторые меню могут ожидать выбора неограниченно долго

### Выбор языка (GRUB)

Если ваш USB-накопитель MiniOS поддерживает несколько языков:
1. На первом экране появятся варианты языков
2. Выберите предпочитаемый язык
3. Загрузочное меню отобразится на выбранном языке
4. Выбор также может передать настройки локали на следующих этапах загрузки, но это не гарантирует, что все сообщения загрузки или приложений будут переведены

⚠️ **Важно:** Многоязычное меню имеет приоритет над настройками локали, указанными в `config.conf`. Язык, выбранный в загрузочном меню, будет использоваться вместо предварительно заданных параметров локали. Подробнее см. в **[Файл конфигурации](/configuration/Configuration-File.md)** и **[live-config](/configuration/live-config.md)** о системных конфигурационных файлах.

## Настройка параметров загрузки

### Временное изменение параметров загрузки

Вы можете изменить параметры загрузки для одной сессии:

**В GRUB:**
1. Выберите нужный пункт меню
2. Нажмите **'e'** для редактирования
3. Перейдите к строке, начинающейся с `linux`
4. Добавьте или измените параметры в конце строки
5. Нажмите **Ctrl+X** или **F10** для загрузки с изменёнными параметрами

**В SYSLINUX:**
1. Выберите нужный пункт меню
2. Нажмите **Tab** перед Enter
3. Добавьте параметры в появившуюся командную строку
4. Нажмите **Enter** для загрузки

### Часто используемые параметры загрузки

- `debug` — Показать подробные сообщения загрузки (полезно для диагностики)
- `toram=trim` — Копировать отфильтрованный набор модулей и необходимые данные в RAM
- `perchsize=2000` — Установить размер хранилища сессии 2 ГБ (можно изменить по необходимости)
- `locales=ru_RU.UTF-8` — Запросить определённый язык/локаль

Полный список доступных параметров загрузки смотрите в **[Параметры загрузки](/configuration/Boot-Parameters.md)**.

## Расположение файлов конфигурации

### На вашем USB-накопителе MiniOS

- **Конфигурация GRUB:** `/minios/boot/grub/grub.cfg`
- **Конфигурация SYSLINUX:** `/minios/boot/syslinux/syslinux.cfg`
- **Загрузочные образы:** `/minios/boot/bootlogo.png`
- **Языковые файлы:** `/minios/boot/grub/locale/`

### В работающей системе

- **Текущие параметры загрузки:** `/proc/cmdline`
- **Каталог данных MiniOS:** `/run/initramfs/memory/data/minios/`

### Редактирование конфигурационных файлов

⚠️ **Внимание:** Редактируйте файлы конфигурации загрузки только если уверены в своих действиях. Неправильные изменения могут сделать ваш USB-накопитель не загружаемым.

**Чтобы изменить конфигурацию GRUB:**
1. Смонтируйте USB-накопитель MiniOS
2. Перейдите в `/minios/boot/grub/`
3. Отредактируйте `grub.cfg` в текстовом редакторе
4. Сохраните изменения и безопасно извлеките накопитель

**Часто вносимые изменения:**
- Изменение директивы тайм-аута, используемой активным меню GRUB или Syslinux
- Изменение `set default=0` для выбора пункта меню по умолчанию
- Добавление пользовательских пунктов меню
