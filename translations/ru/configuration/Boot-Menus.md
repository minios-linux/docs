# Руководство по загрузочным меню MiniOS

MiniOS предоставляет мощную систему загрузочного меню, позволяющую выбрать способ запуска и работы системы. В этом руководстве объясняются доступные варианты загрузки и способы их настройки.

## Обзор

MiniOS использует GRUB в качестве основного загрузчика, предоставляя графический интерфейс с поддержкой нескольких языков. На старых системах с BIOS может использоваться SYSLINUX в качестве альтернативы. Оба загрузчика обеспечивают одинаковую функциональность, но имеют немного разные интерфенты.

## Варианты загрузочного меню

### 1. Возобновить предыдущую сессию

**Что делает:** Пытается продолжить работу с последней сессии, автоматически адаптируясь в зависимости от доступного хранилища.

- **Когда использовать:** Это вариант по умолчанию — подходит большинству пользователей в большинстве ситуаций
- **Что происходит:** 
  - **На записываемом носителе с существующей сессией:** Восстанавливает ваши сохранённые файлы, приложения и настройки
  - **На записываемом носителе без сессии:** Автоматически создаёт первую сессию (сессия №1)
  - **На носителях только для чтения (DVD, CD):** Работает как "Чистый запуск", так как нет доступного хранилища
  - **Если сессия несовместима:** Создаётся новая сессия (например, при использовании другой версии MiniOS)
  - Система автоматически проверяет совместимость и ограничения по хранилищу
- **Результат:** Вы всегда получаете рабочую систему, оптимизированную под ваш тип носителя

### 2. Начать новую сессию

**Что делает:** Создаёт новое рабочее пространство, сохраняя все существующие сессии.

- **Когда использовать:** Когда нужен чистый рабочий стол для другой задачи или тестирования
- **Что происходит:**
  - Создаётся новая сессия с уникальным номером (например, если была сессия 1, создаётся сессия 2)
  - Запускается чистое окружение рабочего стола
  - Все новые изменения сохраняются в новой сессии
  - Все существующие сессии остаются без изменений и доступны для переключения
- **Примечание:** Переключаться между сессиями можно через опцию "Выбор сессии при запуске"

### 3. Выбрать сессию при запуске

**Что делает:** Показывает интерактивное меню для выбора из существующих сессий или создания новой.

- **Когда использовать:** Если у вас несколько сессий и нужно выбрать, с какой работать
- **Что происходит:**
  - Во время загрузки появляется диалоговое окно со списком доступных сессий
  - Отображается информация о сессии (номер, время последнего доступа, использование диска)
  - Можно возобновить любую существующую сессию или начать новую
  - Позволяет выбрать другой носитель, если доступно несколько
- **Преимущества:** Полный контроль над выбором сессии — идеально для пользователей, работающих с несколькими рабочими пространствами

### 4. Чистый запуск

**Что делает:** Запускает MiniOS без сохранения каких-либо изменений.

- **Когда использовать:** 
  - Для тестирования системы на записываемом носителе без влияния на существующие сессии
  - Для устранения неполадок без изменения сохранённых данных
  - Для максимальной приватности (данные не сохраняются)
  - Когда нужно быть уверенным, что не будет постоянных изменений
- **Что происходит:**
  - Самое быстрое время загрузки
  - Все изменения теряются после выключения
  - Нет доступа к устройствам хранения для сохранения данных
- **Примечание:** При запуске с носителей только для чтения (DVD, CD) опция "Возобновить предыдущую сессию" автоматически работает как "Чистый запуск", так как нет доступного хранилища для сессий

### 5. Копирование в RAM

**Что делает:** Загружает всю систему в оперативную память компьютера для максимальной производительности.

- **Когда использовать:**
  - У вас достаточно RAM (рекомендуется от 4 ГБ)
  - Необходима максимальная производительность
  - Нужно извлечь USB-накопитель после загрузки
  - Работа с ресурсоёмкими приложениями
- **Что происходит:**
  - Все системные файлы копируются в RAM во время загрузки
  - USB-накопитель можно извлечь после завершения загрузки
  - Система полностью работает из памяти
  - Самое быстрое время отклика для всех операций
- **Требования:** Достаточно RAM для размещения всей системы

Для расширенных параметров `toram` и техник оптимизации памяти см. **[Оптимизация производительности](/administration/Performance-Optimization.md)**.

## Как использовать загрузочное меню

### Навигация по меню

- Используйте **стрелки** для перемещения между вариантами
- Нажмите **Enter** для выбора варианта
- Нажмите **Esc** для возврата в предыдущее меню (в GRUB)
- Через 10 секунд по умолчанию будет выбран стандартный вариант

### Выбор языка (GRUB)

Если ваш USB-накопитель MiniOS поддерживает несколько языков:
1. На первом экране появятся варианты языков
2. Выберите предпочитаемый язык
3. Загрузочное меню появится на выбранном языке
4. Все последующие системные сообщения будут использовать этот язык

⚠️ **Важно:** Многоязычное меню переопределяет любые настройки локали, указанные в `config.conf`. Язык, выбранный в загрузочном меню, имеет приоритет над предустановленными настройками локали. Подробнее о файлах конфигурации системы смотрите в **[Configuration File](/configuration/Configuration-File.md)** и **[live-config](/configuration/live-config.md)**.

## Настройка параметров загрузки

### Временное изменение параметров загрузки

Вы можете изменить параметры загрузки для одной сессии:

**В GRUB:**
1. Выберите нужный пункт меню
2. Нажмите **'e'** для редактирования
3. Перейдите к строке, начинающейся с `linux`
4. Добавьте или измените параметры в конце строки
5. Нажмите **Ctrl+X** или **F10** для загрузки с изменениями

**В SYSLINUX:**
1. Выберите нужный пункт меню
2. Нажмите **Tab** перед Enter
3. Добавьте параметры в появившуюся командную строку
4. Нажмите **Enter** для загрузки

### Частые изменения параметров загрузки

- `debug` — Показать подробные сообщения загрузки (полезно для диагностики)
- `toram=trim` — Копировать только необходимые файлы в RAM (если полная `toram` требует слишком много памяти)
- `perchsize=2000` — Установить размер хранилища сессии в 2 ГБ (можно изменить при необходимости)
- `locale=ru_RU.UTF-8` — Принудительно задать определённый язык/локаль

Полный список доступных параметров загрузки смотрите в **[Параметры загрузки](/configuration/Boot-Parameters.md)**.

## Расположение файлов конфигурации

### На вашем USB-накопителе MiniOS

- **Конфигурация GRUB:** `/minios/boot/grub/grub.cfg`
- **Конфигурация SYSLINUX:** `/minios/boot/syslinux/syslinux.cfg`
- **Загрузочные изображения:** `/minios/boot/bootlogo.png`
- **Языковые файлы:** `/minios/boot/grub/locale/`

### В работающей системе

- **Текущие параметры загрузки:** `/proc/cmdline`
- **Каталог данных MiniOS:** `/run/initramfs/memory/data/minios/`

### Редактирование файлов конфигурации

⚠️ **Внимание:** Редактируйте загрузочные конфигурационные файлы только если понимаете, что делаете. Неправильные изменения могут сделать ваш USB-накопитель неработоспособным.

**Для редактирования конфигурации GRUB:**
1. Подключите USB-накопитель MiniOS
2. Перейдите в `/minios/boot/grub/`
3. Отредактируйте `grub.cfg` в текстовом редакторе
4. Сохраните и безопасно извлеките USB-накопитель

**Типичные изменения:**
- Изменить `set timeout=10` для настройки времени ожидания меню
- Изменить `set default=0` для выбора варианта по умолчанию
- Добавить собственные пункты меню
