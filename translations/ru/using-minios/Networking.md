# Сетевые подключения

MiniOS использует **NetworkManager** для обычных проводных и Wi-Fi подключений. MiniOS не заменяет его модель подключения отдельной системой настройки сети.

Для стандартного использования откройте значок сети на панели рабочего стола. Также доступны стандартные инструменты NetworkManager:

```bash
nmtui
nmcli
```

Используйте эти инструменты для подключения к Wi-Fi, смены сетей, настройки DHCP или статических адресов, DNS, VPN и других обычных сетевых задач во время работы системы. Для получения полной информации обратитесь к документации и man-страницам NetworkManager.

В постоянной сессии MiniOS профили подключений NetworkManager сохраняются как часть этой сессии. В **Запустить без сохранения**, все изменения будут утеряны после завершения работы.

## Предварительная настройка сети

Сетевые параметры, специфичные для MiniOS, в первую очередь представляют собой **предварительную настройку**. Они полезны, когда образ, установщик или автоматизированное развертывание должны запускаться с заранее известной проводной конфигурацией до того, как пользователь откроет NetworkManager.

Сетевой компонент MiniOS `live-config` поддерживает предварительную настройку проводной сети IPv4. Wi-Fi не настраивается заранее.

Пример статической настройки в `config.conf` выглядит так:

```bash
LIVE_NETWORK_METHOD="static"
LIVE_NETWORK_INTERFACE="enp1s0"
LIVE_NETWORK_ADDRESS="192.0.2.10"
LIVE_NETWORK_PREFIX="24"
LIVE_NETWORK_GATEWAY="192.0.2.1"
LIVE_NETWORK_DNS="1.1.1.1,9.9.9.9"
LIVE_NETWORK_BACKEND="auto"
```

`LIVE_NETWORK_METHOD` поддерживает значения `dhcp`, `static` или `off`. Если не указано или `dhcp` сохраняется существующая сетевая конфигурация образа без замены стандартного поведения NetworkManager. `static` записывает статическую проводную конфигурацию IPv4; `off` подготавливает выбранный проводной интерфейс так, чтобы он не подключался автоматически. При использовании `LIVE_NETWORK_BACKEND="auto"`, MiniOS предпочитает NetworkManager и использует ifupdown только при необходимости. Если интерфейс не указан, предварительная настройка применяется только в случае, если обнаружен ровно один подходящий проводной интерфейс.

См. [Файл конфигурации](/reference/configuration/config.conf) для информации о месте хранения этих настроек и [live-config](/reference/configuration/live-config) для полного списка переменных и компонентов.

## Когда применяется предварительная настройка

Сетевой компонент — это одноразовый `live-config` этап настройки. После успешного выполнения в постоянной сессии обычные сетевые изменения рекомендуется вносить через NetworkManager, а не путем повторного редактирования предварительной настройки.

Если вам нужно применить изменённую предварительную настройку сети MiniOS к той же постоянной сессии, удалите метку завершения и перезагрузите систему:

```bash
sudo rm -f /var/lib/live/config/network
```

Делайте это только в случае необходимости повторного применения `live-config` для генерации политики проводной сети. Для изменения обычных Wi-Fi или Ethernet-подключений это не требуется.

## Предварительная настройка в установщике

Сетевой этап Установщика MiniOS также выполняет предварительную настройку для целевой системы. Поддерживаются проводные настройки DHCP или статический IPv4. Wi-Fi настраивается через NetworkManager уже после запуска установленной системы.

## Сетевые подключения на ранних этапах загрузки отличаются

NetworkManager настраивает сеть в работающей системе MiniOS. Сетевые подключения, используемые initramfs для получения самого MiniOS, реализуются отдельным механизмом.

Параметр загрузки `ip=`, PXE-загрузка и `from=http://...` не создают профили NetworkManager и не предназначены для настройки обычной сети рабочего стола. Подробнее см. [Сетевая загрузка](/reference/boot-process/Network-Boot).

## Устранение неполадок

При возникновении обычных проблем с подключением начните с самого NetworkManager:

```bash
nmcli device status
nmcli connection show --active
```

Используйте редактор подключений на рабочем столе, `nmtui`, либо стандартные журналы и документацию NetworkManager для диагностики проблем с Wi-Fi, DHCP, DNS, VPN или Ethernet.

Диагностика, специфичная для MiniOS, актуальна при возникновении проблем с предварительной настройкой сети или сетевой загрузкой. `live-config`Журнал `/var/log/live/config.log`; вопросы, связанные с ранней сетевой загрузкой, рассматриваются в разделе [Сетевая загрузка](/reference/boot-process/Network-Boot).
