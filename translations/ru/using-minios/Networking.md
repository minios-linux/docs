# Сетевые подключения

MiniOS использует **NetworkManager** для обычных проводных и Wi-Fi сетей. MiniOS не заменяет свою модель подключения отдельной системой сетевой конфигурации.

Для обычного использования откройте значок сети на панели рабочего стола. Также доступны стандартные инструменты NetworkManager:

```bash
nmtui
nmcli
```

Используйте эти инструменты для подключения к Wi-Fi, переключения сетей, настройки DHCP или статических адресов, DNS, VPN и других стандартных сетевых задач во время работы. Для полного описания возможностей обратитесь к документации и man-страницам NetworkManager.

В постоянной сессии MiniOS профили подключений NetworkManager сохраняются как часть этой сессии. В режиме **Запуск без сохранения** изменения исчезают после завершения работы.

## Предварительная настройка сети

Сетевые параметры, специфичные для MiniOS, в первую очередь являются **предварительной конфигурацией**. Они полезны, когда образ, установщик или автоматизированное развертывание должны запускаться с заранее определённой проводной конфигурацией до открытия NetworkManager пользователем.

Компонент сети MiniOS `live-config` поддерживает предварительную настройку проводного IPv4. Wi-Fi не настраивается заранее.

Пример статической настройки в `config.conf`:

```bash
LIVE_NETWORK_METHOD="static"
LIVE_NETWORK_INTERFACE="enp1s0"
LIVE_NETWORK_ADDRESS="192.0.2.10"
LIVE_NETWORK_PREFIX="24"
LIVE_NETWORK_GATEWAY="192.0.2.1"
LIVE_NETWORK_DNS="1.1.1.1,9.9.9.9"
LIVE_NETWORK_BACKEND="auto"
```

`LIVE_NETWORK_METHOD` принимает значения `dhcp`, `static` или `off`. Значения Unset и `dhcp` сохраняют существующую сетевую конфигурацию образа, не заменяя стандартное поведение NetworkManager. `static` записывает статическую проводную конфигурацию IPv4; `off` подготавливает выбранный проводной интерфейс к работе без автоматического подключения. С помощью `LIVE_NETWORK_BACKEND="auto"` MiniOS предпочитает NetworkManager и при необходимости использует ifupdown. Если интерфейс не указан, предварительная настройка применяется только тогда, когда обнаружен ровно один подходящий проводной интерфейс.

См. [Файл конфигурации](/reference/configuration/config.conf) для информации о месте хранения этих параметров и [live-config](/reference/configuration/live-config) для полного справочника переменных и компонентов.

## Когда применяется предварительная настройка

Сетевой компонент — это одноразовый этап настройки `live-config`. После успешного выполнения в постоянной сессии обычные сетевые изменения следует вносить через NetworkManager, а не путём повторного редактирования предварительной конфигурации.

Если вам действительно нужно применить изменённую предварительную сетевую конфигурацию MiniOS к той же постоянной сессии, удалите отметку о завершении и перезагрузите систему:

```bash
sudo rm -f /var/lib/live/config/network
```

Делайте это только если действительно требуется, чтобы `live-config` снова сгенерировал правила для проводной сети. Для изменения обычных Wi-Fi или Ethernet-подключений это не требуется.

## Предварительная настройка установщика

На сетевом этапе Установщик MiniOS также выполняет предварительную конфигурацию целевой системы. Поддерживаются проводной DHCP или статические настройки IPv4. Настройка Wi-Fi передаётся NetworkManager после запуска установленной системы.

## Сетевые подключения на ранней стадии загрузки отличаются

NetworkManager настраивает сеть в работающей системе MiniOS. Сеть, используемая initramfs для получения MiniOS, реализована отдельным механизмом.

Параметр загрузки `ip=`, загрузка по PXE и `from=http://...` не создают профили NetworkManager и не должны использоваться для настройки обычной сети рабочего стола. См. [Загрузка по сети](/reference/boot-process/Network-Boot).

## Поиск и устранение неисправностей

При обычных проблемах с подключением начните с самого NetworkManager:

```bash
nmcli device status
nmcli connection show --active
```

Используйте редактор подключений рабочего стола, `nmtui` или стандартные журналы и документацию NetworkManager для решения типичных проблем с Wi-Fi, DHCP, DNS, VPN или Ethernet.

Диагностика, специфичная для MiniOS, актуальна, если проблема связана с предварительной сетевой настройкой или загрузкой по сети. Журнал `live-config` — это `/var/log/live/config.log`; проблемы ранней загрузки по сети описаны в руководстве [Загрузка по сети](/reference/boot-process/Network-Boot).
