# Режимы загрузки

Режим загрузки определяет, будет ли MiniOS запускаться с чистого листа, открывать сохранённую сессию или работать как обычная установленная система. Для выбора режима не требуется разбираться во внутреннем процессе загрузки.

Названия пунктов меню могут немного отличаться в разных версиях, режимах прошивки и загрузочных утилитах. Ориентируйтесь на нужный вам результат, а не на точную формулировку.

## Быстрый выбор

Обычный пункт по умолчанию — **Запустить MiniOS**. В этом режиме используется автоматический выбор постоянства: MiniOS пытается восстановить совместимую сессию по умолчанию и может создать новую, если подходящей сессии нет и доступно подходящее устройство для записи.

| Пункт меню | Используйте, если | Сохраняются ли изменения? | USB должен оставаться подключённым? |
|---|---|---|---|
| **Запустить MiniOS** (по умолчанию) | Обычное переносное использование | Да, если автоматическое включение постоянства прошло успешно | Да |
| **Начать новую сессию** | Вам нужен отдельный новый рабочий стол | Только если новая сессия создана и успешно активирована | Да |
| **Выбрать сохранённую сессию** | Вы хотите выбрать одну из нескольких существующих рабочих сред | Только если выбранная сессия успешно активирована | Да |
| **Запустить без сохранения** | Вам нужна чистая временная загрузка без постоянства | Нет | Да |
| **Запустить из RAM** | Вы хотите скопировать системные данные MiniOS в RAM для этой загрузки | Изменения, поддерживаемые RAM, будут временными, если только поддерживаемая сессия постоянства не будет явно сохранена обратно или сохранена как новая | Пока MiniOS не отсоединит исходный носитель и все устройства хранения, которые вам ещё нужны |

Для обычной первой загрузки оставьте **Запустить MiniOS** выбранным. Используйте **Запустить без сохранения** если вам нужен именно чистый временный запуск для тестирования оборудования или восстановления, без открытия или создания постоянства.

::: warning Убедитесь, что постоянство активно
Выбор пункта меню с постоянством запрашивает сессию, но не гарантирует, что она откроется. Если носитель только для чтения, переполнен, повреждён или несовместим, MiniOS продолжит работу без сохранения изменений. Проверьте предупреждение при запуске перед началом работы, которую нужно сохранить.
:::

## Запустить MiniOS

**Запустить MiniOS** — это первый и основной пункт меню по умолчанию. Он предназначен для обычного использования, включая первую загрузку только что подготовленного устройства MiniOS.

MiniOS автоматически ищет совместимую сессию с постоянством. Если найдена подходящая сессия по умолчанию, она будет восстановлена. Если подходящей сессии нет, MiniOS может создать совместимую сессию автоматически, если доступно подходящее устройство для записи.

Если создать или активировать постоянство невозможно из-за того, что носитель только для чтения, переполнен, повреждён или по другим причинам не подходит, MiniOS продолжит работу с временным слоем для записи и сообщит, что сессия не является постоянной. Обратите внимание на это предупреждение перед работой, которую нужно сохранить после перезагрузки.

Для рабочей сессии с постоянством Конфигуратор MiniOS может сохранять выбранные обычные журналы и кэши в RAM, при этом диагностические данные загрузки и пользовательские данные останутся на накопителе. Три настройки и их ограничения RAM описаны в разделе [Производительность](/maintenance-and-recovery/Performance#reduce-cache-and-log-writes-with-perch). Эти параметры не влияют на **Запустить без сохранения** загрузку.

## Начать новую сессию

MiniOS открывает меню настройки постоянства, позволяет выбрать поддерживаемое хранилище и нужные параметры шифрования или сжатия DynBlk, а затем создаёт дополнительную пронумерованную сессию с постоянством, не затрагивая существующие сессии. Это текущее `perchdir=setup`поведение. Используйте этот вариант, чтобы создавать отдельные рабочие среды или тестировать новую конфигурацию, не заменяя текущую рабочую сессию.

Для создания требуется совместимый носитель с возможностью записи и достаточным свободным пространством. Доступные варианты хранилища зависят от файловой системы, состояния Secure Boot, установленных драйверов/утилит и возможностей initrd. Новая сессия не является резервной копией существующей.

## Выбрать сохранённую сессию

MiniOS показывает доступные сохранённые сессии и позволяет выбрать одну из них. Используйте этот вариант, если на одном устройстве несколько рабочих сред. Если выбранное хранилище постоянства пусто, путь `ask`автоматически переходит к настройке постоянства, чтобы вы могли создать первую сессию.

Сессия может быть несовместимой, если она создана в другой версии или редакции MiniOS. Также несовместимость может возникнуть из-за другого `union=`параметра.
Интерактивный выбор не делает несовместимую сессию безопасной.

## Запустить без сохранения

В этом режиме постоянство намеренно отключается для текущей загрузки. MiniOS использует временную область для записи в RAM, поэтому созданные в live-системе файлы, установленные пакеты и изменённые настройки будут удалены при завершении работы.

Используйте этот режим, если вы хотите:

- протестировать оборудование без открытия или создания сессии с постоянством;
- диагностировать проблему без изменения сохранённого состояния;
- поработать временно, если ничего не нужно сохранять.

Запуск без сохранения не означает, что загрузочный носитель можно извлечь. Обычно система продолжает считывать свои модули с этого носителя.

## Запустить из RAM

В этом режиме системные данные MiniOS копируются в RAM, чтобы уменьшить количество обращений к исходному носителю. Для этого требуется достаточно оперативной памяти как для копируемой системы, так и для текущей нагрузки.

Теперь копирование системы и копирование постоянства выполняются отдельно. При запросе постоянства `toram`по умолчанию `perchtoram`выбирается `trim`, поэтому выбранная поддерживаемая сессия Raw, DynFileFS, DynBlk, VMDK или SquashFS копируется в RAM, а остальные сохранённые сессии остаются на исходном носителе. Используйте `perchtoram=off`если вы хотите, чтобы система работала из RAM, а активная сессия постоянства продолжала записывать данные напрямую на носитель, или `perchtoram=full`если нужно скопировать все поддерживаемые сохранённые сессии. Сессии в виде обычных директорий не копируются через `perchtoram`.

Сессия постоянства на базе RAM не сохраняет изменения на диск во время работы. Текущий Менеджер сессий MiniOS может явно записать поддерживаемые изменения на базе RAM обратно на исходный носитель с помощью **Сохранить сейчас**, либо сохранить их как новую пронумерованную сессию, если исходный носитель доступен, открыт для записи и соответствует идентификатору, зафиксированному при загрузке. Пока такое сохранение не выполнено, несохранённые изменения RAM будут потеряны при завершении работы. Автоматические политики сохранения SquashFS используют тот же бэкенд сессии, если исходный носитель доступен.

Не извлекайте загрузочное устройство только потому, что **Запустить из RAM** был выбран. Это безопасно только после того, как MiniOS успешно отсоединит исходную файловую систему, ISO-образ, сопоставления Ventoy и все зависимости по постоянству, которые вам ещё нужны. Если отсоединение не удалось, источник продолжает использоваться.

## Нативная установка

::: warning Нативная установка меняет модель системы
Нативная установка сохраняет привычный рабочий стол MiniOS — его визуальный стиль, выбранное окружение и стандартные приложения — но преобразует live-образ в обычную Debian-систему. Инструменты MiniOS, связанные с сессиями, модулями, модульными ядрами и другими live-функциями, будут удалены, так как эти возможности больше не актуальны.
:::

После нативного преобразования используйте стандартные инструменты Debian для управления пакетами, ядром, настройками и загрузчиком. Внешний вид останется привычным, а стандартные приложения выбранной редакции сохранятся, но набор live-функций MiniOS больше не будет доступен. Архитектура live-режима MiniOS описана в разделе [О MiniOS](/getting-started/About-MiniOS).

Используйте [Установщик MiniOS](/installing-minios/MiniOS-Installer) только если вы осознанно хотите выполнить такое преобразование и выбранный образ поддерживает нативную установку.
