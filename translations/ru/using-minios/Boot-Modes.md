# Режимы загрузки

Режим загрузки определяет, будет ли MiniOS запускаться «с нуля», открывать сохранённую сессию или работать как обычная установленная система. Для выбора подходящего варианта не требуется разбираться во внутреннем процессе загрузки.

Названия пунктов меню могут немного отличаться в разных версиях, режимах прошивки и загрузочных инструментах. Ориентируйтесь на желаемый результат, а не на точную формулировку.

## Быстрый выбор

Обычный вариант по умолчанию — **Запустить MiniOS**. В этом режиме используется автоматический выбор постоянства: MiniOS пытается восстановить совместимую сессию по умолчанию и может создать новую совместимую сессию, если подходящей нет и доступно подходящее записываемое хранилище.

| Пункт меню | Когда использовать | Сохраняются ли изменения? | Оставлять USB подключённым? |
|---|---|---|---|
| **Запустить MiniOS** (по умолчанию) | Обычное переносное использование | Да, если автоматическое включение постоянства прошло успешно | Да |
| **Начать новую сессию** | Требуется отдельное новое рабочее пространство | Только если новая сессия создана и активирована успешно | Да |
| **Выбрать сохранённую сессию** | Нужно выбрать одну из нескольких существующих рабочих сред | Только если выбранная сессия активирована успешно | Да |
| **Запустить без сохранения** | Необходимо чистое временное окружение без постоянства | Нет | Да |
| **Запустить из RAM** | Требуется скопировать MiniOS в RAM для этой загрузки | Нет; копия RAM считается временной | Пока MiniOS не отсоединит источник успешно |

Для обычной первой загрузки оставьте выбранным пункт **Запустить MiniOS**. Используйте **Запустить без сохранения**, если требуется чистое временное тестирование оборудования или восстановительная сессия, в которой не должно быть постоянства.

::: warning Убедитесь, что постоянство активно
Выбор пункта меню с постоянством запрашивает сессию, но не гарантирует, что она откроется. Если хранилище только для чтения, заполнено, повреждено или несовместимо, MiniOS может продолжить работу без сохранения изменений. Проверьте предупреждение при запуске, прежде чем приступать к работе, которую нужно сохранить.
:::

## Запустить MiniOS

**Запустить MiniOS** — это первый и основной пункт меню, предназначенный для обычного использования, включая первую загрузку только что подготовленного устройства MiniOS.

MiniOS автоматически ищет совместимую постоянную сессию. Если доступна рабочая сессия по умолчанию, она будет восстановлена. Если подходящей сессии нет, MiniOS может автоматически создать новую совместимую сессию при наличии подходящего записываемого хранилища.

Если создать или активировать постоянство не удалось (например, если хранилище только для чтения, заполнено, повреждено или не подходит), MiniOS продолжит работу с временным записываемым слоем и сообщит, что сессия не постоянная. Обратите внимание на это предупреждение, если ваша работа должна сохраниться после перезагрузки.

## Начать новую сессию

MiniOS создаёт дополнительную пронумерованную постоянную сессию, не затрагивая существующие. Используйте этот режим, чтобы разделить рабочие пространства или протестировать новую конфигурацию без замены текущей рабочей сессии.

Для создания требуется совместимое записываемое хранилище и достаточно свободного места. Новая сессия не является резервной копией существующей.

## Выбрать сохранённую сессию

MiniOS отображает доступные сохранённые сессии и позволяет выбрать одну из них. Используйте этот вариант, если на одном устройстве хранится несколько рабочих сред. Чтобы создать первую сессию на пустом носителе, выберите **Начать новую сессию**.

Сессия может быть несовместимой, если она создана в другой версии или редакции MiniOS. Также несовместимость может возникнуть из-за отличающейся настройки `union=`. Интерактивный выбор не делает несовместимую сессию безопасной.

## Запустить без сохранения

В этом режиме постоянство намеренно отключается для текущей загрузки. MiniOS использует временную область для записи в RAM, поэтому все файлы, созданные в live-системе, установленные пакеты и изменённые настройки исчезнут после завершения работы.

Используйте этот режим, если вам нужно:

- протестировать оборудование без открытия или создания постоянной сессии;
- диагностировать проблему без изменения сохранённого состояния;
- временно поработать, когда ничего не требуется сохранять.

Запуск без сохранения не означает, что загрузочный носитель можно извлечь. Обычно работающая система продолжает считывать системные модули с этого носителя.

## Запустить из RAM

В этом режиме данные MiniOS копируются в RAM, чтобы уменьшить количество чтений с исходного носителя. Для этого требуется достаточно памяти для копируемой системы и текущей рабочей нагрузки.

Сессию, загруженную через RAM, следует считать временной. Если совместить `toram` с постоянством, данные выбранной сессии копируются в RAM; последующие изменения не возвращаются в исходное хранилище постоянства.

Не извлекайте загрузочное устройство только потому, что выбран пункт **Запустить из RAM**. Это безопасно только после того, как MiniOS успешно отсоединит исходную файловую систему, ISO-образ и все сопутствующие маппинги Ventoy. Если операция не удалась, источник продолжает использоваться.

## Нативная установка

::: warning Нативная установка изменяет системную модель
Нативная установка сохраняет привычный рабочий стол MiniOS — его визуальный стиль, выбранную среду рабочего стола и стандартные приложения, — но преобразует live-образ в обычную рабочую станцию Debian. Инструменты MiniOS, связанные с сессиями, модулями, модульными ядрами и другими live-функциями, удаляются, так как эти возможности больше не актуальны.
:::

После нативного преобразования используйте стандартные средства Debian для управления пакетами, ядром, настройками и загрузчиком. Внешний вид системы и обычные приложения выбранной редакции сохраняются, однако набор live-функций MiniOS больше не доступен. Архитектура live-режима MiniOS описана в разделе [О MiniOS](/getting-started/About-MiniOS).

Используйте [Установщик MiniOS](/installing-minios/MiniOS-Installer) только если вы действительно хотите выполнить такое преобразование и выбранный образ поддерживает нативное развертывание.
