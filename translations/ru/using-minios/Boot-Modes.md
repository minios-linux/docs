# Режимы загрузки

Режим загрузки определяет, будет ли MiniOS запускаться «с нуля», открывать сохранённую сессию или работать как обычная установленная система. Для выбора подходящего варианта не требуется знать внутренние детали процесса загрузки.

Названия пунктов меню могут немного отличаться в разных версиях, режимах прошивки и загрузочных утилитах. Ориентируйтесь на необходимый результат, а не на точное совпадение формулировок.

## Быстрый выбор

Обычный пункт по умолчанию — **Запустить MiniOS**. Он использует автоматический выбор постоянства: MiniOS пытается восстановить совместимую сессию по умолчанию и может создать новую, если подходящей сессии нет и доступно подходящее записываемое хранилище.

| Пункт меню | Используйте, когда | Сохраняются ли изменения? | Нужно ли оставлять USB подключённым? |
|---|---|---|---|
| **Запустить MiniOS** (по умолчанию) | Обычное переносное использование | Да, если автоматическое включение постоянства прошло успешно | Да |
| **Начать новую сессию** | Вам нужен отдельный новый рабочий стол | Только если новая сессия создана и активирована успешно | Да |
| **Выбрать сохранённую сессию** | Вам нужно выбрать одну из нескольких существующих рабочих сред | Только если выбранная сессия успешно активирована | Да |
| **Запустить без сохранения** | Вам нужна чистая временная загрузка без постоянства | Нет | Да |
| **Запустить из RAM** | Вы хотите скопировать MiniOS в RAM для этой загрузки | Нет; рассматривайте копию RAM как временную | Пока MiniOS не отсоединит исходник успешно |

Для обычной первой загрузки оставьте **Запустить MiniOS** выбранным. Используйте **Запустить без сохранения** если вам нужен именно чистый временный запуск для тестирования оборудования или восстановления, без открытия или создания постоянства.

::: warning Проверьте, что постоянство активно
Выбор пункта меню с постоянством запрашивает сессию, но не гарантирует, что она будет открыта. Если хранилище только для чтения, заполнено, повреждено или несовместимо, MiniOS может продолжить работу без сохранения изменений. Перед началом работы, которую нужно сохранить, проверьте предупреждение при запуске.
:::

## Запустить MiniOS

**Запустить MiniOS** — это первый и основной пункт меню по умолчанию. Предназначен для обычного использования, в том числе для первой загрузки только что подготовленного устройства MiniOS.

MiniOS автоматически ищет совместимую постоянную сессию. Если подходящая сессия уже есть, она будет восстановлена. Если нет — MiniOS может автоматически создать совместимую сессию, если доступно подходящее записываемое хранилище.

Если создать или активировать постоянство невозможно (например, если хранилище только для чтения, заполнено, повреждено или по другой причине не подходит), MiniOS продолжит работу с временным записываемым слоем и сообщит, что сессия не постоянная. Перед работой, которую нужно сохранить после перезагрузки, обязательно проверьте это предупреждение.

## Начать новую сессию

MiniOS создаёт дополнительную пронумерованную постоянную сессию и не затрагивает уже существующие. Используйте этот режим, чтобы разделять рабочие среды или тестировать новую конфигурацию, не заменяя текущую рабочую сессию.

Для создания требуется совместимое записываемое хранилище и достаточно свободного места. Новая сессия не является резервной копией существующей.

## Выбрать сохранённую сессию

MiniOS показывает доступные сохранённые сессии и позволяет выбрать одну из них. Используйте этот режим, если на одном устройстве хранится несколько рабочих сред. Чтобы создать первую сессию на пустом носителе, выберите **Начать новую сессию** вместо этого.

Сессия может быть несовместимой, если она создана в другой версии или редакции MiniOS. Также несовместимость может возникнуть из-за другого значения `union=` параметра.
Интерактивный выбор не делает несовместимую сессию безопасной.

## Запустить без сохранения

В этом режиме постоянство намеренно отключается для текущей загрузки. MiniOS использует временную область для записи в RAM, поэтому все файлы, созданные в live-системе, установленные пакеты и изменённые настройки будут удалены при выключении.

Используйте этот режим, если вам нужно:

- протестировать оборудование без открытия или создания постоянной сессии;
- диагностировать проблему без изменения сохранённого состояния;
- поработать временно, если ничего не требуется сохранять.

Запуск без сохранения не означает, что загрузочный носитель можно извлечь. Обычно система продолжает читать модули из этого носителя во время работы.

## Запустить из RAM

В этом режиме данные MiniOS копируются в RAM для уменьшения числа обращений к исходному носителю. Для этого требуется достаточно памяти для копируемой системы и выполняемых задач.

Считайте сессию, загруженную через RAM, временной. Если совместить `toram` с постоянством, выбранные данные сессии копируются в RAM; последующие изменения не возвращаются в исходное хранилище постоянства.

Не извлекайте загрузочное устройство только потому, что **Запустить из RAM** был выбран. Это безопасно только после того, как MiniOS успешно отсоединит исходную файловую систему, ISO-образ и все связанные Ventoy-сопоставления. Если операция не удалась, исходный носитель продолжает использоваться.

## Нативная установка

::: warning Нативная установка меняет модель системы
Нативная установка сохраняет привычный рабочий стол MiniOS — его внешний вид, выбранное окружение и стандартные приложения — но преобразует live-образ в обычную Debian-систему. Инструменты MiniOS, связанные с сессиями, модулями, модульными ядрами и другими live-функциями, будут удалены, так как эти возможности больше не применимы.
:::

После нативного преобразования используйте стандартные инструменты Debian для управления пакетами, ядром, настройками и загрузчиком. Внешний вид и стандартные приложения выбранной редакции сохраняются, но набор live-функций MiniOS больше не доступен. Архитектура live-режима MiniOS описана в [О проекте MiniOS](/getting-started/About-MiniOS).

Используйте [Установщик MiniOS](/installing-minios/MiniOS-Installer) только если вы действительно хотите такое преобразование и выбранный образ поддерживает нативную установку.
