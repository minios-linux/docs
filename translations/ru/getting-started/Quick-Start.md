# Быстрый старт

В этом руководстве описан путь от загруженного образа MiniOS до рабочей системы. Здесь рассматриваются только основные решения для первого запуска; подробности по каждому этапу приведены в связанных руководствах.

## 1. Загрузите MiniOS

Выберите редакцию, которая лучше всего соответствует вашим задачам:

| Редакция | Оптимально для |
|---|---|
| **Standard** | **Рекомендуется большинству пользователей и для первого знакомства с MiniOS.** Минимальная система с базовым функционалом и компактным, производительным рабочим столом Xfce для повседневной работы. |
| **Toolbox** | Редакция для администрирования и диагностики системы, предназначенная для профессиональной работы IT-специалистов и восстановления системы. Включает Standard, а также инструменты для администрирования, восстановления, работы с сетью, тестирования оборудования, резервного копирования и удалённого доступа. |
| **Ultra** | Полноценный рабочий стол с широким набором приложений и профессиональных инструментов для творчества и разработки. Включает Toolbox, а также офисные, графические, видео-, аудио-, 3D-, инструменты для разработки и работы с контейнерами. |
| **Flux** | Очень лёгкая редакция на базе Fluxbox для минимального использования ресурсов и старого оборудования. В ней меньше приложений и удобств рабочего стола по сравнению со Standard. **Не рекомендуется новичкам.** |

Доступность конкретных пакетов и рабочих столов зависит от выпуска. См. [О редакциях MiniOS](/getting-started/About-MiniOS) для описания модели редакций и [Пакеты и редакции](/reference/Package-and-Edition-Contents) для актуального списка поддерживаемых пакетов.

Скачайте ISO с [сайта MiniOS](https://minios.dev), официальной страницы [GitHub Releases](https://github.com/minios-linux/minios-live/releases), или с [SourceForge](https://sourceforge.net/projects/minios-linux/).

## 2. Проверьте загрузку

Перед установкой проверьте ISO. Выпуски MiniOS предоставляют соответствующий `.iso.sha256` файл; см. [Проверка загрузок](/installing-minios/Verifying-Downloads) для команд Linux, macOS и Windows.

## 3. Установите MiniOS

Для MiniOS запись системы на съёмный носитель уже является способом установки: итоговое устройство становится загрузочным MiniOS-устройством.

Выберите способ установки в зависимости от желаемого результата:

| Что нужно получить | Метод | Результат |
|---|---|---|
| Обычный USB-накопитель, который также загружает MiniOS | [Rufus](/installing-minios/installation-tools/Rufus) в обычном ISO-режиме или [Установка на основе файлов](/installing-minios/Manual-File-Based-Installation) | Файлы MiniOS и загрузчик находятся на обычной файловой системе, поэтому накопитель можно использовать и для хранения обычных файлов |
| MiniOS вместе с другими ISO-образами | [Ventoy](/installing-minios/installation-tools/Ventoy) | Ventoy сохраняет свой обычный раздел данных, поддерживает мультизагрузку, а MiniOS поддерживает постоянные сессии на этой разметке |
| Управляемая переносимая установка MiniOS | [Установщик MiniOS](/installing-minios/MiniOS-Installer) в **Live** режиме | Создаёт модульную установку MiniOS и может настраивать постоянное хранилище |
| Точное поблочное копирование ISO | [Rufus](/installing-minios/installation-tools/Rufus) в режиме DD, [Balena Etcher](/installing-minios/installation-tools/Balena-Etcher), [Дисковая утилита](/installing-minios/installation-tools/Drive-Utility), или [`dd`](/installing-minios/installation-tools/dd) | Воспроизводит поблочную структуру ISO; просто и предсказуемо, но устройство перестаёт работать как обычная флешка общего назначения |

Если вы хотите использовать переносимый накопитель и для обычного хранения файлов, предпочтительнее использовать Rufus в ISO-режиме, установку на основе файлов, Ventoy или подходящую Live-установку, выполненную с помощью Установщика MiniOS. Запись образа в "сырое" состояние полезна, если важнее точное копирование опубликованного образа, чем возможность использовать устройство для хранения данных.

::: danger Проверьте целевой носитель
Большинство способов установки полностью или частично перезаписывают данные на выбранном устройстве.
Сделайте резервную копию важных данных и убедитесь в правильности модели и объёма устройства перед началом.
:::

См. [Установка MiniOS](/installing-minios/Installation-Methods) для различий между записью "сырых" образов, Ventoy, файловыми разметками и Установщиком MiniOS.

## 4. Первый запуск MiniOS

1. Перезагрузите компьютер с подключённым устройством MiniOS.
2. Откройте меню загрузки прошивки компьютера и выберите это устройство.
3. Оставьте выбранной запись по умолчанию **Запустить MiniOS** и запустите систему.
4. Проверьте, что графика, клавиатура, сеть и нужные накопители работают корректно.

**Запустить MiniOS** — это обычный режим загрузки по умолчанию. Он использует автоматический выбор постоянства: MiniOS пытается возобновить совместимую стандартную сессию и, если подходящей сессии нет, может создать совместимую при наличии подходящего носителя для записи. Если постоянство не может быть активировано, MiniOS продолжает работу с временным слоем записи и сообщает, что изменения не будут сохранены.

Это значит, что для обычного первого запуска не требуется заранее создавать сессию. Выбирайте **Запустить без сохранения** только если вам нужен чистый временный запуск без открытия или создания постоянной сессии.

См. [Режимы загрузки](/using-minios/Boot-Modes) для других вариантов запуска. Если устройство не загружается или важное оборудование не работает, см. [Совместимость оборудования](/getting-started/Hardware-Compatibility) и [Устранение неполадок](/maintenance-and-recovery/Troubleshooting).

## 5. При необходимости выберите другой режим сессии

Для обычного переносимого использования продолжайте использовать запись по умолчанию **Запустить MiniOS**. Другой режим выбирайте только если нужен иной результат:

| Вариант загрузки | Используйте, если | Результат |
|---|---|---|
| **Запустить MiniOS** (по умолчанию) | Обычное переносимое использование | Автоматически возобновляет совместимую стандартную сессию или создаёт новую, если это поддерживается |
| **Начать новую сессию** | Нужна отдельная дополнительная рабочая среда | Создаёт дополнительную пронумерованную постоянную сессию, не затрагивая существующие |
| **Выбрать сохранённую сессию** | Хотите выбрать одну из нескольких существующих рабочих сред | Позволяет выбрать существующую сессию интерактивно |
| **Запустить без сохранения** | Нужен чистый временный запуск без постоянства | Использует временный слой записи в RAM |
| **Запустить из RAM** | Хотите скопировать MiniOS в RAM для этого запуска | Работает с копии RAM; изменения считаются временными |

Автоматическое постоянство требует подходящего носителя для записи. Простая запись ISO не готовит постоянное хранилище. Файловые установки, разметки Ventoy и Live-установки, выполненные с помощью [Установщик MiniOS](/installing-minios/MiniOS-Installer) могут предоставить записываемые разметки для постоянного использования MiniOS. Существующие сессии можно просмотреть и управлять ими через [Управление сессиями](/using-minios/Sessions-and-Persistence).

Перед использованием постоянства перезагрузите систему и убедитесь, что MiniOS сообщает о нужной активной сессии, а тестовое изменение сохраняется после перезагрузки.

## 6. Предварительная настройка MiniOS

Большинство инструментов настройки, специфичных для MiniOS, готовят параметры для следующей загрузки или новой сессии, а не меняют текущий рабочий стол сразу.

Используйте **Конфигуратор MiniOS** для предварительной настройки: язык, часовой пояс, клавиатура, имя компьютера, службы, параметры по умолчанию для учётных записей, политика безопасности и другие параметры запуска MiniOS. Откройте через меню приложений или выполните:

```bash
minios-configurator
```

Для обычных настроек во время работы, таких как сетевые подключения, звук, параметры дисплея и настройки приложений, используйте стандартные инструменты рабочего стола и Linux.
Некоторые параметры Конфигуратора MiniOS применяются при следующей загрузке, а настройки учётных записей и безопасности — только при создании новой сессии. См. [Конфигуратор MiniOS](/preparing-and-customizing/Preconfiguring-MiniOS) для точного описания поведения.
