# Быстрый старт

Это руководство проведёт вас от скачанного образа MiniOS до рабочей системы. Здесь рассматриваются только основные решения для первого запуска; связанные руководства подробно объясняют каждую тему.

## 1. Скачайте MiniOS

Выберите редакцию, которая лучше всего соответствует вашим задачам:

| Редакция | Лучше всего подходит для |
|---|---|
| **Standard** | **Рекомендуется большинству пользователей и для первого знакомства с MiniOS.** Минимальная система с базовой функциональностью и компактным, быстрым рабочим столом Xfce для повседневной работы. |
| **Toolbox** | Редакция для администрирования и диагностики системы, предназначенная для профессиональной работы IT-специалистов и восстановления системы. Включает Standard плюс соответствующие инструменты для администрирования, восстановления, работы с сетью, тестирования оборудования, резервного копирования и удалённого доступа. |
| **Ultra** | Полноценный рабочий стол с широким набором приложений и профессиональных инструментов для творчества и разработки. Включает Toolbox, а также офисные, графические, видео-, аудио-, 3D-, инструменты для разработки и контейнерные приложения. |
| **Flux** | Сверхлёгкая редакция на базе Fluxbox для минимального использования ресурсов и старого оборудования. Содержит меньше приложений и удобств рабочего стола по сравнению со Standard. **Не рекомендуется новичкам.** |

Точный набор пакетов и доступность рабочих столов зависят от релиза. Подробнее см. в разделе [О MiniOS](/getting-started/About-MiniOS) о модели редакций и [Пакеты и редакции](/reference/Package-and-Edition-Contents) о поддерживаемых пакетах.

Скачайте ISO с [сайта MiniOS](https://minios.dev), с официальной [страницы релизов на GitHub](https://github.com/minios-linux/minios-live/releases) или с [SourceForge](https://sourceforge.net/projects/minios-linux/).

## 2. Проверьте скачанный файл

Перед установкой проверьте ISO. Релизы MiniOS сопровождаются соответствующим файлом `.iso.sha256`; см. раздел [Проверка загрузок](/installing-minios/Verifying-Downloads) для команд в Linux, macOS и Windows.

## 3. Установите MiniOS

Для MiniOS запись системы на съёмный носитель уже является способом установки: итоговое устройство — это загрузочная система MiniOS.

Выберите способ в зависимости от желаемого результата:

| Что нужно | Метод | Результат |
|---|---|---|
| Обычная USB-флешка, которая также загружает MiniOS | [Rufus](/installing-minios/installation-tools/Rufus) в обычном ISO-режиме или [Файловая установка](/installing-minios/Manual-File-Based-Installation) | Файлы MiniOS и загрузчик находятся на обычной файловой системе, поэтому флешку можно использовать и для обычных файлов |
| MiniOS вместе с другими ISO-образами | [Ventoy](/installing-minios/installation-tools/Ventoy) | Ventoy сохраняет обычный раздел данных, поддерживает мультизагрузку, а MiniOS поддерживает постоянные сессии на такой разметке |
| Управляемая портативная установка MiniOS | [Установщик MiniOS](/installing-minios/MiniOS-Installer) в режиме **Live** | Создаёт модульную установку MiniOS и может настраивать постоянное хранилище |
| Точная поблочная копия ISO | [Rufus](/installing-minios/installation-tools/Rufus) в режиме DD, [Balena Etcher](/installing-minios/installation-tools/Balena-Etcher), [Дисковая утилита](/installing-minios/installation-tools/Drive-Utility), или [`dd`](/installing-minios/installation-tools/dd) | Воспроизводит структуру ISO поблочно; просто и предсказуемо, но устройство больше не работает как обычная флешка общего назначения |

Если вам нужна портативная флешка, которую вы также хотите использовать для хранения обычных файлов, отдайте предпочтение Rufus в режиме ISO, файловой установке, Ventoy или подходящей Live-установке, созданной с помощью Установщика MiniOS. Запись образа в "сырое" устройство полезна, когда важнее получить точную копию опубликованного образа, чем возможность использовать устройство для хранения данных.

::: danger Проверьте целевой носитель
Большинство способов установки перезаписывают часть или все данные на выбранном устройстве.
Сделайте резервную копию важных данных и убедитесь в правильности модели и объёма устройства перед началом.
:::

Подробнее о различиях между записью "сырых" образов, Ventoy, файловыми разметками и Установщиком MiniOS читайте в разделе [Установка MiniOS](/installing-minios/Installation-Methods).

## 4. Первый запуск MiniOS

1. Перезагрузите компьютер с подключённым устройством MiniOS.
2. Откройте меню загрузки (boot menu) в прошивке компьютера и выберите это устройство.
3. Оставьте выбранной запись **Start MiniOS** по умолчанию и запустите систему.
4. Проверьте, что графика, клавиатура, сеть и нужные накопители работают корректно.

**Start MiniOS** — это обычный режим загрузки по умолчанию. Он использует автоматический выбор постоянства: MiniOS пытается восстановить совместимую сессию по умолчанию и, если подходящей сессии нет, может создать новую, если доступно подходящее записываемое хранилище. Если постоянство не может быть активировано, MiniOS продолжает работу с временным записываемым слоем и сообщает, что изменения не будут сохранены.

Это значит, что для обычной первой загрузки не требуется заранее создавать сессию. Выбирайте **Запуск без сохранения**, только если вам нужен чистый временный запуск без открытия или создания постоянной сессии.

См. [Режимы загрузки](/using-minios/Boot-Modes) для других вариантов запуска. Если устройство не загружается или важное оборудование не работает, обратитесь к разделам [Совместимость оборудования](/getting-started/Hardware-Compatibility) и [Устранение неполадок](/maintenance-and-recovery/Troubleshooting).

## 5. При необходимости выберите другое поведение сессии

Для обычного портативного использования продолжайте запускать систему через запись **Start MiniOS** по умолчанию. Выбирайте другой режим только если нужен иной результат:

| Вариант загрузки | Используйте, когда | Результат |
|---|---|---|
| **Start MiniOS** (по умолчанию) | Обычное портативное использование | Автоматически восстанавливает совместимую сессию по умолчанию или создаёт новую, если поддерживается |
| **Начать новую сессию** | Требуется отдельное дополнительное рабочее пространство | Создаёт дополнительную пронумерованную постоянную сессию, существующие сессии не изменяются |
| **Выбрать сохранённую сессию** | Нужно выбрать одну из нескольких рабочих сред | Позволяет интерактивно выбрать существующую сессию |
| **Запуск без сохранения** | Нужна чистая временная загрузка без постоянства | Использует временный записываемый слой в RAM |
| **Запуск из RAM** | Нужно скопировать MiniOS в RAM для этой загрузки | Запускается из копии RAM; изменения считаются временными |

Автоматическое постоянство всё равно требует подходящего записываемого хранилища. Простая запись ISO не подготавливает постоянное хранилище. Файловые установки, разметки Ventoy и Live-установки, созданные через [Установщик MiniOS](/installing-minios/MiniOS-Installer), могут предоставлять записываемые разметки для постоянного использования MiniOS. Просмотреть и управлять существующими сессиями можно через [Управление сессиями](/using-minios/Sessions-and-Persistence).

Перед тем как полагаться на постоянство, перезагрузитесь и убедитесь, что MiniOS сообщает о нужной активной сессии и что тестовое изменение сохраняется после перезагрузки.

## 6. Предварительная настройка MiniOS

Большинство инструментов настройки, специфичных для MiniOS, подготавливают параметры для следующей загрузки или новой сессии, а не изменяют текущий рабочий стол сразу.

Используйте **Конфигуратор MiniOS** для предварительной настройки: локаль, часовой пояс, клавиатуру, имя хоста, службы, параметры учётных записей, политику безопасности и другие параметры запуска MiniOS. Откройте его из меню приложений или выполните:

```bash
minios-configurator
```

Для обычных параметров во время работы, таких как сетевые подключения, звук, настройка дисплея и предпочтения приложений, используйте стандартные инструменты рабочего стола и Linux.
Некоторые параметры Конфигуратора MiniOS применяются при следующей загрузке, а настройки учётных записей и безопасности — только при создании новой сессии. Подробнее см. в разделе [Конфигуратор MiniOS](/preparing-and-customizing/Preconfiguring-MiniOS).
