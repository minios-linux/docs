# Начало работы с MiniOS 🌟

Добро пожаловать в MiniOS — здесь гибкость и портативность Linux сочетаются с удобством и простотой использования. Если вы впервые используете MiniOS, это подробное руководство поможет вам быстро освоиться и максимально эффективно использовать вашу операционную систему.

## Шаг 1: Выберите подходящую редакцию MiniOS 📦

MiniOS предлагает три основных редакции, каждая из которых оптимизирована под определённые задачи:

- **🚀 Standard** — надёжная рабочая лошадка для повседневных задач
- **🧰 Toolbox** — набор инструментов для опытных пользователей с расширенными системными утилитами
- **⚡ Ultra** — универсальная редакция с полным набором функций

Подробные описания возможностей каждой редакции и установленного ПО смотрите в разделе [О MiniOS](/about/About-MiniOS.md).

**Варианты загрузки:**
- **Официальный сайт**: [minios.dev](https://minios.dev) — полный обзор редакций и прямые ссылки на загрузку
- **GitHub Releases**: [Последние релизы](https://github.com/minios-linux/minios-live/releases) — все версии и примечания к релизам

Для подробного списка пакетов, входящих в каждую редакцию, смотрите [Список пакетов](/administration/Packages.md).

- **Standard (787 МБ)**: минимум 2 ГБ
- **Toolbox (1,2 ГБ)**: минимум 4 ГБ
- **Ultra (1,7 ГБ)**: минимум 4 ГБ
- **Рекомендуемый размер**: 8 ГБ и более для комфортной работы с сохранением изменений

## Шаг 3: Загрузка и знакомство 🖥️

После загрузки с USB ознакомьтесь с рабочим столом MiniOS:

**Основные возможности:**
- Меню приложений (нижняя левая панель)
- Системные настройки и параметры
- Файловый менеджер (Thunar)
- Предустановленные приложения (браузер, офисный пакет, утилиты)
- Настройки оформления рабочего стола

Рабочее окружение по умолчанию — XFCE, обеспечивающее баланс между функциональностью и производительностью.

## Шаг 4: Настройка системы 🌐

**Настройте язык системы, клавиатуру, часовой пояс и другие параметры:**

### 🔧 **Использование MiniOS Configurator** (рекомендуется)

**Доступ:** Меню приложений → Система → Настроить MiniOS

**Основные параметры для настройки:**
- **🌍 Язык и локаль**: выбор языка системы (например, `en_US.UTF-8`, `ru_RU.UTF-8`, `pt_BR.UTF-8`)
- **⏰ Часовой пояс**: настройка часового пояса (например, `Europe/Berlin`, `America/New_York`, `Asia/Tokyo`)
- **⌨️ Клавиатура**: выбор раскладок и переключения (например, `us,ru` с переключением `Alt+Shift`)
- **👤 Пользователь**: изменение имени пользователя, полного имени и групп
- **🔐 Пароли**: установка безопасных паролей для пользователя и root
- **🖥️ Система**: настройка имени хоста, включение/отключение сервисов
- **🔧 Дополнительно**: параметры загрузки и поведение системы

**Как использовать:**
1. Откройте MiniOS Configurator через системное меню
2. Переключайтесь по вкладкам для настройки различных параметров
3. Внесите изменения и сохраните
4. **Перезагрузите систему для применения изменений** — настройки вступают в силу после перезапуска и сохраняются между загрузками

**Техническая справка:** MiniOS Configurator изменяет файл `/etc/live/config.conf`, который является основным конфигурационным файлом MiniOS и управляет поведением системы при загрузке. Для подробной информации о параметрах смотрите руководство [Конфигурационный файл](/configuration/Configuration-File.md).

### 💻 **Альтернатива: настройка через командную строку**

**Изменения применяются сразу:**
```bash
# Set system locale for current session
sudo localectl set-locale LANG=en_US.UTF-8

# Set keyboard layout with switching
sudo localectl set-x11-keymap us,ru pc105 ,dvorak grp:alt_shift_toggle

# Set timezone
sudo timedatectl set-timezone Europe/Berlin

# Change user password
passwd live
```

**Для сохранения изменений между перезагрузками:** используйте MiniOS Configurator или редактируйте `/etc/live/config.conf` вручную.

### 📋 **Дополнительные параметры настройки**

- **Ручное редактирование файлов**: для опытных пользователей — редактируйте `/etc/live/config.conf` вручную
- **Настройка при загрузке**: используйте [Параметры загрузки](/configuration/Boot-Parameters.md) для конфигурации системы до старта
- **Руководство по конфигурации**: подробное описание параметров смотрите в [Конфигурационный файл](/configuration/Configuration-File.md)
- **Предустановка**: настройте систему до установки через [MiniOS Installer](/installation/MiniOS-Installer.md)

**Важно:** Изменения в `/etc/live/config.conf` (через MiniOS Configurator или вручную) требуют перезагрузки для вступления в силу. Инструменты командной строки, такие как `localectl` и `timedatectl`, применяют изменения сразу, но они могут не сохраняться между перезагрузками без дополнительной настройки.

## Шаг 5: Установка программ 🔄

MiniOS предоставляет несколько способов установки программ:

### 📦 **Пакетный менеджер APT**

Базовое управление пакетами Debian — используйте `man apt` для подробной справки по командам.

### 🔄 **Система модулей**

Расширенные SquashFS-модули для постоянного ПО — смотрите руководство [Создание модулей](/development/Creating-Modules.md).

**Ключевое отличие:** установки через APT требуют сохранения изменений для работы после перезагрузки, а модули сохраняются автоматически.

## Шаг 6: Сохранение данных 💾

**Хорошая новость:** MiniOS автоматически настраивает сохранение данных при установке! Ваши файлы, настройки и установленные программы сохраняются автоматически.

### Как это работает

- **Автоматическая настройка**: все способы установки создают сохранение данных автоматически
- **Умное определение**: система выбирает оптимальный режим сохранения для вашей файловой системы
- **Портативность**: ваши данные всегда с вами на USB-носителе

### Расширенная настройка

Для индивидуальной настройки сохранения данных смотрите подробное руководство по [Конфигурационному файлу](/configuration/Configuration-File.md) и справочник по [Параметрам загрузки](/configuration/Boot-Parameters.md).

## Шаг 7: Настройка безопасности 🔐

### 👤 **Учётные записи по умолчанию**

- **Пользователь**: `live` / `evil`
- **Root**: `root` / `toor`

### 🔒 **Важные шаги по безопасности**

1. **Сразу смените пароли** — стандартные данные для входа известны всем
2. **Используйте надёжные уникальные пароли** для всех учётных записей

### Способы настройки пароля

- **🔧 Рекомендуется**: используйте **MiniOS Configurator** (Меню приложений → Система → Настроить MiniOS → вкладка Пользователь)
- **💻 Командная строка**: `passwd live` и `sudo passwd root`
- **📋 Для опытных**: смотрите руководство [Усиление безопасности](/administration/Security-Hardening.md) для детальной настройки

⚠️ **Никогда не используйте стандартные пароли в сетевых системах!**
