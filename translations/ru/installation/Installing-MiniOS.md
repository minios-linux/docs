# Установка MiniOS

Существует две отдельные задачи, которые часто называют установкой:

- Запись ISO на съемный носитель создает загрузочный носитель, используемый для запуска live-сессии MiniOS. Инструменты для записи образов полностью перезаписывают выбранное устройство структурой ISO.
- Запуск [MiniOS Installer](/installation/MiniOS-Installer.md) из live-сессии разворачивает MiniOS на другой диск. Это позволяет создать либо модульную live-установку, либо обычную нативную установку Linux.

## Загрузка и проверка ISO

Скачайте ISO с [официального сайта](https://minios.dev) или с официальной страницы [GitHub Releases](https://github.com/minios-linux/minios-live/releases). Перед записью на устройство проверьте образ; см. [Проверка загрузок](/installation/Verifying-Downloads.md).

## Запись загрузочного носителя

Выберите способ для вашей операционной системы:

- [Rufus](/installation/tools/Rufus.md) для Windows
- [Ventoy](/installation/tools/Ventoy.md) для Windows или Linux
- [Balena Etcher](/installation/tools/Balena-Etcher.md) для Windows, Linux или macOS
- [`dd`](/installation/tools/dd.md) для Linux или macOS
- [Drive Utility](/installation/tools/Drive-Utility.md) для Linux
- [UNetbootin](/installation/tools/UNetbootin.md) для Windows, Linux или macOS
- [Оригинальный метод](/installation/tools/Original-Method.md) для файловой структуры MiniOS

Запись образа с помощью Rufus, Etcher, `dd` или Drive Utility является разрушительной. Перед началом убедитесь в правильности пути к устройству, модели и объема. Эти инструменты создают загрузочный носитель; они не выполняют live- или нативную установку с помощью MiniOS Installer.

Ventoy работает иначе: установите Ventoy на устройство, затем скопируйте ISO на его раздел данных. Это сохраняет мультизагрузочную структуру Ventoy.

## Загрузка live-сессии

1. Перезагрузите компьютер и откройте меню загрузки прошивки.
2. Выберите USB-устройство или другой загрузочный носитель.
3. Запустите MiniOS и проверьте работу накопителей, сети и устройств ввода.

Настройки прошивки зависят от компьютера. Образ MiniOS может загружаться через BIOS или UEFI; цель последующей установки MiniOS Installer не ограничивается MBR.

## Выбор варианта установки

Из live-сессии запустите [MiniOS Installer](/installation/MiniOS-Installer.md), если хотите установить MiniOS на другой USB-накопитель, SSD или жесткий диск.

- Live-режим сохраняет сжатую структуру модулей и live-загрузку. Поддерживается опциональное сохранение сессии, что удобно для переносимых установок.
- Нативный режим разворачивает выбранные модули в стандартную корневую файловую систему Linux, генерирует initramfs и устанавливает поддерживаемый загрузчик. Нативный режим доступен только при наличии необходимой метаинформации в загруженном образе.

Установщик поддерживает автоматические схемы BIOS/MBR, UEFI/MBR и UEFI/GPT. BIOS на GPT не поддерживается текущим установщиком. Подробнее о размещении, файловых системах, сохранении данных и ограничениях разделов см. в разделе [Использование MiniOS Installer](/installation/MiniOS-Installer.md).
