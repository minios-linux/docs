# Установка MiniOS

Существует две отдельные задачи, которые часто называют установкой:

- Запись ISO на съемный носитель создает загрузочный носитель, используемый для запуска live-сессии MiniOS. Инструменты для записи образов полностью перезаписывают выбранное устройство структурой ISO.
- Запуск [MiniOS Installer](/installation/MiniOS-Installer.md) из live-сессии разворачивает MiniOS на другой диск. Это позволяет создать либо модульную live-установку, либо обычную нативную установку Linux.

## Загрузка и проверка ISO

Скачайте ISO с [официального сайта](https://minios.dev) или с официальной страницы [GitHub Releases](https://github.com/minios-linux/minios-live/releases). Перед записью на устройство проверьте образ; см. [Проверка загрузок](/installation/Verifying-Downloads.md).

## Запись загрузочного носителя

Выберите способ для вашей операционной системы:

- [Rufus](/installation/tools/Rufus.md) в Windows
- [Ventoy](/installation/tools/Ventoy.md) в Windows или Linux
- [Balena Etcher](/installation/tools/Balena-Etcher.md) в Windows, Linux или macOS
- [`dd`](/installation/tools/dd.md) в Linux или macOS
- [Drive Utility](/installation/tools/Drive-Utility.md) в Linux
- [UNetbootin](/installation/tools/UNetbootin.md) в Windows, Linux или macOS
- [Оригинальный способ](/installation/tools/Original-Method.md) для файловой структуры MiniOS

Запись образа с помощью Rufus, Etcher, `dd` или Drive Utility приводит к удалению всех данных на выбранном устройстве. Перед началом убедитесь в правильности пути к устройству, его модели и объёма. Запись "сырых" образов полностью воспроизводит структуру образа; при этом не настраивается сохранение данных и не выполняется ни живая, ни штатная установка через MiniOS Installer.

Ventoy работает иначе: сначала установите Ventoy на устройство, затем скопируйте ISO на его раздел данных. Это сохраняет мультизагрузочную структуру Ventoy.

## Загрузка в живом режиме

1. Перезагрузите компьютер и откройте меню загрузки прошивки.
2. Выберите USB-устройство или другой загрузочный носитель.
3. Запустите MiniOS и проверьте работу хранилища, сети и устройств ввода.

Настройки прошивки различаются в зависимости от компьютера. Образ MiniOS может загружаться через BIOS или UEFI; целевой диск для последующей установки через MiniOS Installer не ограничен только MBR.

Используйте [Режимы загрузки](/configuration/Boot-Modes.md) как основной источник информации о поведении живой загрузки. Если на раннем этапе загрузки не удаётся найти образ или его модули, обратитесь к разделу [Обнаружение системы initrd](/configuration/Initrd-System-Discovery.md).

## Выбор типа установленной системы

Из живой сессии запустите [MiniOS Installer](/installation/MiniOS-Installer.md), если хотите установить MiniOS на другой USB-накопитель, SSD или жёсткий диск.

- Live-режим сохраняет сжатый стек модулей и структуру живой загрузки. Он поддерживает опциональное сохранение данных сессии и подходит для переносимых установок.
- Native-режим разворачивает выбранные модули в стандартную корневую файловую систему Linux, генерирует initramfs и устанавливает поддерживаемый загрузчик. Native-режим доступен только если загруженный образ содержит необходимые метаданные для инсталлятора.

Сохранение данных в live-режиме настраивается на раннем этапе загрузки; подробности описаны в разделе [Сохранение данных initrd](/configuration/Initrd-Persistence.md). Это не относится к обычной корневой файловой системе, используемой в native-режиме.

Инсталлятор поддерживает автоматические схемы BIOS/MBR, UEFI/MBR и UEFI/GPT. BIOS на GPT не поддерживается текущей версией инсталлятора. Подробнее о размещении, файловых системах, сохранении данных и ограничениях по разметке читайте в разделе [Использование MiniOS Installer](/installation/MiniOS-Installer.md).
