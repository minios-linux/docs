# Использование MiniOS Installer

MiniOS Installer — это графический инструмент для установки MiniOS на жёсткие диски или USB-накопители с поддержкой UEFI/BIOS и совместимостью с различными файловыми системами.

## Важно

⚠️ **Внимание:** Неправильный выбор устройства приведёт к потере данных! Всегда тщательно проверяйте выбранное устройство и делайте резервные копии важных данных.

## Требования к накопителю

### Размер накопителя

См. [Руководство по совместимости оборудования](Hardware-Compatibility.md#system-requirements) для подробных системных требований и размеров накопителей.

### Поддерживаемые файловые системы

- **ext4** (рекомендуется для Linux)
- **Btrfs** (современная файловая система с поддержкой снимков)
- **FAT32** (максимальная совместимость)
- **NTFS** (совместимость с Windows)

## Создание установки

### Запуск MiniOS Installer

**Через меню приложений:**
1. Откройте меню → Система → "Установить MiniOS"

**Через терминал:**
```bash
sudo minios-installer
```

### Процесс установки

1. **Настройка параметров системы (необязательно, но рекомендуется):**
   - Нажмите кнопку **"Настроить MiniOS перед установкой"**
   - Установите ваши предпочтения:
     - Язык системы и локаль
     - Часовой пояс и раскладку клавиатуры  
     - Учётные записи и пароли
     - Имя хоста и системные службы
   - Сохраните и закройте конфигуратор
   
2. **Выбор целевого устройства:**
   - Выберите жёсткий диск или USB-накопитель из списка
   - Проверьте размер и модель устройства
   
3. **Выбор файловой системы:**
   - **ext4**: рекомендуется в большинстве случаев
   - **Btrfs**: для опытных пользователей
   - **FAT32**: для максимальной совместимости
   
4. **Подтверждение очистки диска:**
   - Все данные на выбранном устройстве будут удалены
   - Убедитесь в правильности выбора устройства
   
5. **Запуск установки:**
   - Нажмите кнопку "Установить"
   - Дождитесь завершения процесса
   
6. **Завершение:**
   - Перезагрузите систему
   - Извлеките LiveUSB/LiveCD
   - **Результат:** Система загружается с вашими предварительно настроенными параметрами

## Предустановка конфигурации

### Преимущества использования конфигуратора MiniOS перед установкой

**Рекомендуемый порядок для новых пользователей:**

1. **Однократная настройка**: Настройте все параметры системы один раз перед установкой
2. **Готово к использованию**: Установленная система загружается с правильными языковыми, клавиатурными и пользовательскими настройками
3. **Без дополнительной настройки**: Не требуется ручная конфигурация после первого запуска
4. **Единый опыт**: Одинаковые настройки на всех установках

**Доступные параметры конфигурации:**
- **🌍 Локализация**: Язык системы, локаль и часовой пояс
- **⌨️ Ввод**: Раскладки клавиатуры и параметры переключения  
- **👤 Учётные записи**: Имя пользователя, полное имя, пароли и группы
- **🖥️ Система**: Имя хоста, включённые/отключённые службы
- **🔒 Безопасность**: Безопасная установка пароля до выхода в интернет

**Простой порядок действий:**
- Настройте параметры один раз перед установкой
- Установите MiniOS с вашими настройками
- Загрузитесь в полностью настроенную систему

## Автоматическое сохранение изменений

После установки MiniOS Installer создаёт систему на выбранном устройстве:

- **Совместимость с UEFI/BIOS**: Автоматическое создание необходимых загрузочных разделов
- **Сохранение изменений**: Полная поддержка режимов сохранения MiniOS
- **Файловые системы**: Поддержка ext4, Btrfs, FAT32, NTFS

### Настройка параметров (для опытных пользователей)

Для точной настройки сохранения изменений можно использовать параметры загрузки:

- `perchmode=native` — сохранение напрямую на раздел (при наличии свободного места)
- `perchmode=dynfilefs` — динамически расширяемый файл
- `perchmode=raw` — файл фиксированного размера
- `perchsize=8000` — размер пространства для данных в МБ

Подробнее в [параметрах загрузки](/configuration/Boot-Parameters.md).
