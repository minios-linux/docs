# Проверка загрузок

Релизы MiniOS публикуются на официальной [странице релизов GitHub](https://github.com/minios-linux/minios-live/releases). Для каждого ISO-файла есть соответствующий файл, имя которого заканчивается на `.iso.sha256`.

Проверка SHA-256 позволяет выявить неполную или изменённую загрузку. Она не подтверждает, кто создал файлы. В данный момент релиз содержит только контрольные суммы, а не криптографические подписи, поэтому на этой странице не описывается проверка подписи.

## Загрузите оба файла

Скачайте ISO и соответствующий ему файл `.sha256` из одного и того же релиза на GitHub. Оставьте оба файла в одной папке. Их базовые имена должны совпадать, например:

```text
minios-trixie-xfce-standard-amd64-5.1.1.iso
minios-trixie-xfce-standard-amd64-5.1.1.iso.sha256
```

Используйте имена из того релиза, который вы скачали, в командах ниже.

## Linux

Откройте терминал в папке загрузки и выполните:

```bash
sha256sum --check minios-trixie-xfce-standard-amd64-5.1.1.iso.sha256
```

При успешной проверке будет выведено имя ISO, за которым следует `OK`.

## macOS

Вычислите контрольную сумму ISO:

```bash
shasum -a 256 minios-trixie-xfce-standard-amd64-5.1.1.iso
```

Показать ожидаемую контрольную сумму:

```bash
cat minios-trixie-xfce-standard-amd64-5.1.1.iso.sha256
```

Точно сравните оба 64-символьных шестнадцатеричных значения.

## Windows PowerShell

Откройте PowerShell в папке загрузки и выполните:

```powershell
(Get-FileHash .\minios-trixie-xfce-standard-amd64-5.1.1.iso -Algorithm SHA256).Hash.ToLower()
Get-Content .\minios-trixie-xfce-standard-amd64-5.1.1.iso.sha256
```

Сравните вычисленное значение со значением в начале файла `.sha256`. Сравнение не чувствительно к регистру.

## Если проверка не прошла

Не записывайте и не загружайте ISO. Убедитесь, что ISO и файл контрольной суммы относятся к одному и тому же релизу и редакции, удалите неудачный ISO и скачайте его снова с официальной [страницы релизов MiniOS](https://github.com/minios-linux/minios-live/releases).
