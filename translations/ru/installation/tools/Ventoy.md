# Использование Ventoy

Ventoy — это популярный инструмент для создания загрузочных USB-накопителей, который позволяет хранить несколько ISO-файлов на одном устройстве и загружаться с любого из них.

## Важно

⚠️ **Внимание:** Неправильный выбор устройства приведет к потере данных! Всегда внимательно проверяйте выбранный диск и делайте резервные копии важных данных.

⚠️ **Требование к режиму загрузки:** Для корректной работы MiniOS с Ventoy обязательно выберите **режим GRUB2** при загрузке или переименуйте ваш ISO-файл, добавив суффикс `VTGRUB2` (например, `minios-standard-amd64_VTGRUB2.iso`), чтобы автоматически принудительно включить режим GRUB2.

## Требования к накопителю

### Размер накопителя

Подробные системные требования и рекомендуемые размеры накопителей смотрите в [Руководстве по совместимости оборудования](/installation/Hardware-Compatibility.md).

## Установка Ventoy

### Метод 1: Стандартная установка

1. **Скачайте Ventoy** с [официального сайта](https://www.ventoy.net/)
2. **Запустите установщик Ventoy** и выберите свой USB-накопитель
3. **Установите Ventoy** на накопитель (все данные будут удалены)
4. **Скопируйте ISO-файл MiniOS** в корневую папку USB-накопителя

В результате создаётся мультизагрузочный носитель с ISO-файлами: Ventoy хранит ISO как файл на своем разделе данных и отображает его при загрузке. Это не запись образа MiniOS в "сыром" виде и не установка MiniOS Installer.

### Метод 2: Установка с отдельным разделом для данных (рекомендуется)

1. **Скачайте Ventoy** с [официального сайта](https://www.ventoy.net/)
2. **Запустите установщик Ventoy** и выберите ваш USB-накопитель
3. **Включите опцию "Reserve Space"** при установке, чтобы создать дополнительный раздел
4. **Установите Ventoy** на накопитель
5. **Скопируйте ISO-файл MiniOS** в корневую папку USB-накопителя
6. **Создайте раздел ext4** в зарезервированном пространстве с меткой `persistence`

Это предоставляет возможное место для хранения данных сессии, однако создание раздела само по себе не включает функцию персистентности и не создает сессию.

## Интеграция с MiniOS

MiniOS поддерживает обнаружение ISO-образа, предоставленного Ventoy. Обнаружение источника и выбор места для сохранения данных происходят отдельно; Ventoy сам по себе не включает поддержку сохранения изменений MiniOS.

### Сохранение изменений

Сохранение изменений включается только при наличии соответствующей записи загрузки или параметра ядра. Для активации требуется совместимое место для записи и рабочая сессия; стандартная установка Ventoy не гарантирует автоматическое создание этих условий. Перед использованием сохранения изменений ознакомьтесь с разделами [Режимы загрузки](/configuration/Boot-Modes.md) и [Initrd persistence](/configuration/Initrd-Persistence.md).

## Использование MiniOS с Ventoy

### Загрузка

После установки Ventoy и копирования ISO-файла MiniOS на накопитель:

1. **Загрузитесь с USB-накопителя** — выберите его в BIOS/UEFI
2. **Выберите MiniOS** из списка доступных ISO-файлов в меню Ventoy
3. **⚠️ ВАЖНО: Выберите режим GRUB2** при появлении запроса от Ventoy
4. **Дождитесь загрузки MiniOS**

### **Требования к режиму загрузки Ventoy**

**Для корректной работы MiniOS:**
- **Режим GRUB2** — необходим для правильной работы MiniOS

**Альтернативное решение:**
- Добавьте суффикс `VTGRUB2` к имени ISO-файла (например, `minios-5.0.0-standard-amd64_VTGRUB2.iso`)
- Это заставит Ventoy автоматически использовать режим GRUB2 без запроса
