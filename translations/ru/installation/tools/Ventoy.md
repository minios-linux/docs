# Использование Ventoy

Ventoy — это популярный инструмент для создания загрузочных USB-накопителей, который позволяет хранить несколько ISO-файлов на одном устройстве и загружаться с любого из них.

## Важно

⚠️ **Внимание:** Неправильный выбор устройства приведет к потере данных! Всегда внимательно проверяйте выбранный диск и делайте резервные копии важных данных.

⚠️ **Требование к режиму загрузки:** Для корректной работы MiniOS с Ventoy обязательно выберите **режим GRUB2** при загрузке или переименуйте ваш ISO-файл, добавив суффикс `VTGRUB2` (например, `minios-standard-amd64_VTGRUB2.iso`), чтобы автоматически принудительно включить режим GRUB2.

## Требования к накопителю

### Размер накопителя

См. [Руководство по совместимости оборудования](/installation/Hardware-Compatibility.md#system-requirements) для подробных системных требований и информации о размерах накопителей.

## Установка Ventoy

### Метод 1: Стандартная установка

1. **Скачайте Ventoy** с [официального сайта](https://www.ventoy.net/)
2. **Запустите установщик Ventoy** и выберите ваш USB-накопитель
3. **Установите Ventoy** на накопитель (все данные будут удалены)
4. **Скопируйте ISO-файл MiniOS** в корневую папку USB-накопителя

После установки накопитель будет готов к использованию. MiniOS автоматически создаст хранилище для сохранения изменений.

### Метод 2: Установка с отдельным разделом для данных (рекомендуется)

1. **Скачайте Ventoy** с [официального сайта](https://www.ventoy.net/)
2. **Запустите установщик Ventoy** и выберите ваш USB-накопитель  
3. **Включите опцию "Reserve Space"** при установке, чтобы создать дополнительный раздел
4. **Установите Ventoy** на накопитель
5. **Скопируйте ISO-файл MiniOS** в корневую папку USB-накопителя
6. **Создайте раздел ext4** в зарезервированном пространстве с меткой `persistence`

Этот способ обеспечивает более быструю работу с данными и больший контроль над хранилищем.

## Интеграция с MiniOS

MiniOS включает встроенную поддержку Ventoy и автоматически определяет запуск в среде Ventoy. Система автоматически настраивает сохранение изменений без дополнительной настройки пользователем.

### Автоматическое сохранение изменений

MiniOS автоматически определяет запуск в среде Ventoy и настраивает сохранение изменений:

- **При наличии отдельного раздела `persistence`**: Использует его для прямого хранения данных (нативный режим, максимальная скорость)
- **При стандартной установке**: Создает динамический файл в основной партиции Ventoy (режим dynfilefs)

### Настройка параметров (для опытных пользователей)

Когда требуется точная настройка, можно использовать параметры загрузки:

**Для отдельного раздела `persistence` (доступны все режимы):**
- `perchmode=native` — прямое сохранение в раздел (самый быстрый)
- `perchmode=dynfilefs` — динамически расширяемый файл
- `perchmode=raw` — файл фиксированного размера

**Для стандартной установки Ventoy (доступны два режима):**
- `perchmode=dynfilefs` — динамически расширяемый файл (по умолчанию, экономит место)
- `perchmode=raw` — файл фиксированного размера

**Общие параметры для файлов:**
- `perchsize=8000` — размер пространства для хранения данных в МБ

Подробнее в [параметрах загрузки](/configuration/Boot-Parameters.md).

## Использование MiniOS с Ventoy

### Загрузка

После установки Ventoy и копирования ISO-файла MiniOS на накопитель:

1. **Загрузитесь с USB-накопителя** — выберите его в BIOS/UEFI
2. **Выберите MiniOS** из списка доступных ISO-файлов в меню Ventoy
3. **⚠️ ВАЖНО: Выберите режим GRUB2** при появлении запроса Ventoy
4. **Дождитесь загрузки** — система автоматически настроится для работы

### **Требования к режиму загрузки Ventoy**

**Для корректной работы MiniOS:**
- **Режим GRUB2** — обязателен для правильной работы MiniOS

**Альтернативное решение:**
- Добавьте суффикс `VTGRUB2` к имени ISO-файла (например, `minios-5.0.0-standard-amd64_VTGRUB2.iso`)
- Это позволит Ventoy автоматически использовать режим GRUB2 без запроса
