# Использование Balena Etcher

Balena Etcher — удобная кроссплатформенная программа для записи ISO-образов на USB-накопители. Подходит для Windows, macOS и Linux.

## Важно

⚠️ **Внимание:** Неправильный выбор устройства приведёт к потере данных! Всегда внимательно проверяйте выбранный диск и делайте резервные копии важных данных.

## Требования к накопителю

### Размер накопителя

Подробные системные требования и размеры накопителей смотрите в [Руководстве по совместимости оборудования](/installation/Hardware-Compatibility.md#system-requirements).

## Подготовка

1. Скачайте Balena Etcher с [официального сайта](https://www.balena.io/etcher/)
2. Установите программу на вашу ОС
3. Подключите USB-накопитель

## Создание загрузочного USB-накопителя

1. Запустите Balena Etcher
2. Выберите ISO-образ MiniOS:
   - Нажмите «Flash from file»
   - Укажите путь к ISO-файлу
3. Выберите целевой USB-накопитель:
   - Нажмите «Select target»
   - Проверьте модель и размер устройства
4. Начните запись:
   - Нажмите «Flash!»
   - Дождитесь завершения процесса (5–15 минут)

## Автоматическое сохранение изменений

При первом запуске MiniOS проверит тип файловой системы накопителя и выберет оптимальный режим сохранения изменений. Если доступно свободное место, система автоматически создаст раздел ext4 для максимальной производительности.

### Настройка параметров (для опытных пользователей)

Если требуется точная настройка сохранения изменений, можно использовать параметры загрузки:

- `perchmode=native` — прямое сохранение на раздел (по умолчанию, самый быстрый)
- `perchmode=dynfilefs` — динамически расширяемый файл
- `perchmode=raw` — файл фиксированного размера
- `perchsize=8000` — размер пространства для хранения данных в МБ для файлов-образов

Подробнее в [параметрах загрузки](/configuration/Boot-Parameters.md).
