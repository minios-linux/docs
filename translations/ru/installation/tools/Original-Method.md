# Оригинальный способ установки (Windows/Linux, устаревший)

Этот устаревший способ установки MiniOS предполагает прямое копирование системных файлов на диск и установку загрузчика. Рекомендуется использовать актуальные методы из раздела [Установка MiniOS](/installation/Installing-MiniOS.md), если только не требуется файловая структура.

**Примечание:** Этот способ работает только в Windows и Linux из-за использования загрузчика SYSLINUX.

## Важно

**Предупреждение:** Эта процедура выполняет переразметку и форматирование выбранного устройства. Она уничтожает все данные на устройстве, а не только видимые файлы. Перед запуском `fdisk`, `mkfs` или `bootinst` обязательно сделайте резервную копию важных данных и проверьте точный путь к устройству, модель, ёмкость, раздел и точку монтирования. По возможности отключите другие съёмные накопители.

## Требования к диску

### Размер накопителя

См. [Руководство по совместимости оборудования](/installation/Hardware-Compatibility.md) для подробных системных требований и размеров накопителей.

### Технические требования

- **Файловые системы**: FAT32, NTFS, ext2/3/4, Btrfs
- **Схема разделов**: MBR
- **Загрузка в режиме EFI**: При использовании файловых систем NTFS, exFAT или ext2/3/4 загрузка в режиме EFI может быть недоступна. Для поддержки EFI рекомендуется использовать FAT32.

## Создание загрузочного USB-накопителя

### Шаг 1: Подготовка накопителя

**Windows:**
1. Откройте "Управление дисками" (`Win+R`, затем `diskmgmt.msc`)
2. Проверьте USB-устройство по номеру диска, модели и ёмкости. Не продолжайте, если есть сомнения в деталях.
3. Щёлкните правой кнопкой мыши по его разделу и выберите "Удалить том"
4. Щёлкните правой кнопкой по нераспределённому пространству и выберите "Создать простой том"
5. Выберите файловую систему: FAT32 (рекомендуется) или NTFS

**Linux:**

Указывайте `TARGET_DISK` и `TARGET_PARTITION` только после проверки модели и ёмкости устройства в `lsblk`. Запись `fdisk` заменяет таблицу разделов на всём целевом диске. Выполните только одну команду `mkfs` для нужной файловой системы.

```bash
lsblk -o NAME,PATH,SIZE,FSTYPE,LABEL,MOUNTPOINTS,MODEL
TARGET_DISK=/dev/sdX
TARGET_PARTITION=/dev/sdX1
lsblk -o NAME,PATH,SIZE,FSTYPE,LABEL,MOUNTPOINTS,MODEL "$TARGET_DISK"

# Create new MBR partition table
sudo fdisk "$TARGET_DISK"
# In fdisk: o (new table), n (new partition), p (primary), a (bootable), w (write)

# Verify the new partition, then create one filesystem
lsblk -o NAME,PATH,SIZE,FSTYPE,LABEL,MOUNTPOINTS,MODEL "$TARGET_DISK"
sudo mkfs.vfat -F 32 "$TARGET_PARTITION"  # For FAT32
# Or: sudo mkfs.ext4 "$TARGET_PARTITION"  # For ext4
```

### Шаг 2: Извлечение и копирование файлов

**Монтирование ISO:**

*Windows:*
- Щёлкните правой кнопкой мыши по ISO-файлу и выберите "Подключить"

*Linux:*
```bash
sudo mkdir /mnt/minios-iso
sudo mount -o loop MiniOS.iso /mnt/minios-iso

TARGET_PARTITION=/dev/sdX1
sudo mkdir /mnt/minios-target
sudo mount "$TARGET_PARTITION" /mnt/minios-target
findmnt --mountpoint /mnt/minios-target
```

**Копирование файлов:**
1. **Найдите папку `/minios/`** в смонтированном ISO
2. **Скопируйте всю папку `/minios/`** в корень USB-накопителя

В Linux целевой корень в приведённом выше примере — `/mnt/minios-target`. Перед копированием файлов убедитесь, что `findmnt --mountpoint /mnt/minios-target` показывает именно тот раздел, который был выбран на шаге 1.

### Шаг 3: Установка загрузчика

Перейдите в папку `/minios/boot/syslinux/` на накопителе и запустите установщик:

`bootinst` записывает загрузочный код на диск, определяемый по расположению установщика. Прочитайте [Восстановление загрузки](/administration/Boot-Recovery.md) перед изменением загрузочного кода и не запускайте установщик, пока не будут проверены устройство и точка монтирования.

**Windows:**
- Откройте проверенный USB-накопитель по его букве, перейдите в `minios\boot\syslinux` и запустите `bootinst.bat` **от имени администратора**.

**Linux:**
```bash
TARGET_MOUNT=/mnt/minios-target
findmnt --mountpoint "$TARGET_MOUNT"
lsblk -o NAME,PATH,SIZE,FSTYPE,LABEL,MOUNTPOINTS,MODEL
cd "$TARGET_MOUNT/minios/boot/syslinux"
chmod +x bootinst.sh
sudo ./bootinst.sh
```

Не подставляйте подстановочные знаки вместо точки монтирования. Скрипт определяет целевой диск по своему расположению и записывает загрузочный код именно на этот диск.

## Результат и персистентность

Эта процедура создаёт файловую live-инсталляцию, размещая дерево `minios/` и загрузчик на обычной файловой системе. Это не простая запись ISO, не мультизагрузка с ISO-файла и не установка через MiniOS Installer.

Выбранная файловая система влияет на то, какие механизмы персистентности могут работать, но сама по себе не включает персистентность и не гарантирует создание сессии. Персистентность активируется только если это указано в загрузочной записи или параметрах ядра, и для её работы требуется подходящее устройство для записи. Перед использованием сохранённых изменений ознакомьтесь с [Режимами загрузки](/configuration/Boot-Modes.md) и [Персистентностью initrd](/configuration/Initrd-Persistence.md).
