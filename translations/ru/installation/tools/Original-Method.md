# Оригинальный способ установки (Windows/Linux)

Оригинальный метод установки MiniOS включает прямое копирование системных файлов на диск и установку загрузчика. Этот способ обеспечивает максимальную гибкость настройки и совместимость с различными типами носителей.

⚠️ **Примечание**: Этот метод работает только в Windows и Linux из-за использования загрузчика SYSLINUX.

## Важно

⚠️ **Внимание:** Неправильный выбор устройства приведёт к потере данных! Всегда внимательно проверяйте выбранный диск и делайте резервные копии важных данных.

## Требования к диску

### Размер диска

Подробные системные требования и размеры дисков смотрите в [Руководстве по совместимости оборудования](/installation/Hardware-Compatibility.md#system-requirements).

### Технические требования

- **Файловые системы**: FAT32, NTFS, ext2/3/4, Btrfs
- **Схема разделов**: MBR
- ⚠️ **Загрузка в режиме EFI**: При использовании файловых систем NTFS, exFAT или ext2/3/4 загрузка в режиме EFI может быть недоступна. Для поддержки EFI рекомендуется использовать FAT32.

## Создание загрузочного USB-накопителя

### Шаг 1: Подготовьте диск

**Windows:**
1. Откройте "Управление дисками" (`Win+R` → `diskmgmt.msc`)
2. Найдите USB-накопитель → правый клик → "Удалить том"
3. Кликните правой кнопкой по нераспределённому пространству → "Создать простой том"
4. Выберите файловую систему: FAT32 (рекомендуется) или NTFS

**Linux:**
```bash
# Identify the device
lsblk

# Create new MBR partition table
sudo fdisk /dev/sdX
# In fdisk: o (new table), n (new partition), p (primary), a (bootable), w (write)

# Create file system
sudo mkfs.vfat -F 32 /dev/sdX1  # For FAT32
sudo mkfs.ext4 /dev/sdX1         # For ext4
```

### Шаг 2: Распаковка и копирование файлов

**Монтирование ISO:**

*Windows:*
- Кликните правой кнопкой по ISO-файлу → "Подключить"

*Linux:*
```bash
sudo mkdir /mnt/minios-iso
sudo mount -o loop MiniOS.iso /mnt/minios-iso
```

**Копирование файлов:**
1. **Найдите папку `/minios/`** в смонтированном ISO
2. **Скопируйте всю папку `/minios/`** в корень USB-накопителя

### Шаг 3: Установка загрузчика

Перейдите в папку `/minios/boot/` на диске и запустите установщик:

**Windows:**
- Запустите `bootinst.bat` **от имени администратора**

**Linux:**
```bash
cd /media/$USER/*/minios/boot/
chmod +x bootinst.sh
sudo ./bootinst.sh
```

## Автоматическое сохранение изменений

При первой загрузке MiniOS определяет тип файловой системы диска и пытается использовать оптимальный режим сохранения изменений:

- **ext2/3/4, Btrfs**: попытка использовать режим `native` (прямое сохранение)
- **FAT32/NTFS**: используется режим `dynfilefs` (динамический файл)
- Если режим native недоступен, автоматически переключается на dynfilefs

### Настройка параметров (для опытных пользователей)

Если требуется точная настройка сохранения изменений, можно использовать параметры загрузки:

- `perchmode=native` — прямое сохранение на раздел (для ext4)
- `perchmode=dynfilefs` — динамически расширяемый файл
- `perchmode=raw` — файл фиксированного размера  
- `perchsize=8000` — размер пространства для хранения данных в МБ

Подробнее в [параметрах загрузки](/configuration/Boot-Parameters.md).
