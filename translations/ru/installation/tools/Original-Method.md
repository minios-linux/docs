# Оригинальный способ установки (Windows/Linux, устаревший)

Этот устаревший способ установки MiniOS предполагает прямое копирование системных файлов на диск и установку загрузчика. Рекомендуется использовать актуальные методы из раздела [Установка MiniOS](/installation/Installing-MiniOS.md), если только не требуется файловая структура.

**Примечание:** Этот способ работает только в Windows и Linux из-за использования загрузчика SYSLINUX.

## Важно

**Внимание:** Неправильный выбор устройства приведёт к потере данных. Всегда тщательно проверяйте выбранный диск и делайте резервные копии важных данных.

## Требования к диску

### Размер диска

См. [Руководство по совместимости оборудования](/installation/Hardware-Compatibility.md#system-requirements) для подробных системных требований и размеров дисков.

### Технические требования

- **Файловые системы**: FAT32, NTFS, ext2/3/4, Btrfs
- **Схема разделов**: MBR
- **Загрузка в режиме EFI**: При использовании файловых систем NTFS, exFAT или ext2/3/4 загрузка в режиме EFI может быть недоступна. Для поддержки EFI рекомендуется использовать FAT32.

## Создание загрузочного USB-накопителя

### Шаг 1: Подготовьте диск

**Windows:**
1. Откройте "Управление дисками" (`Win+R`, затем `diskmgmt.msc`)
2. Найдите USB-накопитель, кликните правой кнопкой мыши и выберите "Удалить том"
3. Кликните правой кнопкой по нераспределённому пространству и выберите "Создать простой том"
4. Выберите файловую систему: FAT32 (рекомендуется) или NTFS

**Linux:**
```bash
# Identify the device
lsblk

# Create new MBR partition table
sudo fdisk /dev/sdX
# In fdisk: o (new table), n (new partition), p (primary), a (bootable), w (write)

# Create file system
sudo mkfs.vfat -F 32 /dev/sdX1  # For FAT32
sudo mkfs.ext4 /dev/sdX1         # For ext4
```

### Шаг 2: Извлеките и скопируйте файлы

**Монтирование ISO:**

*Windows:*
- Кликните правой кнопкой мыши по ISO-файлу и выберите "Подключить"

*Linux:*
```bash
sudo mkdir /mnt/minios-iso
sudo mount -o loop MiniOS.iso /mnt/minios-iso
```

**Копирование файлов:**
1. **Найдите папку `/minios/`** в смонтированном ISO
2. **Скопируйте всю папку `/minios/`** в корень USB-накопителя

### Шаг 3: Установите загрузчик

Перейдите в папку `/minios/boot/syslinux/` на диске и запустите установщик:

**Windows:**
- Запустите `bootinst.bat` **от имени администратора**

**Linux:**
```bash
lsblk -o NAME,SIZE,FSTYPE,LABEL,MOUNTPOINTS,MODEL
TARGET_MOUNT="/media/$USER/MINIOS"
cd "$TARGET_MOUNT/minios/boot/syslinux"
chmod +x bootinst.sh
sudo ./bootinst.sh
```

Замените `MINIOS` на точную директорию монтирования, которую вы проверили с помощью `lsblk`. Не используйте подстановочные знаки: скрипт определяет целевой диск по своему расположению и записывает загрузочный код именно на этот диск.

## Автоматическое сохранение изменений

При первой загрузке MiniOS определяет тип файловой системы диска и пытается использовать оптимальный режим сохранения изменений:

- **ext2/3/4, Btrfs**: попытка использовать режим `native` (прямое сохранение)
- **FAT32/NTFS**: используется режим `dynfilefs` (динамический файл)
- При недоступности нативного режима автоматически переключается на dynfilefs

### Настройка параметров для опытных пользователей

Когда требуется точная настройка параметров сохранения, можно использовать загрузочные параметры:

- `perchmode=native` — Прямое сохранение на раздел (для ext4)
- `perchmode=dynfilefs` — Динамически расширяемый файл
- `perchmode=raw` — Файл фиксированного размера
- `perchsize=8000` — Размер пространства для хранения данных в МБ

Подробнее см. в разделе [загрузочные параметры](/configuration/Boot-Parameters.md).
