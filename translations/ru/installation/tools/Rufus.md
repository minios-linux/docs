# Использование Rufus (Windows)

Rufus — это популярная утилита для Windows, которая помогает форматировать и создавать загрузочные USB-накопители.

## Важно

**Внимание:** Неправильный выбор устройства приведёт к потере данных! Всегда внимательно проверяйте выбранный диск и делайте резервные копии важных данных.

## Требования к накопителю

### Размер накопителя

Подробные системные требования и размеры накопителей смотрите в [Руководстве по совместимости оборудования](/installation/Hardware-Compatibility.md).

## Установка Rufus

1. **Скачайте Rufus** с [официального сайта](https://rufus.ie/)
2. **Запустите программу** — Rufus не требует установки, это портативное приложение

## Создание загрузочного USB-накопителя

Rufus предлагает два способа записи MiniOS на USB-накопитель:

### Способ 1: DD режим (рекомендуется)

1. **Запустите Rufus** от имени администратора
2. **Выберите USB-накопитель** в поле «Устройство»
3. **Выберите ISO-файл MiniOS**:
   - Нажмите кнопку «ВЫБРАТЬ»
   - Найдите и выберите загруженный ISO-файл MiniOS
4. **Выберите режим записи**:
   - В диалоговом окне «Обнаружен гибридный ISO-образ» выберите **«Записать в режиме DD-образа»**
5. **Запустите процесс**: нажмите кнопку «СТАРТ»
6. **Подтвердите действие** — все данные на накопителе будут удалены
7. **Дождитесь завершения** процесса записи

### Метод 2: Режим ISO (Альтернативный)

1. **Запустите Rufus** от имени администратора
2. **Выберите USB-накопитель** в поле "Устройство"
3. **Выберите файл MiniOS ISO**:
   - Нажмите кнопку "ВЫБРАТЬ"
   - Найдите и выберите загруженный файл MiniOS ISO
4. **Выберите режим записи**:
   - В диалоговом окне "Обнаружен гибридный ISO-образ" выберите **"Записать в режиме ISO-образа"**
5. **Настройте параметры**:
   - **Файловая система**: FAT32 (рекомендуется) или NTFS
   - **Если выбран NTFS**: загрузка в режиме EFI может быть недоступна
6. **Запустите процесс**: нажмите кнопку "СТАРТ"
7. **Подтвердите форматирование** — все данные на накопителе будут удалены

## Результат и персистентность

Режим DD выполняет запись образа на низком уровне и копирует структуру ISO на всё целевое устройство. Режим ISO форматирует файловую систему и извлекает содержимое ISO для создания live-носителя на основе файлов. Ни один из режимов не является установкой MiniOS Installer, и Rufus не создает автоматически раздел ext4 или сессию с персистентностью.

Персистентность включается только при наличии соответствующей загрузочной записи или параметра ядра, и всё равно требует подходящего носителя с возможностью записи. Перед использованием сохранения изменений ознакомьтесь с разделами [Режимы загрузки](/configuration/Boot-Modes.md) и [Персистентность Initrd](/configuration/Initrd-Persistence.md).
