# Использование Rufus (Windows)

Rufus — это популярная утилита для Windows, которая помогает форматировать и создавать загрузочные USB-накопители.

## Важно

⚠️ **Внимание:** Неправильный выбор устройства приведёт к потере данных! Всегда внимательно проверяйте выбранный диск и делайте резервные копии важных данных.

## Требования к накопителю

### Размер накопителя

См. [Руководство по совместимости оборудования](/installation/Hardware-Compatibility.md#system-requirements) для подробных системных требований и размеров накопителей.

## Установка Rufus

1. **Скачайте Rufus** с [официального сайта](https://rufus.ie/)
2. **Запустите программу** — Rufus не требует установки, это портативное приложение

## Создание загрузочного USB-накопителя

Rufus предлагает два способа записи MiniOS на USB-накопитель:

### Способ 1: DD режим (рекомендуется)

1. **Запустите Rufus** от имени администратора
2. **Выберите USB-накопитель** в поле «Устройство»
3. **Выберите ISO-файл MiniOS**:
   - Нажмите кнопку «ВЫБРАТЬ»
   - Найдите и выберите загруженный ISO-файл MiniOS
4. **Выберите режим записи**:
   - В диалоговом окне «Обнаружен гибридный ISO-образ» выберите **«Записать в режиме DD-образа»**
5. **Запустите процесс**: нажмите кнопку «СТАРТ»
6. **Подтвердите действие** — все данные на накопителе будут удалены
7. **Дождитесь завершения** процесса записи

### Способ 2: ISO режим (альтернатива)

1. **Запустите Rufus** от имени администратора
2. **Выберите USB-накопитель** в поле «Устройство»
3. **Выберите ISO-файл MiniOS**:
   - Нажмите кнопку «ВЫБРАТЬ»
   - Найдите и выберите загруженный ISO-файл MiniOS
4. **Выберите режим записи**:
   - В диалоговом окне «Обнаружен гибридный ISO-образ» выберите **«Записать в режиме ISO-образа»**
5. **Настройте параметры**:
   - **Файловая система**: FAT32 (рекомендуется) или NTFS
   - ⚠️ **При выборе NTFS**: загрузка в режиме EFI может быть недоступна
6. **Запустите процесс**: нажмите кнопку «СТАРТ»
7. **Подтвердите форматирование** — все данные на накопителе будут удалены

## Автоматическое сохранение изменений

MiniOS автоматически определит способ записи и настроит сохранение изменений:

- **DD режим**: если есть свободное место, будет создан раздел ext4 для максимальной производительности
- **ISO режим**: используется динамический файл для сохранения изменений

### Настройка параметров (для опытных пользователей)

Если требуется точная настройка сохранения изменений, можно использовать параметры загрузки:

- `perchmode=native` — прямое сохранение на раздел (для DD режима)
- `perchmode=dynfilefs` — динамически расширяемый файл
- `perchmode=raw` — файл фиксированного размера
- `perchsize=8000` — размер пространства для хранения данных в МБ

Подробнее в [параметрах загрузки](/configuration/Boot-Parameters.md).
