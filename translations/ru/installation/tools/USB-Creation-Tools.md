# Инструменты для создания USB

MiniOS можно установить на USB-накопитель с помощью различных инструментов в зависимости от вашей операционной системы.

## Рекомендуемые инструменты

### 🖥️ Windows

- **[Rufus](Rufus.md)** — Надёжный и универсальный инструмент. Рекомендуется большинству пользователей.
- **[Balena Etcher](Balena-Etcher.md)** — Простой, кроссплатформенный, современный интерфейс.
- **[Ventoy](Ventoy.md)** — Позволяет размещать несколько ISO на одном накопителе без форматирования.

### 🐧 Linux

- **[dd command](dd.md)** — Универсальный инструмент командной строки. Быстрый и предустановлен во многих дистрибутивах.
- **[Balena Etcher](Balena-Etcher.md)** — Удобный графический интерфейс.
- **[Original Method](Original-Method.md)** — Использование стандартных инструментов Linux (`cp`, `tar`).

### 🍎 macOS

- **[Balena Etcher](Balena-Etcher.md)** — Самый простой способ для пользователей Mac.
- **[dd command](dd.md)** — Для опытных пользователей, знакомых с терминалом.

## Другие инструменты

- **[UNetbootin](UNetbootin.md)** — Классический инструмент, но иногда менее надёжен с современными ISO.
- **[Drive Utility](Drive-Utility.md)** — GNOME Disks или аналогичные встроенные утилиты.
