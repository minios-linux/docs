# Использование UNetbootin

UNetbootin — это кроссплатформенная утилита с открытым исходным кодом, которая позволяет создавать загрузочные USB-накопители для различных дистрибутивов Linux, включая MiniOS.

## Важно

⚠️ **Внимание:** Неправильный выбор устройства приведёт к потере данных! Всегда тщательно проверяйте выбранный диск и делайте резервные копии важных данных.

## Требования к накопителю

### Размер накопителя

См. [Руководство по совместимости оборудования](/installation/Hardware-Compatibility.md#system-requirements) для подробных системных требований и размеров накопителей.

## Установка UNetbootin

1. **Скачайте UNetbootin** с [официального сайта](https://unetbootin.github.io/)
2. **Установите программу** на вашу систему:
   - **Windows**: Запустите установщик от имени администратора
   - **Linux**: Установите из репозитория или используйте AppImage
   - **macOS**: Перетащите приложение в папку Applications

## Создание загрузочного USB-накопителя

1. **Запустите UNetbootin** от имени администратора/root
2. **Выберите источник образа:**
   - Установите переключатель на "Образ диска"
   - Нажмите кнопку "..." и выберите ISO-файл MiniOS
3. **Выберите целевое устройство:**
   - В списке "Диск" выберите ваш USB-накопитель
   - Убедитесь, что выбран правильный диск
4. **Запустите процесс:** Нажмите "OK"
5. **Дождитесь завершения** — процесс может занять 10–20 минут

## Автоматическое сохранение изменений

UNetbootin автоматически форматирует накопитель в FAT32, поэтому MiniOS будет использовать режим dynfilefs для сохранения изменений. Это обеспечивает максимальную совместимость с различными системами, включая поддержку загрузки через EFI.

### Настройка параметров (для опытных пользователей)

Когда требуется точная настройка, можно использовать параметры загрузки:

- `perchmode=dynfilefs` — динамически расширяемый файл (по умолчанию)
- `perchmode=raw` — файл фиксированного размера
- `perchsize=8000` — размер пространства для хранения данных в МБ

Подробнее в [параметрах загрузки](/configuration/Boot-Parameters.md).
