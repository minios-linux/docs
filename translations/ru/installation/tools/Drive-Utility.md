# Использование Drive Utility

Drive Utility — это графическая утилита для записи ISO-образов MiniOS на USB-накопители.

**Установка:** По умолчанию доступна в MiniOS, для других дистрибутивов смотрите https://github.com/minios-linux/driveutility

## Важно

⚠️ **Внимание:** Неправильный выбор устройства приведёт к потере данных! Всегда перепроверяйте выбранный накопитель и делайте резервные копии важных данных.

## Требования к накопителю

### Размер накопителя (для записи MiniOS)

Подробные системные требования и размеры накопителей смотрите в [Руководстве по совместимости оборудования](/installation/Hardware-Compatibility.md#system-requirements).

### Поддерживаемые файловые системы

- **FAT32**: максимальная совместимость
- **NTFS**: совместимость с Windows  
- **EXT4**: рекомендуется для Linux

## Запуск Drive Utility

**Через меню приложений:**
1. Откройте меню → Система → "Drive Utility"

**Через терминал:**
```bash
driveutility
```

## Создание загрузочного USB-накопителя

1. **Выберите режим "Write"** в главном окне программы
2. **Выберите ISO-файл MiniOS:**
   - Нажмите кнопку "Обзор" рядом с полем "Источник"
   - Найдите и выберите загруженный файл MiniOS.iso
3. **Выберите целевой накопитель:**
   - Укажите ваш USB-накопитель в списке устройств
   - Проверьте выбор по размеру и модели
4. **Начните запись:**
   - Нажмите кнопку "Write"
   - Подтвердите операцию — все данные на накопителе будут удалены
5. **Дождитесь завершения** — процесс займет несколько минут

## Автоматическое сохранение изменений

При записи MiniOS через Drive Utility создаётся точная копия ISO-образа. MiniOS автоматически определит способ записи и настроит сохранение изменений при первом запуске.

### Настройка параметров (для опытных пользователей)

Для точной настройки сохранения изменений можно использовать параметры загрузки:

- `perchmode=native` — сохранение на раздел напрямую (если есть свободное место)
- `perchmode=dynfilefs` — динамически расширяемый файл
- `perchmode=raw` — файл фиксированного размера
- `perchsize=8000` — размер пространства для данных в МБ

Подробнее в [параметрах загрузки](/configuration/Boot-Parameters.md).
