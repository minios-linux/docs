# Использование команды `dd`

`dd` — это многофункциональная утилита командной строки для побитового копирования данных между файлами и устройствами. Чаще всего используется для записи ISO-образов на USB-накопители, создания резервных копий и восстановления данных.

## Важно

⚠️ **Внимание:** Неправильный выбор устройства приведёт к потере данных! Всегда тщательно проверяйте выбранный диск и делайте резервные копии важных данных.

## Требования к накопителю

### Размер накопителя

См. [Руководство по совместимости оборудования](/installation/Hardware-Compatibility.md#system-requirements) для подробных системных требований и размеров накопителей.

## Подготовка

1. Определите ваш USB-накопитель:
   - **Linux:** `lsblk` или `sudo fdisk -l`
   - **macOS:** `diskutil list`

2. Отмонтируйте накопитель:
   - **Linux:** `sudo umount /dev/sdX*`
   - **macOS:** `sudo diskutil unmountDisk /dev/diskX`

## Создание загрузочного USB-накопителя

**Linux:**
```bash
sudo dd if=MiniOS.iso of=/dev/sdX bs=4M status=progress conv=fsync
```

**macOS:**
```bash
sudo dd if=MiniOS.iso of=/dev/diskX bs=4m
```

**Замените:**
- `MiniOS.iso` — путь к вашему ISO-файлу
- `/dev/sdX` — ваш USB-накопитель (например, `/dev/sdb`)

## Автоматическое сохранение изменений

При первом запуске MiniOS проверит тип файловой системы накопителя и выберет оптимальный режим сохранения изменений. Если есть свободное место, система автоматически создаст раздел ext4 для максимальной производительности.

### Настройка параметров (для опытных пользователей)

Для точной настройки сохранения изменений можно использовать параметры загрузки:

- `perchmode=native` — прямое сохранение на раздел (по умолчанию, самый быстрый)
- `perchmode=dynfilefs` — динамически расширяемый файл
- `perchmode=raw` — файл фиксированного размера
- `perchsize=8000` — размер пространства для данных в МБ для файлов-образов

Подробнее в [параметрах загрузки](/configuration/Boot-Parameters.md).
