# Использование команды `dd`

`dd` — это многофункциональная утилита командной строки для побитового копирования данных между файлами и устройствами. Чаще всего используется для записи ISO-образов на USB-накопители, создания резервных копий и восстановления данных.

## Важно

**Внимание:** Неправильный выбор устройства приведёт к потере данных! Всегда внимательно проверяйте выбранный диск и делайте резервные копии важных данных.

## Требования к накопителю

### Размер накопителя

Подробные системные требования и размеры накопителей смотрите в [Руководстве по совместимости оборудования](/installation/Hardware-Compatibility.md).

## Подготовка

1. Определите ваш USB-накопитель:
   - **Linux:** `lsblk` или `sudo fdisk -l`
   - **macOS:** `diskutil list`

2. Отмонтируйте накопитель:
   - **Linux:** `sudo umount /dev/sdX*`
   - **macOS:** `sudo diskutil unmountDisk /dev/diskX`

## Создание загрузочного USB-накопителя

**Linux:**
```bash
sudo dd if=MiniOS.iso of=/dev/sdX bs=4M status=progress conv=fsync
```

**macOS:**
```bash
sudo dd if=MiniOS.iso of=/dev/diskX bs=4m
```

**Замените:**
- `MiniOS.iso` — путь к вашему ISO-файлу
- `/dev/sdX` — ваш USB-накопитель (например, `/dev/sdb`)

## Результат и персистентность

`dd` выполняет запись образа на низком уровне: копирует структуру ISO на всё целевое устройство. Он не создаёт раздел ext4 в неиспользуемом пространстве, не создаёт сессию персистентности и не выполняет установку MiniOS Installer.

Персистентность включается только при наличии соответствующей записи загрузки или параметра ядра, и всё равно требует подходящего носителя с возможностью записи. Перед использованием сохранения изменений ознакомьтесь с разделами [Режимы загрузки](/configuration/Boot-Modes.md) и [Initrd персистентность](/configuration/Initrd-Persistence.md).
