# Параметры загрузки

## Как использовать параметры загрузки

Параметры загрузки позволяют настраивать запуск MiniOS. Разделяйте параметры пробелами в командной строке ядра.

### Syslinux

- Нажмите <kbd>Esc</kbd> во время загрузки MiniOS для доступа к загрузочному меню.
- Нажмите <kbd>Tab</kbd> для редактирования параметров загрузки.
- Введите необходимые параметры и нажмите <kbd>Enter</kbd> для запуска.

### GRUB

- Нажмите <kbd>E</kbd> в меню GRUB.
- Отредактируйте параметры загрузки в конце командной строки.
- Нажмите <kbd>F10</kbd> для загрузки с новыми настройками.

## Параметры загрузки

Столбец «Применение» различает параметры, которые обычно принимаются при каждой загрузке, и параметры учётной записи, предназначенные для первоначальной настройки. При использовании постоянства компоненты live-config обычно запускаются только один раз; см. [live-config](/reference/configuration/live-config).

Эта таблица служит краткой справкой. Приоритет источников и допустимые формы `from=` определены в разделе [Обнаружение системы в initrd](/reference/boot-process/System-Discovery), фильтрация модулей — в разделе [Загрузка модулей в initrd](/reference/boot-process/Module-Loading), выбор постоянства — в разделе [Внутренняя работа постоянства в initrd](/reference/boot-process/Persistence-Internals), поддерживаемые комбинации — в разделе [Режимы загрузки](/using-minios/Boot-Modes).

| Параметр | Применение | Описание | Пример |
|---|---|---|---|
| `from` | Каждая загрузка | Загружает данные MiniOS из каталога, поддерживаемого пути к устройству или ISO. Формы UUID, PARTUUID и by-id не разбираются. URL вида **`http://` only** имеет приоритет над `ip=` и запускает [сетевую загрузку](/reference/boot-process/Network-Boot) через httpfs2. | `from=/minios/`<br>`from=/Downloads/minios.iso`<br>`from=http://domain.com/minios.iso`<br>`from=/dev/sr0/minios`<br>`from=/dev/disk/by-label/MyFlash/minios`<br>`from=askdisk`<br>`from=askdisk:customdir` |
| `load` | Каждая загрузка | Оставляет кандидаты `.sb`, путь которых соответствует нефиксированному расширенному регулярному выражению; запятые становятся чередованием, а целый возрастающий числовой диапазон имеет специальное расширение. Также фильтрует `toram=trim`. Может исключать основные или модульные ядра и сделать систему незагружаемой. | `load=00-core`<br>`load=core,kernel,firmware`<br>`load=00,01,02`<br>`load=00-03` |
| `noload` | Каждая загрузка | Исключает кандидаты, путь которых соответствует нефиксированному расширенному регулярному выражению, включая из `toram=trim`; применяется после `load` и может исключать основные или модульные ядра. | `noload=05-xfce-apps`<br>`noload=xfce-apps,firefox`<br>`noload=05,06`<br>`noload=04-06` |
| `bext` | Каждая загрузка | Устанавливает расширение для бандла. По умолчанию: `sb`. Координация с ядром всё равно использует буквальные имена `.sb`, поэтому пользовательское расширение не может координировать модуль `01-kernel`. | `bext=mymod` |
| `timing` | Каждая загрузка | Включает вывод времени запуска. | `timing` |
| `union` | Каждая загрузка | Выбирает файловую систему union. | `union=aufs`<br>`union=overlayfs` |
| `ip` | Каждая загрузка | Статический адрес для ранней загрузки по сети. Формат: `<client-ip>:<server-ip>:<gateway-ip>:<netmask>[:<port>]` (по умолчанию порт PXE HTTP **7529**). Буквальный `from=http://...` имеет приоритет над `ip=` и использует его поля адресации; иначе любой непустой `ip=` принудительно скачивает данные PXE и пропускает локальные носители. Это не настройка NetworkManager для сессии. См. [Сетевая загрузка](/reference/boot-process/Network-Boot). | `ip=192.168.1.10:192.168.1.1:192.168.1.1:255.255.255.0` |
| `cache` | Каждая загрузка | Размер кэша httpfs в MiB для сетевой загрузки HTTP ISO (`from=http://…`). См. [Сетевая загрузка](/reference/boot-process/Network-Boot). | `cache=512` |
| `rd.break` | Каждая загрузка | Открывает отладочную оболочку в конце стадии initramfs. | `rd.break` |
| `perchdir` | Каждая загрузка | Выбирает номер сессии постоянства или действие: `resume`, `new` или `ask`. Несуществующий числовой селектор может перейти к метаданным по умолчанию; он не резервирует и не создаёт этот номер. Устройство/путь или форма `askdisk` выбирает другое место для постоянства. Используйте двоеточие для указания пользовательского пути. Без параметра постоянства MiniOS стартует "чисто". | `perchdir=1`<br>`perchdir=resume`<br>`perchdir=new`<br>`perchdir=ask`<br>`perchdir=/dev/sda1/changes`<br>`perchdir=/dev/disk/by-label/MyFlash/changes`<br>`perchdir=askdisk`<br>`perchdir=askdisk:customdir` |
| `perchsize` | Каждая загрузка | Размер контейнера для `dynfilefs`, `raw` и `luks`; не применяется к `native` или `squashfs`. Число или значение `M`/`MB` выделяется в MiB; `G`/`GB` и `T`/`TB` преобразуются в 1000 и 1 000 000 MiB соответственно. Лимит — 1 000 000 MiB, дополнительно ограничен доступным пространством после `perchreserve`. Менеджер сессий MiniOS ограничивает raw и LUKS-файлы 4000 MiB на FAT32; initrd LUKS применяет этот лимит, но запрос на слишком большой raw-файл в initrd может завершиться ошибкой вместо уменьшения. Новые raw и LUKS-контейнеры по умолчанию — 4000 MiB. Контейнер DynFileFS, созданный initramfs, по умолчанию занимает всё доступное пространство, округлённое до 1000 MiB; Менеджер сессий MiniOS по умолчанию выделяет 4000 MiB. | `perchsize=4000`<br>`perchsize=32GB`<br>`perchsize=1TB` |
| `perchreserve` | Каждая загрузка | Запас по выделению и порог предупреждения о низком пространстве в MiB. Вычитается при создании или увеличении контейнеров, но не является квотой во время работы и не предотвращает последующее заполнение устройства. По умолчанию: 256; максимум: 4096. | `perchreserve=512`<br>`perchreserve=1024` |
| `perchmode` | Каждая загрузка | Режим хранения постоянства.<br>`native` (по умолчанию): каталог на записываемой POSIX-файловой системе.<br>`dynfilefs`: расширяемый контейнер, в том числе на FAT32, NTFS или exFAT.<br>`raw`: образ ext4 фиксированного размера.<br>`luks`: контейнер с шифрованием LUKS2 и ext4; создание и разблокировка требуют поддержки crypt в initramfs и выполняются через консоль.<br>`squashfs`: существующий сжатый снимок, распаковываемый для сессии. Менеджер сессий MiniOS может создавать и сохранять снимки SquashFS из работающей системы; initramfs может только возобновлять, но не создавать их. | `perchmode=native`<br>`perchmode=dynfilefs`<br>`perchmode=raw`<br>`perchmode=luks`<br>`perchmode=squashfs` |
| `perch` | Каждая загрузка | Включает устаревший путь возобновления постоянства. В отличие от `perchdir=resume`, не создаёт автоматически совместимую замену при отсутствии подходящей сессии по умолчанию. | `perch` |
| `toram` | Каждая загрузка | Обычный `toram` — это `full`. При постоянстве верхнеуровневая копия `*` в режиме full не включает скрытые файлы; без постоянства не включает `changes`, но копирует другие верхнеуровневые элементы, включая скрытые файлы. Trim копирует необходимые `config.conf`, обычные файлы `authorized_keys`, выбранные верхнеуровневые и рекурсивные модули, а также полностью дерево `changes/` при запросе постоянства; не включает `boot/`, `kernels/`, `rootcopy/`, `config.conf.d/`, журналы, другие не модульные данные и отдельный уровень модулей постоянства. Ни один режим не проверяет вместимость RAM заранее. Хранилище постоянства, скопированное в RAM, не является долговременным, и изменения не копируются обратно. Извлекайте носитель только после подтверждения успешного отсоединения источника, loop-устройств и маппингов. | `toram`<br>`toram=trim`<br>`toram=full` |
| `text` | Каждая загрузка | Запускает в текстовом консольном режиме. | `text` |
| `automount` | Каждая загрузка | Включает автоматическое монтирование устройств хранения. | `automount` |
| `debug` | Каждая загрузка | Включает дополнительную диагностику запуска. | `debug` |
| `nozram` | Каждая загрузка | Отключает swap на zram. | `nozram` |
| `zramsize` | Каждая загрузка | Устанавливает размер swap на zram в MiB. Если не задано, MiniOS рассчитывает его исходя из общего объёма RAM. | `zramsize=512`<br>`zramsize=2048` |
| `zramcomp` | Каждая загрузка | Выбирает `lzo`, `lzo-rle`, `lz4`, `lz4hc` или `zstd`; доступность зависит от используемого ядра. Если не задано, сохраняется значение по умолчанию ядра. | `zramcomp=lzo`<br>`zramcomp=lz4` |
| `default-target` | Каждая загрузка | Устанавливает целевой systemd по умолчанию. | `default-target=multi-user`<br>`default-target=rescue` |

## Соображения безопасности

Командная строка ядра хранится в открытом виде и обычно видна в конфигурации загрузчика, `/proc/cmdline` и диагностике. Не размещайте повторно используемые секреты в `root-password=` или `user-password=`. Предпочитайте соответствующие параметры `*-crypted`, но даже хэши паролей, если они раскрыты, следует считать чувствительными.

Хуки выполняются с привилегиями загрузочного кода. Хук `http://` не использует шифрование транспорта и не проверяет подлинность сервера, поэтому любой, кто может изменить сетевой маршрут, может его подменить. Используйте только доверенные механизмы доставки и содержимое; не применяйте неаутентифицированные HTTP-хуки для запуска, критичного к безопасности.

Команды разделяются пробелами. Дополнительные параметры ядра, общие для всех дистрибутивов Linux, смотрите на справочных страницах `man bootparam`.

Подробную информацию о параметрах live-config см. в разделе [live-config](/reference/configuration/live-config).

О загрузке MiniOS по сети (PXE и HTTP ISO) см. [Сетевая загрузка](/reference/boot-process/Network-Boot).
