# Содержимое пакета и редакции

Содержимое пакета MiniOS формируется на основе условных исходных списков. Итоговый набор зависит от дистрибутива, архитектуры, системы инициализации, рабочего окружения, локали, параметров ядра и доступности репозиториев. На этой странице перечислены пользовательские пакеты, запрошенные поддерживаемыми манифестами Flux и Xfce. Инструменты для сборки и зависимости, устанавливаемые только через APT, здесь не отображаются.

`Yes` означает, что текущий манифест запрашивает этот пакет для выбранной редакции.
`Conditional` означает, что имя пакета или его включение зависит от параметров сборки или целевой платформы. Тире означает, что редакция не запрашивает этот пакет.
Окончательное содержимое образа является приоритетным.

## Структура редакций

Поддерживаемые редакции Xfce основаны друг на друге: Standard — это компактный рабочий стол для повседневного использования, Toolbox предназначен для профессионального администрирования, диагностики и восстановления системы, а Ultra превращает эту базу в полноценную рабочую среду для повседневной работы, творчества и разработки. Flux — это отдельная сверхлёгкая конфигурация Fluxbox для минимального использования ресурсов и старого оборудования; это не просто уменьшенный список пакетов Xfce.

| Редакция | Вариант пакетов и окружение | Основное назначение |
|---|---|---|
| **Standard** | `standard` с `xfce` | Минимальный рабочий стол Xfce с базовой функциональностью |
| **Toolbox** | `toolbox` с `xfce` | Профессиональное администрирование, диагностика и восстановление системы |
| **Ultra** | `ultra` с `xfce` | Полноценный рабочий стол для универсальной работы, творчества и разработки |
| **Flux** | `minimum` с `flux` | Сверхлёгкий рабочий стол Fluxbox для минимального использования ресурсов и старого оборудования |

Другие поддерживаемые окружения имеют собственные цепочки модулей и должны проверяться отдельно. В частности, наличие пакетов в сборках LXQt или консольных вариантах не следует определять по таблицам Xfce ниже.

## Просмотр установленных пакетов

Работающая система является источником достоверной информации о реально установленных пакетах.
Чтобы вывести список имён и версий пакетов, используйте:

```bash
dpkg-query -W -f='${binary:Package}\t${Version}\n' | sort
```

## Исходные манифесты сборки

Таблицы пакетов выше сформированы на основе системы сборки [`minios-live` build system](https://github.com/minios-linux/minios-live). Пути ниже указаны относительно корня этого исходного репозитория и используются при сборке или кастомизации образа из исходников:

- `linux-live/environments/<environment>/` определяет последовательность модулей.
- `linux-live/scripts/00-core/packages.list` определяет общую базу и добавления для вариантов пакетов.
- `linux-live/scripts/01-kernel/packages.list` определяет условную сборку ядра и пакеты DKMS.
- `linux-live/scripts/02-firmware/packages.list` определяет прошивки, специфичные для дистрибутива.
- `linux-live/scripts/03-gui-base/packages.list` определяет общую графическую базу.
- `linux-live/scripts/04-flux-desktop/packages.list` и `05-flux-apps/packages.list` определяют Flux.
- `linux-live/scripts/04-xfce-desktop/packages.list` определяет Xfce и инструменты рабочего стола MiniOS.
- `linux-live/scripts/05-apps/packages.list` определяет графические приложения Toolbox и Ultra.
- `linux-live/scripts/10-firefox/packages.list` определяет браузеры, специфичные для редакции и локали.
- В каждом модуле файлы `install` и `skip_conditions.conf` определяют, будет ли использоваться его список пакетов и каким образом.
- `linux-live/build.conf` выбирает редакцию, архитектуру, окружение, вариант пакета, init-систему, ядро и локаль.
- `linux-live/condinapt.map` определяет префиксы условий для списков пакетов.

Исходные списки описывают запрашиваемые пакеты и альтернативы. Только готовый образ и `dpkg-query` показывают итоговый набор зависимостей и точные версии для конкретного релиза.

См. [Архитектура системы](/reference/System-Architecture) для порядка модулей и [CondinAPT в MiniOS](/development/CondinAPT) для условного выбора пакетов.
