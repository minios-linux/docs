# О MiniOS

MiniOS — это дистрибутив Linux на базе Debian, предназначенный для запуска с
съемных носителей или локального диска. Система работает в режиме только для чтения и собирается из модулей SquashFS,
с возможностью создания записываемых сессий для файлов, настроек и установленных пакетов.
MiniOS поддерживает 64-битные x86-системы и может загружаться через UEFI или классический BIOS.

## Модель системы

- Базовая система и дополнительное программное обеспечение реализованы как отдельные модули. Модули можно выбирать при загрузке или добавлять без пересборки всей системы.
- Новая сессия Live не изменяет базовые модули.
- Персистентность может сохранять изменения в родной директории, расширяемом контейнере DynFileFS, образе фиксированного размера или в зашифрованном контейнере LUKS — в зависимости от способа установки и целевой файловой системы.
- Установщик MiniOS может выполнить модульную live-инсталляцию или, если образ это поддерживает, развернуть обычную нативную установку Linux.

См. [Режимы загрузки](/configuration/Boot-Modes.md) для основного руководства по поведению live-загрузки и [Архитектура системы](/about/System-Architecture.md) для структуры загрузки и модулей. Подробные контракты ранней загрузки описаны в [Обнаружение системы в initrd](/configuration/Initrd-System-Discovery.md), [Загрузка модулей в initrd](/configuration/Initrd-Module-Loading.md) и [Персистентность в initrd](/configuration/Initrd-Persistence.md).

## Редакции

Доступные редакции зависят от релиза и базового дистрибутива:

- **Flux** использует окружение Flux и сокращённый набор пакетов. Подходит для систем, где предпочтительна минимальная подборка программ.
- **Standard** — универсальная редакция. В текущих сборках на базе Debian и Ubuntu по умолчанию используется Xfce.
- **Toolbox** добавляет инструменты для администрирования системы, работы с хранилищем, диагностики и восстановления.
- **Ultra** включает расширенный набор приложений по сравнению с другими редакциями.

Xfce обычно используется в редакциях Standard, Toolbox и Ultra, но это не единственное окружение MiniOS. Редакция Flux использует Fluxbox, а поддерживаемые конфигурации сборки могут предлагать и другие окружения. Если для вас важно рабочее окружение, ознакомьтесь с описанием релиза перед загрузкой.

Список программного обеспечения для каждой редакции смотрите в [списке пакетов](/administration/Packages.md) и в разделе [Приложения и инструменты MiniOS](/about/MiniOS-Applications.md).

## Установка и персистентность

ISO-образ можно записать как загрузочный, скопировать на мультизагрузочное устройство или установить с помощью MiniOS Installer. Эти методы отличаются по принципу работы с хранилищем. Инструменты записи образов, такие как `dd` и Etcher, воспроизводят структуру ISO; Ventoy загружает ISO-файл; MiniOS Installer может выделять и настраивать пространство для записи данных сессии. Не предполагается, что любой способ записи автоматически создаёт персистентность.

Начните с [Быстрого старта](/installation/Quick-Start.md) и используйте соответствующее руководство для выбранного метода установки. Персистентность также можно выбрать через подходящее загрузочное меню или настроить с помощью документированных параметров загрузки, если доступно место для записи. См. [Режимы загрузки](/configuration/Boot-Modes.md) для описания поведения live-сессии и [Управление сессиями](/configuration/Session-Management.md) для вариантов хранения.
