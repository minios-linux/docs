# MiniOS: Идеальный портативный опыт Linux 🌐

MiniOS — это универсальный и портативный дистрибутив Linux на базе Debian, созданный с помощью скриптов minios-live. Его основная цель — предоставить полноценную и комфортную среду для работы, развлечений и творчества на любом оборудовании с поддержкой x86, при этом сохраняя ваши личные данные на съемных носителях.

## Основан на Debian: стабильность и универсальность 🎯

Построенный на надежной платформе Debian, MiniOS унаследовал все преимущества одного из самых стабильных и безопасных дистрибутивов Linux. Эта база обеспечивает MiniOS:

- **Стабильность**: Гарантия плавной и надежной работы.
- **Безопасность**: Использование сильной системы безопасности Debian с оперативными обновлениями и патчами.
- **Совместимость**: Доступ к огромному репозиторию программного обеспечения Debian.
- **Поддержка сообщества**: Возможность пользоваться обширными знаниями и поддержкой сообщества Debian.

## Ключевые особенности MiniOS 🛠️

- **Модульность**: Большой выбор настраиваемых модулей для адаптации системы под конкретные задачи.
- **Портативность**: Разработан для установки на USB-накопитель и использования на разных устройствах.
- **Совместимость**: Работа на широком спектре систем с поддержкой как UEFI, так и классического BIOS.
- **Обновления**: Актуальный релиз с обновленным ядром и дополнительными инструментами для отладки.

## Редакции MiniOS: под ваши задачи 📦

### 🚀 **Standard**: Надежная рабочая лошадка

MiniOS Standard — ваш основной выбор для повседневных задач. Надежный, хорошо оснащенный и готовый к работе — это основа линейки MiniOS.

### 🧰 **Toolbox**: Набор инструментов для профессионалов

MiniOS Toolbox создан для специалистов и опытных пользователей, которым нужен мощный набор утилит для администрирования системы, разметки дисков и восстановления данных. Это идеальный инструмент для тех, кто требует расширенных возможностей управления системой.

### ⚡ **Ultra**: Мощная универсальная редакция

MiniOS Ultra — самая полная версия MiniOS, объединяющая все функции и инструменты редакций Standard и Toolbox, а также дополнительное ПО для разработки, мультимедиа и продвинутых сетевых задач. Идеально подходит для тех, кто хочет получить полноценную портативную рабочую станцию с готовым набором всего необходимого.

Подробный список пакетов для каждой редакции смотрите здесь: [Список пакетов](/administration/Packages.md)

## Почему выбирают MiniOS? 💡

MiniOS — это разумный выбор для тех, кому нужна портативная, стабильная и безопасная операционная система. Отлично подходит для восстановления старых ПК, создания портативной рабочей станции или просто для того, чтобы пользоваться свободой Linux где угодно.
