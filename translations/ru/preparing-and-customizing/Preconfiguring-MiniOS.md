# Предварительная настройка MiniOS

Конфигуратор MiniOS — это графический редактор настроек MiniOS `live-config` . Он проверяет изменения и записывает конфигурацию для следующей загрузки. Текущая система не изменяется напрямую.

## Запуск конфигуратора

Откройте Конфигуратор MiniOS через меню приложений или выполните команду:

```bash
minios-configurator
```

Целевой файл по умолчанию — `/etc/live/config.conf`. Чтобы отредактировать другой обычный файл, укажите его путь:

```bash
minios-configurator /path/to/config.conf
```

Для сохранения требуется аутентификация через PolicyKit. Символические ссылки и не обычные целевые файлы не поддерживаются.

## Конфигурация носителя и среды выполнения

MiniOS может читать конфигурацию из двух мест:

- `minios/config.conf` и `minios/config.conf.d/*.conf` на загрузочном носителе
- `/etc/live/config.conf` и `/etc/live/config.conf.d/*.conf` в корневой файловой системе текущей среды

Конфигуратор MiniOS редактирует только выбранный файл. Без указания пути редактируется файл среды выполнения `/etc/live/config.conf`; файл на носителе напрямую не открывается. MiniOS синхронизирует более новую конфигурацию между файловой системой среды выполнения и доступными для записи носителями MiniOS при загрузке. На носителях только для чтения изменения среды выполнения не сохраняются, а постоянная конфигурация среды может быть независимой от копии на носителе.

Для каждой опции параметры ядра имеют приоритет над конфигурационными файлами, а настройки на носителе — над настройками в корневой файловой системе.
Используйте `-i` чтобы добавить распознанные параметры из текущей командной строки ядра в редактор:

```bash
minios-configurator --inherit-cmdline /etc/live/config.conf
```

Выбранный файл остается целевым для сохранения. Неизвестные параметры ядра игнорируются.

## Когда применяются настройки

Каждый элемент управления указывает, когда он используется. Сохранение никогда не применяет настройку к текущей сессии.

### Применяются после перезагрузки

Имя хоста, язык, часовой пояс, клавиатура, целевой режим загрузки, выбор сервисов, режим модулей, работа с пользовательскими директориями на носителях, параметры отладки и экспорт журналов читаются при следующей загрузке. После сохранения перезагрузите систему, чтобы применить изменения.

### Используются только для новой сессии

Создание учетной записи, пароли пользователя и root, `noroot`, политика sudo и PolicyKit, политика SSH и XRDP, доступ к X11, подсказки к паролям и блокировка экрана — это одноразовые настройки. В постоянной сессии обычно сохраняются завершённые `live-config` компоненты в каталоге `/var/lib/live/config/`, поэтому изменение этих значений и перезагрузка той же сессии не приведёт к повторному созданию аккаунта или изменению состояния безопасности. Чтобы применить их как начальные параметры, начните новую сессию.

Профили безопасности — это предустановки редактора. Сохраняется не имя профиля, а отдельные параметры безопасности, которые остаются доступными для редактирования.

## Пользовательские директории и постоянство

Связывание и bind-монтирование пользовательских директорий взаимоисключающие. Оба варианта используют существующий доступный для записи локальный носитель данных MiniOS и безопасный путь относительно носителя. Эти функции недоступны при `toram`, `toram=full`, или `toram=trim`, и MiniOS не объединяет автоматически две заполненные директории.

`perchmode` и `perchsize` — это параметры загрузки initramfs, а не настройки Конфигуратора MiniOS. Конфигуратор MiniOS не создаёт, не разблокирует, не изменяет размер и не восстанавливает контейнер постоянства. Для зашифрованного постоянства он только сообщает, установлен ли маркер шифрования initramfs.

## Поведение при сохранении

В обзоре отображаются только изменённые значения, а пароли скрыты. При сохранении обновляются только изменённые ключи, при этом сохраняются комментарии, порядок, неизвестные ключи, права владельца, разрешения и расширенные атрибуты. Запись происходит атомарно.

Полную справку по переменным и параметрам загрузки смотрите в разделе [Конфигурационный файл](/reference/configuration/config.conf), [Параметры загрузки](/reference/Boot-Parameters), и [live-config](/reference/configuration/live-config).
