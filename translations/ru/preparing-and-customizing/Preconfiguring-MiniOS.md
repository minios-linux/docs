# Предварительная настройка MiniOS

Конфигуратор MiniOS — это графический редактор настроек MiniOS `live-config`. Он проверяет изменения и сохраняет конфигурацию для последующей загрузки. Текущая система при этом не изменяется напрямую.

## Запуск конфигуратора

Откройте Конфигуратор MiniOS через меню приложений или выполните команду:

```bash
minios-configurator
```

Цель по умолчанию — `/etc/live/config.conf`. Чтобы изменить другой обычный файл, укажите его путь:

```bash
minios-configurator /path/to/config.conf
```

Для сохранения требуется аутентификация PolicyKit. Символические ссылки и не обычные целевые файлы не поддерживаются.

## Конфигурация носителя и среды выполнения

MiniOS может читать конфигурацию из двух источников:

- `minios/config.conf` и `minios/config.conf.d/*.conf` на загрузочном носителе
- `/etc/live/config.conf` и `/etc/live/config.conf.d/*.conf` в корневой файловой системе среды выполнения

Конфигуратор MiniOS редактирует только выбранный файл. Если путь не указан, он редактирует файл среды выполнения `/etc/live/config.conf`; файл на носителе напрямую не открывается. MiniOS синхронизирует более новую конфигурацию между файловой системой среды выполнения и доступным для записи носителем MiniOS во время загрузки. Носители только для чтения не могут принимать изменения среды выполнения, а постоянная конфигурация среды выполнения может оставаться независимой от копии на носителе.

Для любой опции параметры ядра имеют приоритет над конфигурационными файлами, а конфигурация на носителе — над конфигурацией в корневой файловой системе.
Используйте `-i`, чтобы наложить распознанные параметры из текущей командной строки ядра в редакторе:

```bash
minios-configurator --inherit-cmdline /etc/live/config.conf
```

Выбранный файл остаётся целевым для сохранения. Неизвестные параметры ядра игнорируются.

## Когда применяются настройки

Каждый элемент управления указывает, когда он используется. Сохранение никогда не применяет настройку к текущей сессии.

### Применяются после перезагрузки

Имя хоста, локаль, часовой пояс, клавиатура, целевой режим загрузки, выбор сервисов, режим модулей, обработка пользовательских каталогов на носителе, параметры отладки и экспорт журналов читаются при следующей загрузке. Перезагрузите систему после сохранения, чтобы применить их.

### Используются только для новой сессии

Создание учетной записи, пароли пользователя и root, `noroot`, политика sudo и PolicyKit, политика SSH и XRDP, доступ к X11, подсказки к паролям и блокировка экрана — это одноразовые настройки. В постоянной сессии обычно фиксируются завершённые компоненты `live-config` в `/var/lib/live/config/`, поэтому изменение этих значений и перезагрузка той же сессии не приведёт к повторному созданию учетной записи или изменению состояния безопасности. Чтобы применить их как начальные настройки, начните новую сессию.

Профили безопасности — это предустановки редактора. Имя профиля не сохраняется; сохраняются отдельные параметры безопасности, которые остаются доступными для редактирования.

## Пользовательские каталоги и постоянство данных

Связывание и монтирование пользовательских каталогов с помощью bind являются взаимоисключающими. Оба метода используют существующий доступный для записи локальный носитель данных MiniOS и безопасный путь, относительный к носителю. Они недоступны при использовании `toram`, `toram=full` или `toram=trim`, и MiniOS не объединяет автоматически два заполненных дерева каталогов.

`perchmode` и `perchsize` — это параметры загрузки initramfs, а не настройки Конфигуратора MiniOS. Конфигуратор MiniOS не создаёт, не разблокирует, не изменяет размер и не восстанавливает контейнер постоянства. Для зашифрованного постоянства он только сообщает, присутствует ли маркер шифрования initramfs.

## Поведение при сохранении

В обзоре отображаются только изменённые значения, а пароли скрываются. При сохранении обновляются только изменённые ключи с сохранением комментариев, порядка, неизвестных ключей, владельца, прав доступа и расширенных атрибутов. Запись происходит атомарно.

Полную справку по переменным и параметрам загрузки смотрите в [Configuration file](/reference/configuration/config.conf), [Boot parameters](/reference/Boot-Parameters) и [live-config](/reference/configuration/live-config).
