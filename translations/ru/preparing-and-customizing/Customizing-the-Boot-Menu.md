# Настройка загрузочного меню

Меню загрузки MiniOS предоставляют удобные пункты для популярных режимов загрузки Live-системы. В этом руководстве объясняется, как выбирать и редактировать эти пункты.

## Обзор

Образы MiniOS могут использовать GRUB или Syslinux в зависимости от прошивки, структуры образа и сборки. Их графические меню, клавиши редактирования, поддержка языков и доступные пункты могут отличаться. В конечном итоге загрузчик передает командную строку ядра одному и тому же initrd; см. [Режимы загрузки](/using-minios/Boot-Modes) для получения информации об исходном источнике, постоянстве, поведении RAM-копирования и зависимости от носителя.

## Параметры загрузочного меню

Предоставляемый образ обычно предлагает следующие варианты, хотя названия, наличие, порядок и выбор по умолчанию могут отличаться в зависимости от образа:

| Пункт меню | Типичный селектор initrd | Назначение |
|---|---|---|
| Запустить MiniOS | `perchdir=resume` | Попробовать совместимую с настройками сессию по умолчанию и разрешить создание замены при соблюдении описанных условий. |
| Начать новую сессию | `perchdir=new` | Создать дополнительную пронумерованную постоянную сессию, сохраняя существующие сессии без изменений. |
| Выбрать сохранённую сессию | `perchdir=ask` | Интерактивно выбрать одну из ранее сохранённых сессий. Используйте **Начать новую сессию** при пустом хранилище. |
| Запустить без сохранения | селектор без постоянства | Использовать временный записываемый слой в RAM. |
| Запустить с RAM | `toram` | Скопировать всё дерево данных MiniOS на RAM и попытаться отключить исходный носитель. |

Это селекторы, а не гарантии того, что хранилище доступно для записи, сессия совместима, объём RAM достаточен или исходный носитель отключён. Подробнее о поведении и комбинациях см. [Режимы загрузки](/using-minios/Boot-Modes), о пограничных случаях селекторов — [Постоянство initrd](/reference/boot-process/Persistence-Internals), а о производительности и компромиссах ввода-вывода — [Оптимизация производительности](/maintenance-and-recovery/Performance) для RAM.

## Как пользоваться загрузочным меню

### Навигация по меню

- Используйте **стрелки** для перемещения между пунктами
- Нажмите **Enter** для выбора пункта
- Нажмите **Esc** для возврата к предыдущему меню (в GRUB)
- Автоматический выбор и время ожидания зависят от текущей конфигурации меню; некоторые меню могут ожидать выбора неограниченно долго

### Выбор языка (GRUB)

Если ваш USB-накопитель MiniOS поддерживает несколько языков:
1. На первом экране появятся варианты языков
2. Выберите предпочитаемый язык
3. Загрузочное меню отобразится на выбранном языке
4. Выбранный язык также может передаваться в параметры локали при запуске, но это не гарантирует перевод всех сообщений загрузки или приложений

**Важно:** Многоязычное меню имеет приоритет над настройками локали, указанными в `config.conf`. Язык, выбранный в загрузочном меню, будет использоваться вместо заранее заданных настроек локали. Подробнее см. в **[Файл конфигурации](/reference/configuration/config.conf)** и **[live-config](/reference/configuration/live-config)** о системных конфигурационных файлах.

## Настройка параметров загрузки

### Временное изменение параметров загрузки

Вы можете изменить параметры загрузки для одной сессии:

**В GRUB:**
1. Выберите нужный пункт меню
2. Нажмите **'e'** для редактирования
3. Перейдите к строке, начинающейся с `linux`
4. Добавьте или измените параметры в конце строки
5. Нажмите **Ctrl+X** или **F10** для загрузки с изменениями

**В SYSLINUX:**
1. Выберите нужный пункт меню
2. Нажмите **Tab** перед Enter
3. Добавьте параметры в появившуюся командную строку
4. Нажмите **Enter** для загрузки

### Часто используемые параметры загрузки

- `debug` — Показать подробные сообщения загрузки (полезно для диагностики)
- `toram=trim` — Копировать отфильтрованный набор модулей и необходимые данные в RAM
- `perchsize=2000` — Установить размер хранилища сессии 2 ГБ (можно изменить)
- `locales=ru_RU.UTF-8` — Запросить определённый язык/локаль

Полный список доступных параметров загрузки смотрите в **[Параметры загрузки](/reference/Boot-Parameters)**.

## Расположение файлов конфигурации

### На вашем USB-накопителе MiniOS

- **Конфигурация GRUB:** `/minios/boot/grub/grub.cfg`
- **Конфигурация SYSLINUX:** `/minios/boot/syslinux/syslinux.cfg`
- **Загрузочные образы:** `/minios/boot/bootlogo.png`
- **Языковые файлы:** `/minios/boot/grub/locale/`

### В запущенной системе

- **Текущие параметры загрузки:** `/proc/cmdline`
- **Каталог данных MiniOS:** `/run/initramfs/memory/data/minios/`

### Редактирование конфигурационных файлов

**Внимание:** Редактируйте файлы загрузочной конфигурации только если уверены в своих действиях. Неправильные изменения могут сделать ваш USB-накопитель нерабочим.

**Чтобы изменить конфигурацию GRUB:**
1. Смонтируйте USB-накопитель MiniOS
2. Перейдите в `/minios/boot/grub/`
3. Отредактируйте `grub.cfg` в текстовом редакторе
4. Сохраните изменения и безопасно извлеките накопитель

**Частые изменения:**
- Изменение директивы тайм-аута, используемой в активном меню GRUB или Syslinux
- Изменение `set default=0` для выбора пункта меню по умолчанию
- Добавление собственных пунктов меню
