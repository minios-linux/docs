# Настройка загрузочного меню

Меню загрузки MiniOS предоставляет удобный выбор для стандартных режимов Live-загрузки. В этом руководстве объясняется, как выбирать и редактировать эти пункты.

## Обзор

Образы MiniOS могут использовать GRUB или Syslinux в зависимости от прошивки, структуры образа и сборки. Их меню, клавиши для редактирования, поддержка языков и доступные пункты могут отличаться. В конечном итоге загрузчик передаёт командную строку ядра одному и тому же initrd; см. [Режимы загрузки](/using-minios/Boot-Modes) для информации о конечном источнике, работе с постоянством, копировании RAM и зависимости от носителя.

## Параметры загрузочного меню

В предоставленном образе обычно доступны следующие варианты, однако названия, наличие, порядок и выбор по умолчанию могут отличаться в зависимости от образа:

| Выбор в меню | Типичный селектор initrd | Назначение |
|---|---|---|
| Запустить MiniOS | `perchdir=resume` | Запустить совместимую с большинством устройств сессию по умолчанию и разрешить создание новой при выполнении указанных условий. |
| Начать новую сессию | `perchdir=new` | Создать дополнительную пронумерованную постоянную сессию, сохраняя существующие сессии без изменений. |
| Выбрать сохранённую сессию | `perchdir=ask` | Интерактивно выбрать одну из сохранённых сессий. Используйте **Начать новую сессию** при пустом хранилище. |
| Запустить без сохранения | без селектора постоянства | Использовать временный доступный для записи слой в RAM. |
| Запустить из RAM | `toram` | Скопировать полностью дерево данных MiniOS на RAM и попытаться отключить исходный носитель. |

Это только селекторы, а не гарантия, что хранилище доступно для записи, сессия совместима, объём RAM достаточен или исходный носитель отключён. Подробнее см. [Режимы загрузки](/using-minios/Boot-Modes) для описания поведения и комбинаций, [Постоянство initrd](/reference/boot-process/Persistence-Internals) для крайних случаев выбора, а также [Оптимизация производительности](/maintenance-and-recovery/Performance) для RAM и компромиссов по скорости ввода-вывода.

## Как пользоваться загрузочным меню

### Навигация по меню

- Используйте **клавиши со стрелками** для перемещения между пунктами меню
- Нажмите **Enter** чтобы выбрать пункт
- Нажмите **Esc** чтобы вернуться к предыдущему меню (в GRUB)
- Автоматический выбор и время ожидания зависят от настроек активного меню; некоторые меню могут ожидать выбора бесконечно

### Выбор языка (GRUB)

Если ваш USB-накопитель MiniOS поддерживает несколько языков:
1. На первом экране появятся варианты языков
2. Выберите предпочитаемый язык
3. Загрузочное меню отобразится на выбранном языке
4. Выбранный язык также может передавать настройки локали при дальнейшем запуске, но это не гарантирует перевод всех сообщений загрузки или приложений

**Важно:** Многоязычное меню имеет приоритет над любыми настройками локали, указанными в `config.conf`. Язык, выбранный в загрузочном меню, будет иметь приоритет над предустановленными настройками локали. Подробнее см. **[Файл конфигурации](/reference/configuration/config.conf)** и **[live-config](/reference/configuration/live-config)** для информации о системных конфигурационных файлах.

## Настройка параметров загрузки

### Временное изменение параметров загрузки

Вы можете изменить параметры загрузки только для одной сессии:

**В GRUB:**
1. Выберите пункт меню, который хотите изменить
2. Нажмите **'e'** для редактирования
3. Перейдите к строке, начинающейся с `linux`
4. Добавьте или измените параметры в конце строки
5. Нажмите **Ctrl+X** или **F10** чтобы загрузиться с изменёнными параметрами

**В SYSLINUX:**
1. Выберите нужный пункт меню
2. Нажмите **Tab** перед нажатием Enter
3. Добавьте параметры в появившуюся командную строку
4. Нажмите **Enter** для загрузки

### Часто используемые параметры загрузки

- `debug` - Показать подробные сообщения загрузки (полезно для диагностики)
- `toram=trim` - Копировать отфильтрованный набор модулей и необходимые данные на RAM
- `perchsize=2000` - Установить размер хранилища сессии 2 ГБ (можно изменить по необходимости)
- `locales=ru_RU.UTF-8` - Запросить определённый язык/локаль

Полный список доступных параметров загрузки смотрите в разделе **[Параметры загрузки](/reference/Boot-Parameters)**.

## Расположение файлов конфигурации

### На вашем USB-накопителе MiniOS

- **Конфигурация GRUB:** `/minios/boot/grub/grub.cfg`
- **Конфигурация SYSLINUX:** `/minios/boot/syslinux/syslinux.cfg`
- **Образы для загрузки:** `/minios/boot/bootlogo.png`
- **Языковые файлы:** `/minios/boot/grub/locale/`

### В работающей системе

- **Текущие параметры загрузки:** `/proc/cmdline`
- **Каталог данных MiniOS:** `/run/initramfs/memory/data/minios/`

### Редактирование конфигурационных файлов

**Внимание:** Редактируйте файлы конфигурации загрузки только если понимаете, что делаете. Неправильные изменения могут сделать ваш USB-накопитель не загружаемым.

**Чтобы изменить конфигурацию GRUB:**
1. Смонтируйте USB-накопитель MiniOS
2. Перейдите в `/minios/boot/grub/`
3. Откройте `grub.cfg` в текстовом редакторе
4. Сохраните изменения и безопасно извлеките USB-накопитель

**Часто вносимые изменения:**
- Изменить директиву тайм-аута, используемую в активном меню GRUB или Syslinux
- Измените `set default=0` чтобы изменить пункт меню по умолчанию
- Добавить собственные пункты меню
