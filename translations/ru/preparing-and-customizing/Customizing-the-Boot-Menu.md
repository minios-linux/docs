# Настройка загрузочного меню

Загрузочные меню MiniOS предоставляют удобный выбор для стандартных режимов загрузки Live-системы. В этом руководстве объясняется, как выбирать и редактировать эти пункты меню.

## Обзор

Образы MiniOS могут использовать GRUB или Syslinux в зависимости от прошивки, структуры образа и сборки. Их меню, клавиши для редактирования, поддержка языков и доступные пункты могут отличаться. В конечном итоге загрузчик передаёт командную строку ядра одному и тому же initrd; см. [Режимы загрузки](/using-minios/Boot-Modes) для информации о исходных данных, работе с сохранением, поведении копирования RAM и зависимости от носителя.

## Параметры загрузочного меню

В предоставленном образе обычно доступны следующие варианты, однако названия, наличие, порядок и выбор по умолчанию могут отличаться в зависимости от образа:

| Пункт меню | Типичный селектор initrd | Назначение |
|---|---|---|
| Запустить MiniOS | `perchdir=resume` | Запустить совместимую с большинством устройств сессию по умолчанию и разрешить создание новой сессии при выполнении описанных условий. |
| Начать новую сессию | `perchdir=setup` | Открыть выбор хранилища для сохранения, затем создать дополнительную сессию с новым номером, не изменяя уже существующие. |
| Выбрать сохранённую сессию | `perchdir=ask` | Выбрать сохранённую сессию вручную; если хранилище пустое, MiniOS запускает тот же процесс создания первой сессии. |
| Запустить без сохранения | без выбора сохранения | Использовать временный записываемый слой в RAM. |
| Запустить из RAM | `toram` | Скопировать системные данные MiniOS на RAM; при наличии сохранения по умолчанию `perchtoram=trim` отдельно копируется выбранная поддерживаемая сессия. |

Это только селекторы, а не гарантия, что носитель доступен для записи, сессия совместима, объём RAM достаточен или исходный носитель отключён. Подробнее см. [Режимы загрузки](/using-minios/Boot-Modes) о поведении и комбинациях, [Сохранение в initrd](/reference/boot-process/Persistence-Internals) о нюансах выбора, а также [Оптимизация производительности](/maintenance-and-recovery/Performance) для RAM и особенностей работы с вводом/выводом.

## Как пользоваться загрузочным меню

### Навигация по меню

- Используйте **клавиши со стрелками** для перемещения между пунктами меню
- Нажмите **Enter** чтобы выбрать пункт
- Нажмите **Esc** чтобы вернуться в предыдущее меню (в GRUB)
- Автоматический выбор и время ожидания зависят от текущей конфигурации меню; некоторые меню могут ожидать выбора неограниченно долго

### Справка и выбор языка

Текущие многоязычные меню GRUB и родные меню SYSLINUX сначала предлагают выбор режима загрузки, а не экрана выбора языка. **F1** открывает справку по загрузке, а **F2** открывает выбор языка. После выбора языка вы возвращаетесь в переведённое меню режимов. В однъязычных образах доступна только справка, навигация по недоступным языкам не предлагается.

Начальное многоязычное меню сохраняет установленную локаль системы. Только явный выбор языка добавляет параметры локали, которые переопределяют `config.conf` для этой загрузки. Это не гарантирует перевод всех сообщений при запуске или в приложениях. Подробнее см. [Файл конфигурации](/reference/configuration/config.conf) и [live-config](/reference/configuration/live-config).

## Настройка параметров загрузки

### Временное изменение параметров загрузки

Вы можете изменить параметры загрузки для одной сессии:

**В GRUB:**
1. Выберите пункт меню, который хотите изменить
2. Нажмите **'e'** для редактирования
3. Перейдите к строке, начинающейся с `linux`
4. Добавьте или измените параметры в конце строки
5. Нажмите **Ctrl+X** или **F10** чтобы загрузиться с изменёнными параметрами

**В SYSLINUX:**
1. Выберите нужный пункт меню
2. Нажмите **Tab** перед нажатием Enter
3. Добавьте параметры в появившуюся командную строку
4. Нажмите **Enter** для загрузки

### Общие изменения параметров загрузки

- `debug` - Показать подробные сообщения загрузки (полезно для диагностики)
- `toram=trim` - Скопировать отфильтрованный набор модулей и необходимую ограниченную информацию в RAM
- `perchsize=2000` - Запросить 2000 MiB для нового или расширяемого поддерживаемого контейнера; это не влияет на размер нативных или SquashFS сессий
- `locales=ru_RU.UTF-8` - Запросить определённый язык/локаль

Полный список доступных параметров загрузки см. в разделе **[Параметры загрузки](/reference/Boot-Parameters)**.

## Расположение файлов конфигурации

### На вашем MiniOS USB-накопителе

- **Конфигурация GRUB:** `/minios/boot/grub/grub.cfg`
- **Меню режимов и языков GRUB:** `/minios/boot/grub/main.cfg` и `/minios/boot/grub/languages.cfg`; в локализованных сборках можно выбрать другие сгенерированные файлы
- **Конфигурация SYSLINUX:** `/minios/boot/syslinux/syslinux.cfg`
- **Оформление загрузки:** проверьте активную настройку SYSLINUX `MENU BACKGROUND` или тему GRUB; пути зависят от выбранного загрузчика
- **Языковые файлы:** `/minios/boot/grub/locale/`

### В работающей системе

- **Текущие параметры загрузки:** `/proc/cmdline`
- **Каталог данных MiniOS:** `/run/initramfs/memory/data/minios/`

### Редактирование файлов конфигурации

**Внимание:** Редактируйте файлы конфигурации загрузки только если вы понимаете, что делаете. Неправильные изменения могут сделать вашу USB-флешку непригодной для загрузки.

**Чтобы изменить конфигурацию GRUB:**
1. Смонтируйте вашу USB-флешку MiniOS
2. Перейдите в `/minios/boot/grub/`
3. Откройте `grub.cfg` в текстовом редакторе
4. Сохраните изменения и безопасно извлеките USB-флешку

**Часто изменяют:**
- Изменить директиву timeout для активного меню GRUB или Syslinux
- Измените `set default=0` чтобы изменить пункт меню по умолчанию
- Добавить собственные пункты меню
