# Управление ядрами

## Зачем заменять ядро?

MiniOS поставляется с ядром по умолчанию, но есть несколько причин, по которым вы можете захотеть его заменить:

### **Различные варианты ядра Debian**

Debian предоставляет несколько вариантов ядра, оптимизированных для разных сценариев использования:

- **`linux-image-6.12.38+deb13-amd64`** — стандартное ядро для 64-битных систем (по умолчанию в MiniOS)
- **`linux-image-6.12.38+deb13-rt-amd64`** — ядро реального времени для задач с критичными требованиями к времени отклика
- **`linux-image-6.12.38+deb13-cloud-amd64`** — оптимизировано для облачных и виртуализированных сред

> **Примечание:** Номера версий (например, `6.12.38+deb13`) меняются с обновлениями. Чтобы узнать, какие ядра доступны сейчас:
> ```bash
> apt search linux-image-.*-amd64
> apt search linux-image-.*-rt-amd64
> apt search linux-image-.*-cloud-amd64
> ```

### **Специализированные сценарии использования**

- **Вычисления в реальном времени** - RT-ядра для аудиопроизводства, промышленной автоматизации
- **Игры и низкая задержка** - Пользовательские ядра с оптимизациями для игр
- **Усиление безопасности** - Ядра с дополнительными патчами безопасности (grsecurity и др.)
- **Совместимость с оборудованием** - Новые ядра для поддержки современного оборудования
- **Оптимизация производительности** - Собранные вручную ядра с определёнными оптимизациями

### **Особенности пользовательских ядер**

- **Пользовательские патчи** - Применяйте определённые патчи для вашего оборудования или задач
- **Модули ядра** - Добавляйте поддержку специализированного оборудования или файловых систем
- **Оптимизация компилятора** - Сборка с разными флагами оптимизации
- **Оптимизация размера** - Удаляйте ненужные драйверы для уменьшения размера ядра

### **Типовые сценарии**

- **Рабочие станции для аудиопроизводства** - Используйте RT-ядро для минимальной аудиозадержки
- **Игровые системы** - Применяйте патчи и оптимизации для игр
- **Серверные среды** - Используйте ядра, оптимизированные для облака, для лучшей виртуализации
- **Устаревшее оборудование** - Используйте старые ядра для совместимости с винтажными системами
- **Системы для разработки** - Тестируйте приложения на разных версиях ядра

## Обзор Менеджера ядер MiniOS

MiniOS предоставляет два инструмента для управления ядрами:

1. **Менеджер ядер MiniOS (GUI):** Удобное графическое приложение для упаковки, установки и управления ядрами
2. **minios-kernel (CLI):** Командная утилита для опытных пользователей и автоматизации

Оба инструмента автоматически выполняют:
- **Упаковку ядра** в формате SquashFS
- **Генерацию initramfs** с нужными драйверами и загрузочными скриптами
- **Установку** в репозиторий ядер MiniOS
- **Настройку загрузчика** обновления
- **Активацию ядра** и переключение

На этой странице описана модульная живая система MiniOS. Менеджер ядер MiniOS и `minios-kernel` доступны для этой live-архитектуры и её согласованного модуля ядра, `vmlinuz`, а также набора initramfs. После нативного преобразования система использует стандартный рабочий процесс Debian для ядер; инструменты live-ядра MiniOS удаляются, так как модульная модель ядра больше не применяется, поэтому используйте стандартные пакеты ядра Debian, инструменты initramfs и установленный загрузчик. Подробнее см. [О MiniOS](/getting-started/About-MiniOS) и [Режимы загрузки](/using-minios/Boot-Modes). Для точного поведения согласованного ядра в live initrd см. [Загрузка модулей в initrd](/reference/boot-process/Module-Loading).

### **Важные замечания:**

- **Административные права:** Оба инструмента требуют административных прав и запросят аутентификацию через PolicyKit
- **Совместимость ядер:** Убедитесь, что ядра совместимы с MiniOS. Рекомендуется использовать ядра из репозитория
- **Каталог MiniOS:** Инструменты автоматически определяют каталог MiniOS (`/minios/`) и проверяют права на запись
- **Автоматические обновления:** Конфигурация загрузчика обновляется автоматически при активации ядра

## Метод 1: Использование Менеджера ядер MiniOS (GUI)

Графический менеджер ядер предоставляет интуитивно понятный интерфейс для всех операций с ядрами.

### **Шаги:**

#### 1. **Запустите приложение**

```bash
minios-kernel-manager
```

Или найдите «Менеджер ядер MiniOS» в меню приложений.

#### 2. **Упакуйте новое ядро**

**Во вкладке «Упаковать ядро»:**

1. **Выбор исходника ядра:**
   - **Ручная упаковка:** Просмотрите и выберите локальный `.deb` пакет ядра
   - **Репозиторий:** Выберите из доступных ядер в репозиториях Debian/Ubuntu

2. **Настройка сжатия:**
   - Выберите сжатие SquashFS: `zstd` (рекомендуется), `lz4`, `lzo`, `xz`, или `gzip`

3. **Упаковать ядро:**
   - Нажмите кнопку «Упаковать ядро»
   - Следите за ходом процесса в журнале упаковки
   - Файлы автоматически устанавливаются в репозиторий MiniOS

#### 3. **Управление установленными ядрами**

**Во вкладке «Управление ядрами»:**

1. **Просмотр доступных ядер:**
   - Просматривайте все упакованные ядра со статусами:
     - **АКТИВНО:** Текущее настроенное ядро
     - **ЗАПУЩЕНО:** Текущее загруженное ядро
     - **ДОСТУПНО:** Доступно для активации

2. **Активация ядра:**
   - Щёлкните правой кнопкой мыши по ядру и выберите «Активировать ядро»
   - Подтвердите диалог активации
   - Конфигурация загрузчика обновляется автоматически

3. **Удаление ядра:**
   - Щёлкните правой кнопкой мыши по неактивному ядру и выберите «Удалить ядро»
   - Подтвердите удаление (действие необратимо)

## Метод 2: Использование minios-kernel (CLI)

Командная утилита предоставляет возможности управления ядрами для скриптов и автоматизации.

### **Требуются административные права:**

Для работы CLI-инструмента необходимы права root; они будут автоматически проверены. Запускайте команды с помощью `sudo` или через `pkexec`:

```bash
sudo minios-kernel list
# or
pkexec minios-kernel activate 6.12.38+deb13-amd64
```

### **Базовые команды:**

#### 1. **Список доступных ядер**

```bash
sudo minios-kernel list
```

Показывает все установленные пакеты ядер и их статус.

#### 2. **Упаковать ядро**

**Из репозитория:**
```bash
sudo minios-kernel package --repo linux-image-6.12.38+deb13-amd64 -o /tmp/kernel-output
```

**Из локального .deb-файла:**
```bash
sudo minios-kernel package --deb /path/to/kernel.deb -o /tmp/kernel-output
```

**С пользовательским сжатием:**
```bash
sudo minios-kernel package --repo linux-image-6.12.38+deb13-rt-amd64 --sqfs-comp lz4 -o /tmp/kernel-output
```

#### 3. **Активировать ядро**

```bash
sudo minios-kernel activate 6.12.38+deb13-amd64
```

#### 4. **Удалить ядро**

```bash
sudo minios-kernel delete 6.12.38+deb13-amd64
```

#### 5. **Проверить статус**

```bash
sudo minios-kernel status
```

Показывает статус каталога MiniOS и информацию о текущем ядре.

#### 6. **Показать информацию о ядре**

```bash
sudo minios-kernel info                           # Information about current active kernel
sudo minios-kernel info 6.12.38+deb13-amd64     # Information about specific kernel
```

Показывает подробную информацию о выбранном ядре, включая его статус и доступность.

### **Расширенные опции CLI:**

#### **JSON-вывод (для скриптов):**

```bash
sudo minios-kernel --json list
sudo minios-kernel --json status
sudo minios-kernel --json info
sudo minios-kernel --json package --repo linux-image-6.12.38+deb13-amd64 -o /tmp/output
sudo minios-kernel --json activate 6.12.38+deb13-amd64
sudo minios-kernel --json delete 6.12.38+deb13-amd64
```

#### **Расширенные параметры упаковки:**

```bash
# Use custom temporary directory (requires at least 1024MB free space)
sudo minios-kernel package --repo linux-image-6.12.38+deb13-rt-amd64 -o /tmp/output --temp-dir /custom/temp

# Force package lists update if outdated
sudo minios-kernel package --repo linux-image-6.12.38+deb13-rt-amd64 -o /tmp/output --force-update
```

#### **Справка и использование:**

```bash
minios-kernel --help                    # General help (doesn't require root)
sudo minios-kernel package --help       # Package command help
sudo minios-kernel list --help          # List command help
sudo minios-kernel activate --help      # Activate command help
sudo minios-kernel info --help          # Info command help
sudo minios-kernel status --help        # Status command help
sudo minios-kernel delete --help        # Delete command help
```

## Устранение неполадок

### Частые проблемы и решения:

#### **Каталог MiniOS не найден**

- **Причина:** Инструменты не могут найти каталог MiniOS
- **Решение:** Убедитесь, что вы работаете в системе MiniOS или USB-накопитель корректно смонтирован
- **Проверка:** Выполните `sudo minios-kernel status` для проверки обнаружения каталога

#### **Отказано в доступе**

- **Причина:** Каталог MiniOS доступен только для чтения или недостаточно прав
- **Решение:** Убедитесь, что у вас есть административные права, и файловая система разрешает запись
- **Проверка:** Проверьте статус каталога MiniOS в GUI или CLI

#### **Ошибка установки пакета**

- **Причина:** Повреждённый пакет, проблемы с сетью или зависимостями
- **Решение:**
  - Проверьте целостность файла пакета
  - Проверьте сетевое соединение для пакетов из репозитория
  - Обновите списки пакетов: `sudo apt update`

#### **Kernel panic после активации**

- **Причина:** Несовместимое ядро или отсутствуют драйверы
- **Что делать:** Загрузите рабочую систему MiniOS, сохраните важные данные и восстановите полный комплект проверенных ядер, если он есть. В противном случае переустановите затронутую установку MiniOS. Не пытайтесь чинить систему, смешивая отдельные образы ядра, initramfs или `01-kernel-*.sb` файлы. Подробнее см. [Устранение неполадок](/maintenance-and-recovery/Troubleshooting).

#### **Система загружает старое ядро**

- **Причина:** Конфигурация загрузчика не была обновлена корректно
- **Решение:**
  - Повторно активируйте ядро: `sudo minios-kernel activate <version>`
  - Проверьте, что ядро было правильно упаковано и установлено

#### **Оборудование не работает после смены ядра**

- **Причина:** В новом ядре отсутствуют необходимые драйверы
- **Решение:**
  - Проверьте, что файл модуля ядра SquashFS был установлен
  - Проверьте, поддерживает ли новое ядро ваше оборудование
  - Рассмотрите возможность использования другого варианта ядра

#### **Восстановление после неудачной смены ядра**

Не копируйте отдельный образ ядра, initramfs или `01-kernel-*.sb` модуль из другого образа. Для загрузки ядра MiniOS требуется согласованный комплект. Если полного комплекта нет в наличии через менеджер ядер, переустановите затронутую установку MiniOS вместо ручной сборки загрузочных компонентов. Сначала сохраните важные данные; см. [Устранение неполадок](/maintenance-and-recovery/Troubleshooting).

### **Диагностические команды:**

**Проверить текущий статус системы:**
```bash
sudo minios-kernel status
sudo minios-kernel info     # Current active kernel info
uname -r                    # Current running kernel
cat /proc/version           # Kernel version details
lsmod                       # Loaded kernel modules
```

**Проверить файлы ядра:**
```bash
ls -la /minios/kernels/     # List packaged kernels
ls -la /minios/boot/        # List boot files
```

**Проверить конфигурацию загрузчика:**
```bash
grep -r "vmlinuz" /minios/boot/  # Find kernel references in boot configs
```

## Обзор структуры файлов

Менеджер ядер MiniOS автоматически управляет следующими файлами:

### **Структура репозитория ядер:**

```
/minios/
├── 01-kernel-<version>.sb         # Active kernel module
├── kernels/                       # Repository of inactive/alternative kernels
│   └── <version>/
│       ├── 01-kernel-<version>.sb # SquashFS kernel module
│       ├── vmlinuz-<version>      # Kernel image
│       └── initrfs-<version>.img  # Initial RAM filesystem
├── boot/
│   ├── vmlinuz-<version>          # Active kernel binary
│   ├── initrfs-<version>.img      # Active initial RAM filesystem
│   ├── syslinux/
│   │   └── syslinux.cfg           # SYSLINUX bootloader config
│   └── grub/
│       └── grub.cfg               # GRUB bootloader config
```

**Примечание:** Стандартный модуль `01-kernel-<version>.sb`, поставляемый с MiniOS, содержит дополнительные драйверы по сравнению с оригинальными пакетами ядра из репозитория. Эти дополнительные драйверы обеспечивают расширенную совместимость с беспроводными адаптерами и устройствами хранения данных.

### **Индикаторы статуса:**

- **АКТИВНО:** Ядро выбрано в загрузчике (будет загружено при следующей перезагрузке)
- **ЗАПУЩЕНО:** В данный момент выполняется это ядро
- **ДОСТУПНО:** Упаковано и готово к активации

### **Автоматические операции:**

- Упаковка и сжатие ядра
- Генерация initramfs с необходимыми драйверами
- Установка в репозиторий MiniOS
- Обновление конфигурации загрузчика
- Управление символическими ссылками для активных ядер
- Удаление временных файлов

## Рекомендации по использованию

### **Выбор ядра:**

- По возможности используйте ядра из официальных репозиториев Debian/Ubuntu
- Тестируйте новые ядра сначала в тестовой среде
- Держите хотя бы одно проверенное рабочее ядро для восстановления

### **Перед установкой:**

- Убедитесь, что каталог MiniOS доступен для записи
- Проверьте, достаточно ли места на диске (ядра могут занимать 100–500 МБ)
- Обновите списки пакетов для ядер из репозитория

### **После установки:**

- Тщательно протестируйте новое ядро
- Убедитесь, что всё оборудование работает корректно
- Сохраняйте предыдущее ядро в качестве резервного, пока новое не подтвердит свою стабильность

### **Планирование восстановления:**

- Всегда храните полный комплект проверенного рабочего ядра
- Знайте, как загрузиться с аварийного носителя при необходимости
- Документируйте, какие ядра работают с вашей аппаратной конфигурацией
