# USB-Erstellungstools

MiniOS kann mithilfe verschiedener Tools, abhängig vom Betriebssystem, auf ein USB-Laufwerk installiert werden.

## Empfohlene Tools

### Windows

- **[Rufus](Rufus.md)** – Zuverlässig und vielseitig. Empfohlen für die meisten Nutzer.
- **[Balena Etcher](Balena-Etcher.md)** – Einfach, plattformübergreifend, moderne Benutzeroberfläche.
- **[Ventoy](Ventoy.md)** – Ermöglicht das Ablegen mehrerer ISOs auf einem Laufwerk ohne erneutes Formatieren.

### Linux

- **[dd command](dd.md)** – Universelles Kommandozeilen-Tool. Schnell und auf den meisten Distributionen vorinstalliert.
- **[Balena Etcher](Balena-Etcher.md)** – Einfache grafische Oberfläche.
- **[Dateibasierte USB-Installation](File-Based-USB-Installation.md)** – MiniOS-Dateien manuell kopieren und den SYSLINUX-Bootloader installieren.

### macOS

- **[Balena Etcher](Balena-Etcher.md)** – Die einfachste Methode für Mac-Anwender.
- **[dd-Befehl](dd.md)** – Für fortgeschrittene Nutzer, die sich mit dem Terminal auskennen.

## Weitere Tools

- **[UNetbootin](UNetbootin.md)** – Ein Klassiker, allerdings manchmal weniger zuverlässig mit modernen ISOs.
- **[Laufwerksdienstprogramm](Drive-Utility.md)** – GNOME Disks oder ähnliche integrierte Tools.
