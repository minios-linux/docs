# USB-Erstellungstools

MiniOS kann mithilfe verschiedener Tools, abhängig vom Betriebssystem, auf ein USB-Laufwerk installiert werden.

## Empfohlene Tools

### 🖥️ Windows

- **[Rufus](Rufus.md)** – Zuverlässig und vielseitig. Für die meisten Nutzer empfohlen.
- **[Balena Etcher](Balena-Etcher.md)** – Einfach, plattformübergreifend, moderne Oberfläche.
- **[Ventoy](Ventoy.md)** – Ermöglicht das Ablegen mehrerer ISOs auf einem Laufwerk ohne Neuformatierung.

### 🐧 Linux

- **[dd-Befehl](dd.md)** – Universelles Kommandozeilen-Tool. Schnell und auf den meisten Distributionen vorinstalliert.
- **[Balena Etcher](Balena-Etcher.md)** – Einfache grafische Oberfläche.
- **[Originalmethode](Original-Method.md)** – Nutzung von Standard-Linux-Tools (`cp`, `tar`).

### 🍎 macOS

- **[Balena Etcher](Balena-Etcher.md)** – Der einfachste Weg für Mac-Nutzer.
- **[dd-Befehl](dd.md)** – Für fortgeschrittene Nutzer, die sich mit dem Terminal auskennen.

## Weitere Tools

- **[UNetbootin](UNetbootin.md)** – Ein Klassiker, allerdings manchmal weniger zuverlässig mit modernen ISOs.
- **[Laufwerksdienstprogramm](Drive-Utility.md)** – GNOME Disks oder ähnliche integrierte Tools.
