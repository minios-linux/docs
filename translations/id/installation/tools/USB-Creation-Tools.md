# Alat Pembuatan USB

MiniOS dapat diinstal ke drive USB menggunakan berbagai alat tergantung pada sistem operasi Anda.

## Alat yang Direkomendasikan

### 🖥️ Windows

- **[Rufus](Rufus.md)** - Andal dan serbaguna. Direkomendasikan untuk sebagian besar pengguna.
- **[Balena Etcher](Balena-Etcher.md)** - Antarmuka sederhana, lintas platform, dan modern.
- **[Ventoy](Ventoy.md)** - Memungkinkan menempatkan beberapa file ISO dalam satu drive tanpa perlu format ulang.

### 🐧 Linux

- **[Perintah dd](dd.md)** - Alat command-line universal. Cepat dan sudah terpasang di sebagian besar distro.
- **[Balena Etcher](Balena-Etcher.md)** - Antarmuka grafis yang mudah digunakan.
- **[Metode Asli](Original-Method.md)** - Menggunakan alat standar Linux (`cp`, `tar`).

### 🍎 macOS

- **[Balena Etcher](Balena-Etcher.md)** - Cara termudah untuk pengguna Mac.
- **[Perintah dd](dd.md)** - Untuk pengguna tingkat lanjut yang terbiasa dengan terminal.

## Alat Lainnya

- **[UNetbootin](UNetbootin.md)** - Alat klasik, meskipun terkadang kurang stabil dengan ISO modern.
- **[Drive Utility](Drive-Utility.md)** - GNOME Disks atau utilitas bawaan serupa.
