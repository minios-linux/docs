# MiniOS: La experiencia Linux portátil definitiva 🌐

MiniOS es una distribución Linux versátil y portátil basada en Debian, creada con los scripts minios-live. Su objetivo principal es ofrecer un entorno completo y cómodo para trabajar, entretenerse y crear en cualquier hardware compatible con x86, mientras mantiene tus datos personales a salvo en medios extraíbles.

## Basado en Debian: Estabilidad y Versatilidad 🎯

Construido sobre la sólida base de Debian, MiniOS hereda todas las ventajas de una de las distribuciones Linux más estables y seguras. Esta base le proporciona a MiniOS:

- **Estabilidad**: Garantiza una experiencia de usuario fluida y confiable.
- **Seguridad**: Se beneficia del fuerte enfoque en seguridad de Debian, con actualizaciones y parches oportunos.
- **Compatibilidad**: Acceso al extenso repositorio de paquetes de software de Debian.
- **Soporte de la comunidad**: Aprovecha el amplio conocimiento y respaldo de la comunidad de Debian.

## Características clave de MiniOS 🛠️

- **Modularidad**: Ofrece una amplia variedad de módulos personalizables para adaptar el sistema a necesidades específicas.
- **Portabilidad**: Diseñado para instalarse en una unidad USB y usarse en diferentes dispositivos.
- **Compatibilidad**: Funciona en una gran variedad de sistemas, con soporte para UEFI y BIOS heredado.
- **Actualizaciones**: Incluye la versión más reciente con kernel actualizado y herramientas adicionales para depuración.

## Ediciones de MiniOS: Personalizadas para tus necesidades 📦

### 🚀 **Standard**: El caballo de batalla confiable

MiniOS Standard es tu opción ideal para las tareas diarias. Confiable, bien equipado y listo para la acción, es la columna vertebral de la familia MiniOS.

### 🧰 **Toolbox**: El kit de herramientas para usuarios avanzados

MiniOS Toolbox está diseñado para profesionales y usuarios avanzados que necesitan un conjunto robusto de utilidades para administración del sistema, particionado de discos y tareas de recuperación de datos. Es el kit definitivo para quienes requieren capacidades avanzadas de gestión del sistema.

### ⚡ **Ultra**: La estación de trabajo todo en uno

MiniOS Ultra es la versión más completa de MiniOS, combinando todas las funciones y herramientas de las ediciones Standard y Toolbox, además de software adicional para desarrollo, multimedia y redes avanzadas. Ideal para quienes buscan una estación de trabajo portátil y lista para usar con todo incluido.

Para consultar la lista detallada de paquetes incluidos en cada edición, visita: [Lista de Paquetes](/administration/Packages.md)

## ¿Por qué elegir MiniOS? 💡

MiniOS destaca como una opción inteligente para quienes necesitan un sistema operativo portátil, estable y seguro. Es perfecto para revivir PCs antiguos, crear una estación de trabajo portátil o simplemente disfrutar la libertad de Linux en cualquier lugar.
