# Herramientas para crear USB

MiniOS se puede instalar en una unidad USB utilizando varias herramientas, según tu sistema operativo.

## Herramientas recomendadas

### Windows

- **[Rufus](Rufus.md)** - Fiable y versátil. Recomendado para la mayoría de los usuarios.
- **[Balena Etcher](Balena-Etcher.md)** - Interfaz sencilla, multiplataforma y moderna.
- **[Ventoy](Ventoy.md)** - Permite colocar varias imágenes ISO en una sola unidad sin reformatear.

### Linux

- **[dd command](dd.md)** - Herramienta universal de línea de comandos. Rápida y preinstalada en la mayoría de las distribuciones.
- **[Balena Etcher](Balena-Etcher.md)** - Interfaz gráfica sencilla.
- **[Instalación USB basada en archivos](File-Based-USB-Installation.md)** - Copia manualmente los archivos de MiniOS e instala el gestor de arranque SYSLINUX.

### macOS

- **[Balena Etcher](Balena-Etcher.md)** - La forma más sencilla para usuarios de Mac.
- **[dd command](dd.md)** - Para usuarios avanzados que se sienten cómodos con la terminal.

## Otras herramientas

- **[UNetbootin](UNetbootin.md)** - Una herramienta clásica, aunque a veces menos fiable con ISOs modernas.
- **[Drive Utility](Drive-Utility.md)** - GNOME Disks u otras utilidades integradas similares.
