# Herramientas para crear USB

MiniOS se puede instalar en una unidad USB utilizando varias herramientas, según tu sistema operativo.

## Herramientas recomendadas

### 🖥️ Windows

- **[Rufus](Rufus.md)** - Fiable y versátil. Recomendado para la mayoría de los usuarios.
- **[Balena Etcher](Balena-Etcher.md)** - Interfaz sencilla, multiplataforma y moderna.
- **[Ventoy](Ventoy.md)** - Permite colocar varias ISOs en una sola unidad sin formatear.

### 🐧 Linux

- **[Comando dd](dd.md)** - Herramienta universal de línea de comandos. Rápida y preinstalada en la mayoría de las distribuciones.
- **[Balena Etcher](Balena-Etcher.md)** - Interfaz gráfica sencilla.
- **[Método original](Original-Method.md)** - Utilizando herramientas estándar de Linux (`cp`, `tar`).

### 🍎 macOS

- **[Balena Etcher](Balena-Etcher.md)** - La forma más fácil para usuarios de Mac.
- **[Comando dd](dd.md)** - Para usuarios avanzados que se sienten cómodos con la terminal.

## Otras herramientas

- **[UNetbootin](UNetbootin.md)** - Una herramienta clásica, aunque a veces menos fiable con ISOs modernas.
- **[Drive Utility](Drive-Utility.md)** - GNOME Disks u otras utilidades integradas similares.
