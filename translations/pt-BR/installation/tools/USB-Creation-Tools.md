# Ferramentas para Criação de USB

O MiniOS pode ser instalado em um pendrive usando várias ferramentas, dependendo do seu sistema operacional.

## Ferramentas Recomendadas

### 🖥️ Windows

- **[Rufus](Rufus.md)** - Confiável e versátil. Recomendado para a maioria dos usuários.
- **[Balena Etcher](Balena-Etcher.md)** - Interface simples, moderna e multiplataforma.
- **[Ventoy](Ventoy.md)** - Permite colocar múltiplos ISOs em um único drive sem precisar formatar.

### 🐧 Linux

- **[Comando dd](dd.md)** - Ferramenta universal de linha de comando. Rápida e já vem instalada na maioria das distros.
- **[Balena Etcher](Balena-Etcher.md)** - Interface gráfica fácil de usar.
- **[Método Original](Original-Method.md)** - Usando ferramentas padrão do Linux (`cp`, `tar`).

### 🍎 macOS

- **[Balena Etcher](Balena-Etcher.md)** - A maneira mais fácil para usuários de Mac.
- **[Comando dd](dd.md)** - Para usuários avançados que já têm familiaridade com o terminal.

## Outras Ferramentas

- **[UNetbootin](UNetbootin.md)** - Uma ferramenta clássica, embora às vezes menos confiável com ISOs mais recentes.
- **[Utilitário de Disco](Drive-Utility.md)** - GNOME Disks ou outros utilitários nativos semelhantes.
