# USB Creation Tools


MiniOS can be installed to a USB drive using various tools depending on your operating system.

## Recommended Tools

### Windows
- **[Rufus](Rufus.md)** - Reliable and versatile. Recommended for most users.
- **[Balena Etcher](Balena-Etcher.md)** - Simple, cross-platform, modern interface.
- **[Ventoy](Ventoy.md)** - Allows placing multiple ISOs on one drive without reformatting.

### Linux
- **[dd command](dd.md)** - Universal command-line tool. Fast and pre-installed on most distros.
- **[Balena Etcher](Balena-Etcher.md)** - Easy graphical interface.
- **[File-based USB installation](File-Based-USB-Installation.md)** - Copy MiniOS files manually and install the SYSLINUX bootloader.

### macOS
- **[Balena Etcher](Balena-Etcher.md)** - The easiest way for Mac users.
- **[dd command](dd.md)** - For advanced users comfortable with the terminal.

## Other Tools
- **[UNetbootin](UNetbootin.md)** - A classic tool, though sometimes less reliable with modern ISOs.
- **[Drive Utility](Drive-Utility.md)** - GNOME Disks or similar built-in utilities.
